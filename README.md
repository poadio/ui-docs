# ui-docs

Site statique de la documentation de la bibliothèque poad UI, servi par GitHub Pages sur https://ui.poad.io.

Ce dépôt ne contient que le site construit. La source est dans `poadio/ui` (dossier `site/`, `bun run site:build`, sortie `site/dist/`).
Ne pas retirer `CNAME` (domaine) ni `.nojekyll` (sert tels quels les dossiers qui commencent par `_`, comme `_astro/`).
