Jetons et thèmes

Une seule source : @poadio/ui-core/tokens.css. Les composants ne lisent que des jetons --poad-* — aucun sélecteur de thème dans leurs feuilles. Redéfinir un jeton change le composant dans tous les frameworks à la fois.

Trois couches

Primitifs

Rayons, tailles de police, durées, polices : --poad-radius, --poad-font, --poad-dur…

Sémantiques

Surfaces, texte, accent, sévérités, ombres : --poad-bg, --poad-fg, --poad-accent, --poad-danger…

Composants

Hauteurs de contrôle, champs : --poad-control-h, --poad-input-bg… Densité tactile : classe poad-touch sur <html>.

Clair et sombre

Le thème est porté par la classe theme-dark (ou theme-light) sur <html> ou sur une zone : les alias sont redéclarés au porteur de la classe, le thème se limite donc à n’importe quel sous-arbre. Le bouton lune / soleil de ce site fait exactement cela — les démos de chaque framework suivent.

<!-- Le thème sombre : une classe sur <html> (ou sur n'importe quelle zone) -->
<html class="theme-dark">

/* Les jetons --poad-* reprennent les variables de base de l'application (--surface-*, --text-*…),
   avec un repli clair. Pour le sombre, définissez-les sous .theme-dark : */
.theme-dark {
  --surface-ground: #0d1117; --surface-section: #161b22; --surface-card: #161b22; --surface-overlay: #21262d;
  --surface-border: #30363d; --surface-hover: #21262d;
  --text-primary: #f0f6fc; --text-secondary: #9ba5b0; --text-muted: #7d8590;
  --input-bg: #0d1117; --input-border: #30363d;
}

Personnaliser

/* Toute l'application */
:root {
  --poad-accent: #0e7c66;
  --poad-accent-hover: #0b6654;
  --poad-accent-soft: rgba(14, 124, 102, .12);
  --poad-ring: rgba(14, 124, 102, .35);
  --poad-radius: 10px;
}

/* Une zone seulement (même mécanique pour un thème sombre local) */
.marketing { --poad-font: 'Inter', system-ui, sans-serif; }
