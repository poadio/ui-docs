Langues (i18n)

Règle de la bibliothèque : aucune phrase, dans aucune langue, n'est écrite en dur dans un composant. Tout texte visible ou lu par un lecteur d'écran vient d'un catalogue de messages — UI_EN, UI_FR, dans @poadio/ui-core — ou de l'application. Une garde (tools/check-i18n.mjs) le vérifie pour chaque paquet.

Choisir la langue

Sans rien fournir, la bibliothèque parle anglais. Chaque rendu a son moyen idiomatique de fournir la langue et le catalogue ; la langue (locale) sert aussi aux formats (Intl : nombres, pourcentages).

import { provideUiI18n, UiI18n, UI_FR, UI_EN } from '@poadio/ui-angular';

// au démarrage
providers: [provideUiI18n({ locale: 'fr-FR', messages: UI_FR })]

// à chaud, sans rechargement
inject(UiI18n).use('en-GB', UI_EN);
import { UiI18nProvider, useUiI18n, UI_EN, UI_FR } from '@poadio/ui-react';

<UiI18nProvider locale={lang === 'fr' ? 'fr-FR' : 'en-GB'} messages={lang === 'fr' ? UI_FR : UI_EN}>
  <App />
</UiI18nProvider>

// dans un composant
const { t, locale } = useUiI18n();   // t('common.close')
import { createPoadUi, provideUiI18n, useUiI18n, UI_EN, UI_FR } from '@poadio/ui-vue';

app.use(createPoadUi({ locale: 'fr-FR', messages: UI_FR }));

// un sous-arbre, langue réactive (ref ou getter)
provideUiI18n({ locale: () => lang.value, messages: () => (lang.value === 'fr' ? UI_FR : UI_EN) });
<html lang="fr">
<script type="module">
  import { registerUiMessages, setUiLocale, refreshUi, UI_FR } from '@poadio/ui-elements';
  registerUiMessages('fr', UI_FR);  // l'anglais est déjà là
  setUiLocale('fr');                // quand aucun lang ne s’applique
  // chaque élément suit le lang le plus proche ; après un changement de lang : refreshUi()
</script>

Sur ce site, les démos de la version française reçoivent UI_FR, celles de la version anglaise UI_EN : changez de langue (bouton en haut à droite) pour voir les textes des composants changer.

Une autre langue

import { UI_EN, type UiMessages } from '@poadio/ui-core';

// Un catalogue complet, typé : TypeScript signale toute clé manquante.
export const UI_DE: UiMessages = {
  ...UI_EN,
  common: { ...UI_EN.common, close: 'Schließen', clear: 'Leeren' },
  field: { ...UI_EN.field, increment: 'Erhöhen', decrement: 'Verringern' },
};

Les messages acceptent des paramètres ({label}, {n}) ; un texte passé par l’application à une option (par exemple aria-label, optionalText) l’emporte toujours sur le catalogue.
