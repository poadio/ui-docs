Installation

Deux paquets : le rendu de votre framework, et @poadio/ui-core (jetons, feuilles de style, catalogue de messages, icônes) que chaque rendu partage.

PaquetPourRendu serveur
@poadio/ui-corele socle, sans framework (toujours installé)aucun accès au DOM au chargement
@poadio/ui-angularAngular 21+Angular SSR
@poadio/ui-reactReact 19, Next.jsApp Router : 'use client' sur les composants interactifs
@poadio/ui-vueVue 3.5+, NuxtNuxt, vue/server-renderer ; identifiants stables (useId)
@poadio/ui-elementsHTML, Svelte, Solid, Astro, pages rendues par un serveurimport sûr côté serveur ; le DOM intérieur est dessiné dans le navigateur

1. Installer

npm i @poadio/ui-angular @poadio/ui-core
npm i @poadio/ui-react @poadio/ui-core
npm i @poadio/ui-react @poadio/ui-core
npm i @poadio/ui-vue @poadio/ui-core
npm i @poadio/ui-elements @poadio/ui-core

2. Charger les styles

Les styles vivent dans @poadio/ui-core, en CSS pur, une feuille par composant : la même feuille habille tous les frameworks. Les jetons d'abord, puis la base, puis ce que l'application emploie. (Angular inclut la feuille de chaque composant à la construction : seuls tokens.css et base.css sont à charger.)

/* Une fois, dans la feuille globale de l'application */
@import '@poadio/ui-core/tokens.css';   /* jetons --poad-*, thèmes clair / sombre */
@import '@poadio/ui-core/base.css';     /* focus, mouvement réduit, .poad-input */
@import '@poadio/ui-core/switch.css';   /* puis une feuille par composant employé : */
@import '@poadio/ui-core/button.css';   /* button, field, select, option-list, icon, badge, tag, chip, avatar, */
@import '@poadio/ui-core/field.css';    /* divider, skeleton, progress, meter, message, checkbox, radio, segmented, */
@import '@poadio/ui-core/icon.css';     /* toggle-button, button-group, number, password, rating, slider, inplace */

3. Brancher la langue et utiliser un composant

// app.config.ts
import { ApplicationConfig } from '@angular/core';
import { provideUiI18n, UI_FR } from '@poadio/ui-angular';

export const appConfig: ApplicationConfig = {
  providers: [
    provideUiI18n({ locale: 'fr-FR', messages: UI_FR }), // défaut : anglais
  ],
};

// un composant standalone importe ce qu’il emploie
import { PoadSwitchComponent, PoadButtonComponent } from '@poadio/ui-angular';
@Component({ imports: [PoadSwitchComponent, PoadButtonComponent], template: `
  <poad-switch [(value)]="wifi" label="Wi-Fi" />
  <button poadButton (click)="save()">Save</button>` })
// app/layout.tsx — composant serveur
import '@poadio/ui-core/tokens.css';
import '@poadio/ui-core/base.css';
import '@poadio/ui-core/switch.css';
import { Providers } from './providers';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return <html lang="fr"><body><Providers>{children}</Providers></body></html>;
}

// app/providers.tsx — le fournisseur de langue est un composant client
'use client';
import { UiI18nProvider, UI_FR } from '@poadio/ui-react';
export function Providers({ children }: { children: React.ReactNode }) {
  return <UiI18nProvider locale="fr-FR" messages={UI_FR}>{children}</UiI18nProvider>;
}
// main.tsx
import '@poadio/ui-core/tokens.css';
import '@poadio/ui-core/base.css';
import '@poadio/ui-core/switch.css';
import { createRoot } from 'react-dom/client';
import { UiI18nProvider, UI_FR } from '@poadio/ui-react';
import App from './App';

createRoot(document.getElementById('root')!).render(
  <UiI18nProvider locale="fr-FR" messages={UI_FR}>   {/* défaut : anglais */}
    <App />
  </UiI18nProvider>,
);
// main.ts (Vite)
import '@poadio/ui-core/tokens.css';
import '@poadio/ui-core/base.css';
import '@poadio/ui-core/switch.css';
import { createApp } from 'vue';
import { createPoadUi, UI_FR } from '@poadio/ui-vue';
import App from './App.vue';

createApp(App).use(createPoadUi({ locale: 'fr-FR', messages: UI_FR })).mount('#app');

// Nuxt — nuxt.config.ts : css: ['@poadio/ui-core/tokens.css', '@poadio/ui-core/base.css', …]
// plugins/poad-ui.ts
export default defineNuxtPlugin((nuxt) => nuxt.vueApp.use(createPoadUi({ locale: 'fr-FR', messages: UI_FR })));
<html lang="fr">
<head>
  <link rel="stylesheet" href="/node_modules/@poadio/ui-core/tokens.css">
  <link rel="stylesheet" href="/node_modules/@poadio/ui-core/base.css">
  <link rel="stylesheet" href="/node_modules/@poadio/ui-core/switch.css">
  <script type="module">
    import { defineElements, registerUiMessages, UI_FR } from '@poadio/ui-elements';
    registerUiMessages('fr', UI_FR);   // chaque élément suit le lang le plus proche
    defineElements();                  // <poad-switch>, <poad-button>… (ou { prefix: 'poadx' })
  </script>
</head>
<body>
  <form>
    <poad-switch name="wifi" label="Wi-Fi" checked></poad-switch>
    <poad-button type="submit">Save</poad-button>
  </form>
</body>
</html>

Rendu serveur

  • Next.js : les composants qui ont un état ou des gestionnaires commencent par 'use client' dans le paquet ; PoadButton, PoadBadge, PoadTag, PoadAvatar, PoadDivider, PoadSkeleton se rendent aussi dans un composant serveur. Le HTML sort du serveur, l'hydratation reprend la main.
  • Nuxt : @poadio/ui-vue ne touche ni window ni document pendant le rendu ; mesures et écouteurs globaux après montage seulement.
  • Composants web : honnêtement, pas de rendu serveur du contenu. Le serveur écrit les balises et leurs attributs ; le DOM intérieur est dessiné à la définition, dans le navigateur. Pour un rendu serveur complet : React (Next.js) ou Vue (Nuxt).
  • Angular : compatible avec le rendu serveur d’Angular ; la liste déroulante passe par l’overlay du CDK (@angular/cdk/overlay-prebuilt.css).

Composants web et Angular dans la même page

Les éléments portent les noms des sélecteurs d'Angular (poad-switch…). Si une application Angular charge aussi les composants web, enregistrez-les sous un autre préfixe : defineElements({ prefix: 'poadx' }) → <poadx-switch>, sans quoi le navigateur « mettrait à niveau » les hôtes Angular.
