Paginateur

<poad-paginator>

La navigation entre les pages d’une liste : liens de pages avec ellipses autour de la page courante, page précédente et suivante, première et dernière, rapport « 41–50 sur 137 » et taille de page qui garde la page en cours.

Angularrendu par @poadio/ui-angularNext.jsrendu par @poadio/ui-reactReactrendu par @poadio/ui-reactVuerendu par @poadio/ui-vueVanillarendu par @poadio/ui-elements

Votre réglage : :root { }

Réglage en direct, dans la démo seulement : rien n’est enregistré.

@Component({

    </div>
    <code>first={{ first() }} rows={{ rows() }}</code>
  `,
})
export default class PaginatorDemo {
  readonly first = signal(0);
  readonly rows = signal(10);
}

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/paginator-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadPaginator } from '@poadio/ui-react';

export default function PaginatorDemo() {
  const [first, setFirst] = useState(0);
  const [rows, setRows] = useState(10);
  return (
    <>
      <div className="demo-wide">
        <PoadPaginator totalRecords={137} first={first} rows={rows} rowsPerPageOptions={[10, 25, 50]} showFirstLastIcon
          onPageChange={(e) => { setFirst(e.first); setRows(e.rows); }} />
      </div>
      <code>first={first} rows={rows}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import PaginatorDemo from './paginator-demo';

export default function Page() {
  return <PaginatorDemo />;
}

À quoi ça sert

Sous une liste ou une grille de cartes paginée par l’application ou par un serveur. Sous une table, inutile : la table a le sien (paginator).

Accessibilité

  • Région role="navigation" nommée par le catalogue (« Pagination ») ; page courante marquée aria-current="page".
  • Taille de page : une liste déroulante de la bibliothèque (role="combobox", jamais de <select> natif), nommée par son libellé (« Lignes par page »).
  • Boutons sans texte nommés par le catalogue (« Page suivante », « Page 3 »…) ; ellipses cachées des technologies d’assistance.

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius: 4px;            /* Arrondi des coins des contrôles */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius: 0;              /* Arrondi des coins des contrôles */
}

À quoi ça sert

Quand chaque élément se lit mieux en carte ou en ligne riche qu’en colonnes : ouvrages, projets, fichiers. L’application fournit un gabarit de liste et (ou) de grille ; showLayoutSwitch ajoute la bascule, gridCols règle les colonnes par point de rupture ("1 sm:2 lg:3") ou gridMin une largeur minimale de carte. sortField / sortOrder trient, filterValue cherche (sans accents ni casse) dans filterBy, paginator découpe en pages. Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius: 4px;            /* Arrondi des coins des contrôles */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius: 0;              /* Arrondi des coins des contrôles */
}
