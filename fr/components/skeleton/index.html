Squelette

Une silhouette grise et animée qui tient la place d’un contenu en cours de chargement : texte, image, avatar.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular
import { Component } from '@angular/core';
import { PoadSkeletonComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-skeleton-demo',
  imports: [PoadSkeletonComponent],
  template: `
    <div class="demo-row" style="width: min(100%, 420px); flex-wrap: nowrap; align-items: flex-start">
      <poad-skeleton shape="circle" width="40px" height="40px" />
      <div class="demo-col" style="flex: 1">
        <poad-skeleton width="60%" height="14px" />
        <poad-skeleton [lines]="3" />
      </div>
    </div>
    <poad-skeleton shape="rect" width="min(100%, 420px)" height="96px" [animation]="false" />
  `,
})
export default class SkeletonDemo {}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

PoadSkeleton n’a pas d’état : idéal dans un loading.tsx de l’App Router, rendu sur le serveur.

// app/skeleton-demo.tsx — composant client (état, gestionnaires)
'use client';

import { PoadSkeleton } from '@poadio/ui-react';

export default function SkeletonDemo() {
  return (
    <>
      <div className="demo-row" style={{ width: 'min(100%, 420px)', flexWrap: 'nowrap', alignItems: 'flex-start' }}>
        <PoadSkeleton shape="circle" width="40px" height="40px" />
        <div className="demo-col" style={{ flex: 1 }}>
          <PoadSkeleton width="60%" height="14px" />
          <PoadSkeleton lines={3} />
        </div>
      </div>
      <PoadSkeleton shape="rect" width="min(100%, 420px)" height="96px" animation={false} />
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import SkeletonDemo from './skeleton-demo';

export default function Page() {
  return <SkeletonDemo />;
}

À quoi ça sert

Reprenez la forme du contenu attendu : la page ne saute pas quand il arrive. Annoncez le chargement autrement (indicateur, aria-busy sur la zone) : le squelette est invisible aux lecteurs d’écran.

Clavier

Aucune interaction clavier : composant d’affichage.

Accessibilité

  • Caché aux technologies d’assistance (aria-hidden="true") : une barre par ligne, aucune n’est lue.
  • Le reflet respecte prefers-reduced-motion.

Vérifié par le banc de conformité — Ces scénarios sont joués, à l’identique, sur chaque rendu déclaré (angular, react, vue, elements) à chaque push :

  • skeleton/lines-and-shape

Attributs vérifiés : aria-hidden

Textes du catalogue

Aucun texte de la bibliothèque : tout ce qui s'affiche vient de l'application.

Jetons de thème

Jetons --poad-* lus par la feuille @poadio/ui-core/skeleton.css de @poadio/ui-core. Les redéfinir (globalement ou sur un conteneur) suffit à thémer le composant, dans tous les frameworks à la fois.

--poad-elevated --poad-hover --poad-radius
