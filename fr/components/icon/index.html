Icône

Dessine une icône du jeu nommé de la bibliothèque (le même dans chaque framework), en SVG à trait qui prend la couleur du texte.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular
import { Component } from '@angular/core';
import { PoadIconComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-icon-demo',
  imports: [PoadIconComponent],
  template: `
    <div class="demo-row">
      <poad-icon name="search" />
      <poad-icon name="bell" [size]="20" />
      <poad-icon name="settings" [size]="24" [strokeWidth]="1.5" />
      <poad-icon name="alert-triangle" label="Warning" filled />
      <poad-icon name="loader" label="Loading" spin />
      <poad-icon name="map-pin" flip="h" />
      <poad-icon name="edit" [rotate]="90" />
    </div>
  `,
})
export default class IconDemo {}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/icon-demo.tsx — composant client (état, gestionnaires)
'use client';

import { PoadIcon } from '@poadio/ui-react';

export default function IconDemo() {
  return (
    <div className="demo-row">
      <PoadIcon name="search" />
      <PoadIcon name="bell" size={20} />
      <PoadIcon name="settings" size={24} strokeWidth={1.5} />
      <PoadIcon name="alert-triangle" label="Warning" filled />
      <PoadIcon name="loader" label="Loading" spin />
      <PoadIcon name="map-pin" flip="h" />
      <PoadIcon name="edit" rotate={90} />
    </div>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import IconDemo from './icon-demo';

export default function Page() {
  return <IconDemo />;
}

Rendu par Vue

Sous-ensemble ou icônes de l’application : createPoadUi({ icons: { … } }) ou provideIconRegistry().

<script setup lang="ts">

<template>

    <PoadIcon name="search" />

À quoi ça sert

Décorative par défaut (cachée aux lecteurs d'écran) ; donnez-lui un label dès qu'elle porte un sens que rien d'autre n'exprime. Le jeu complet et le registre sont décrits sur la page Icônes.

Clavier

Aucune interaction clavier : composant d’affichage.

Accessibilité

  • Hôte role="img" ; sans label, aria-hidden="true" et aucun aria-label.
  • Avec label : nommée par lui, plus d’aria-hidden.
  • <svg viewBox="0 0 24 24"> en currentColor : le contraste est celui du texte qui l’entoure.

Vérifié par le banc de conformité — Ces scénarios sont joués, à l’identique, sur chaque rendu déclaré (angular, react, vue, elements) à chaque push :

  • icon/named-decorative-or-labelled

Attributs vérifiés : role aria-hidden aria-label accessible name

Textes du catalogue

Aucun texte de la bibliothèque : tout ce qui s'affiche vient de l'application.

Jetons de thème

Jetons --poad-* lus par la feuille @poadio/ui-core/icon.css de @poadio/ui-core. Les redéfinir (globalement ou sur un conteneur) suffit à thémer le composant, dans tous les frameworks à la fois.
