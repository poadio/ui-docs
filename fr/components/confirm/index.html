Confirmation

<poad-confirm>

Une question oui / non posée par le code et attendue comme une promesse : boîte titrée avec message et icône, bouton d’acceptation de la sévérité, saisie exigée pour les actions graves ; true si accepté, false sinon (annuler, croix, Échap, fond).

Disponible en····

Démonstration

Angularrendu par @poadio/ui-angularNext.jsrendu par @poadio/ui-reactReactrendu par @poadio/ui-reactVuerendu par @poadio/ui-vueVanillarendu par @poadio/ui-elements

Votre réglage : :root { }

Réglage en direct, dans la démo seulement : rien n’est enregistré.

Chargement de la démo…

La démo ne s’est pas chargée. Une nouvelle version du site vient peut-être d’être publiée.

Aucun composant à poser : PoadConfirmService ouvre la boîte par PoadDialogService (overlay du CDK). Le message accepte du HTML simple ou un TemplateRef.

import { Component, inject, signal } from '@angular/core';
import { PoadButtonComponent, PoadConfirmService } from '@poadio/ui-angular';

@Component({
  selector: 'app-confirm-demo',
  imports: [PoadButtonComponent],
  template: `
    <div class="demo-row">
      <button poadButton severity="danger" variant="outline" (click)="remove()">Delete project…</button>
    </div>
    <code>result={{ result() }}</code>
  `,
})
export default class ConfirmDemo {
  private readonly confirm = inject(PoadConfirmService);
  readonly result = signal('none');

  async remove(): Promise<void> {
    const ok = await this.confirm.confirm({
      header: 'Delete project?', message: 'This cannot be undone.', severity: 'danger', acceptLabel: 'Delete',
    });
    this.result.set(String(ok));
  }
}

La démo ne s’est pas chargée. Une nouvelle version du site vient peut-être d’être publiée.

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/confirm-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadButton, PoadConfirmProvider, useConfirm } from '@poadio/ui-react';

function DeleteButton({ onResult }: { onResult: (ok: boolean) => void }) {
  const confirm = useConfirm();
  const remove = async () => {
    const ok = await confirm({ header: 'Delete project?', message: 'This cannot be undone.', severity: 'danger', acceptLabel: 'Delete' });
    onResult(ok);
  };
  return <PoadButton severity="danger" variant="outline" onClick={remove}>Delete project…</PoadButton>;
}

export default function ConfirmDemo() {
  const [result, setResult] = useState('none');
  return (
    <PoadConfirmProvider>
      <div className="demo-row">
        <DeleteButton onResult={(ok) => setResult(String(ok))} />
      </div>
      <code>result={result}</code>
    </PoadConfirmProvider>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import ConfirmDemo from './confirm-demo';

export default function Page() {
  return <ConfirmDemo />;
}

À quoi ça sert

Avant une action irréversible ou coûteuse. Pas pour informer (un toast) ni pour saisir plusieurs champs (une boîte de dialogue).

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius: 4px;            /* Arrondi des coins des contrôles */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius: 0;              /* Arrondi des coins des contrôles */
}
app/globals.css
