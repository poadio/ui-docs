Tiroir de navigation

<poad-nav-drawer>

Le menu principal d’une application, sur le côté : une colonne permanente sur grand écran, un tiroir par-dessus le contenu sur mobile, ou un rail d’icônes. Intertitres, groupes repliables, destination courante.

À quoi ça sert

Pour une application qui a plus de destinations qu’une barre de menus n’en montre, ou qui les regroupe. En auto (défaut), le point de rupture de la fenêtre décide : colonne au-dessus de breakpoint (md), tiroir modal en dessous, ouvert par votre bouton « menu » (open) ; railBelow intercale un rail d’icônes. Sur mobile, les trois à cinq destinations les plus fréquentes vont plutôt dans une barre de navigation basse. Donnez un value à chaque intertitre repliable : c’est sa clé dans collapsed, que vous pouvez conserver.

Accessibilité

  • Région navigation nommée par le catalogue (« Menu principal »), liste d’entrées ; la destination courante porte aria-current="page" et un filet en plus de la couleur.
  • Tiroir ouvert : boîte de dialogue modale (role="dialog", aria-modal), focus posé sur la destination courante et piégé, voile ; fermé, le panneau est caché et inerte (aria-hidden, inert).
  • Intertitre repliable : un bouton aria-expanded qui garde le compte de son groupe une fois replié. En rail, le libellé passe en title et en nom accessible, le compte devient un point.

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius-pill: 6px;       /* Arrondi complet : pastilles, badges, étiquettes */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius-pill: 0;         /* Arrondi complet : pastilles, badges, étiquettes */
}
