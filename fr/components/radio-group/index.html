Boutons radio

Un choix exclusif parmi quelques options visibles d’un coup, chacune avec une aide facultative.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular
import { Component, signal } from '@angular/core';
import { PoadRadioComponent, PoadRadioGroupComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-radio-group-demo',
  imports: [PoadRadioGroupComponent, PoadRadioComponent],
  template: `
    <poad-radio-group [(value)]="mode" ariaLabel="Pooling mode" orientation="horizontal">
      <poad-radio value="transaction" label="Transaction" />
      <poad-radio value="session" label="Session" />
      <poad-radio value="statement" label="Statement" disabled />
    </poad-radio-group>
    <poad-radio-group [(value)]="plan" ariaLabel="Database plan">
      <poad-radio value="env" label="One per environment" hint="Strong isolation, more databases." />
      <poad-radio value="project" label="One per project" hint="One schema per environment." />
      <poad-radio value="shared" label="Shared" hint="Serverless pool (default)." />
    </poad-radio-group>
    <code>mode={{ mode() }} · plan={{ plan() }}</code>
  `,
})
export default class RadioGroupDemo {
  readonly mode = signal<string | null>('transaction');
  readonly plan = signal<string | null>('shared');
}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/radio-group-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadRadio, PoadRadioGroup } from '@poadio/ui-react';

export default function RadioGroupDemo() {
  const [mode, setMode] = useState<unknown>('transaction');
  const [plan, setPlan] = useState<unknown>('shared');
  return (
    <>
      <PoadRadioGroup aria-label="Pooling mode" orientation="horizontal" value={mode} onValueChange={setMode}>
        <PoadRadio value="transaction" label="Transaction" />
        <PoadRadio value="session" label="Session" />
        <PoadRadio value="statement" label="Statement" disabled />
      </PoadRadioGroup>
      <PoadRadioGroup aria-label="Database plan" value={plan} onValueChange={setPlan}>
        <PoadRadio value="env" label="One per environment" hint="Strong isolation, more databases." />
        <PoadRadio value="project" label="One per project" hint="One schema per environment." />
        <PoadRadio value="shared" label="Shared" hint="Serverless pool (default)." />
      </PoadRadioGroup>
      <code>mode={String(mode)} · plan={String(plan)}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import RadioGroupDemo from './radio-group-demo';

export default function Page() {
  return <RadioGroupDemo />;
}

Clavier

ToucheEffet
↓ →Choisit l’option suivante (en boucle, options désactivées sautées).
↑ ←Choisit l’option précédente (en boucle).
TabEntre dans le groupe sur l’option choisie (un seul arrêt de tabulation), puis en sort.

Accessibilité

  • role="radiogroup" nommé par aria-label ; chaque option role="radio" avec aria-checked.
  • Tabulation itinérante : seule l’option choisie (sinon la première active) a tabindex="0".
  • Groupe désactivé : aucune flèche ne change la valeur.

Vérifié par le banc de conformité — Ces scénarios sont joués, à l’identique, sur chaque rendu déclaré (angular, react, vue, elements) à chaque push :

Jetons de thème

Jetons --poad-* lus par la feuille @poadio/ui-core/radio.css de @poadio/ui-core. Les redéfinir (globalement ou sur un conteneur) suffit à thémer le composant, dans tous les frameworks à la fois.

--poad-font --poad-font-size --poad-fg --poad-ring --poad-border-strong --poad-input-bg --poad-dur --poad-fg-on-accent --poad-accent --poad-fg-muted
