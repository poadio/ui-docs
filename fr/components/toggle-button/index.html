Bouton à bascule

<poad-toggle-button>

Un bouton qui garde un état : enfoncé ou non. Allumé, il prend le plein de sa sévérité ; éteint, le contour secondaire. Libellé et icône peuvent changer avec l’état.

Votre réglage : :root { }

Réglage en direct, dans la démo seulement : rien n’est enregistré.

import { Component, signal } from '@angular/core';
import { PoadToggleButtonComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-toggle-button-demo',
  imports: [PoadToggleButtonComponent],
  template: `
    <div class="demo-row">
      <poad-toggle-button [(value)]="watching" onLabel="Watching" offLabel="Watch" onIcon="eye" offIcon="eye-off" />
      <poad-toggle-button [(value)]="pinned" onLabel="Pinned" offLabel="Pin" severity="success" size="sm" />
      <poad-toggle-button [value]="true" onLabel="Locked" offLabel="Unlocked" readonly />
      <poad-toggle-button [value]="false" onLabel="On" offLabel="Off" disabled />
    </div>
    <code>watching={{ watching() }} · pinned={{ pinned() }}</code>
  `,
})
export default class ToggleButtonDemo {
  readonly watching = signal<boolean | null>(false);
  readonly pinned = signal<boolean | null>(true);
}

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/toggle-button-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadToggleButton } from '@poadio/ui-react';

export default function ToggleButtonDemo() {
  const [watching, setWatching] = useState(false);
  const [pinned, setPinned] = useState(true);
  return (
    <>
      <div className="demo-row">
        <PoadToggleButton pressed={watching} onPressedChange={setWatching} onLabel="Watching" offLabel="Watch" onIcon="eye" offIcon="eye-off" />
        <PoadToggleButton pressed={pinned} onPressedChange={setPinned} onLabel="Pinned" offLabel="Pin" severity="success" size="sm" />
        <PoadToggleButton defaultPressed onLabel="Locked" offLabel="Unlocked" readOnly />
        <PoadToggleButton onLabel="On" offLabel="Off" disabled />
      </div>
      <code>watching={String(watching)} · pinned={String(pinned)}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import ToggleButtonDemo from './toggle-button-demo';

export default function Page() {
  return <ToggleButtonDemo />;
}

Ouvrir la démo en plein écran

À quoi ça sert

Pour un état qu’on active d’un geste et qui se voit (suivre, épingler, mettre en gras). Pour un réglage, l’interrupteur est plus clair.

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius: 4px;            /* Arrondi des coins des contrôles */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius: 0;              /* Arrondi des coins des contrôles */
}
