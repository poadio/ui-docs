Texte riche

<poad-richtext>

Un champ de texte mis en forme — titres, gras, italique, souligné, barré, code, listes, citation, liens — dont la valeur est un HTML nettoyé par liste blanche, ou du Markdown.

À quoi ça sert

Pour un compte rendu, une description, un message : un texte court à moyen, mis en forme simplement. Notre propre code, sans moteur tiers. Un collage depuis Word ou le web est nettoyé ; un texte Markdown collé est converti ; « ## », « - », « 1. » ou « > » en début de ligne posent le bloc. format="markdown" fait de la valeur du Markdown. Pour un document fait de blocs (images, tableaux, encadrés), préférer l’éditeur de blocs ; pour du code, l’éditeur de code.

Accessibilité

  • Corps role="textbox" aria-multiline="true", nommé par ariaLabel (ou « Texte riche »), aria-invalid au-delà de maxLength, aria-readonly en lecture seule.
  • Barre role="toolbar" nommée, focus itinérant ; chaque bouton nommé avec son raccourci, aria-pressed pour les bascules (gras, listes…) selon le texte sous le curseur.
  • Style de bloc dans le menu de la bibliothèque (aria-haspopup="menu", flèches) ; lien dans sa boîte de dialogue (piège à focus, champ nommé, adresse refusée annoncée par role="alert").
  • Sécurité : liste blanche de balises, AUCUN attribut sauf un href sûr (https://, mailto:, /chemin, #ancre) — ni script, ni attribut d’évènement, ni javascript: ou data:, au collage comme à l’affichage d’une valeur.

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius: 4px;            /* Arrondi des coins des contrôles */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius: 0;              /* Arrondi des coins des contrôles */
}
