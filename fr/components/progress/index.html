Barre de progression

Montre l’avancement d’une tâche : une valeur bornée, ou un mode indéterminé quand la durée est inconnue.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular
import { Component, signal } from '@angular/core';
import { PoadButtonComponent, PoadProgressComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-progress-demo',
  imports: [PoadProgressComponent, PoadButtonComponent],
  template: `
    <div class="demo-col">
      <poad-progress [value]="build()" label="Build" showValue />
      <poad-progress [value]="82" severity="warning" size="sm" striped ariaLabel="Disk usage" />
      <poad-progress indeterminate ariaLabel="Upload" />
    </div>
    <div class="demo-row">
      <button poadButton severity="secondary" size="sm" (click)="build.set((build() + 10) % 110)">+10 %</button>
      <code>build={{ build() }}</code>
    </div>
  `,
})
export default class ProgressDemo {
  readonly build = signal(40);
}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/progress-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadButton, PoadProgress } from '@poadio/ui-react';

export default function ProgressDemo() {
  const [build, setBuild] = useState(40);
  return (
    <>
      <div className="demo-col">
        <PoadProgress value={build} label="Build" showValue />
        <PoadProgress value={82} severity="warning" size="sm" striped aria-label="Disk usage" />
        <PoadProgress indeterminate aria-label="Upload" />
      </div>
      <div className="demo-row">
        <PoadButton severity="secondary" size="sm" onClick={() => setBuild((b) => (b + 10) % 110)}>+10 %</PoadButton>
        <code>build={build}</code>
      </div>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import ProgressDemo from './progress-demo';

export default function Page() {
  return <ProgressDemo />;
}

<script type="module">
  const build = document.querySelector('#build');
  document.querySelector('#more').addEventListener('click', () => {
    build.value = ((build.value ?? 0) + 10) % 110;
    document.querySelector('#build-out').textContent = `build=${build.value}`;
  });
</script>

À quoi ça sert

Pour une tâche mesurable (téléversement, construction). Pour une attente brève sans mesure, l’indicateur de chargement ; pour une répartition (disque, quota), la jauge.

Clavier

Aucune interaction clavier : composant d’affichage.

Accessibilité

  • role="progressbar" avec aria-valuenow, aria-valuemin, aria-valuemax (valeur brute, même au-delà du maximum).
  • Nommée par son libellé, sinon par aria-label. Indéterminée : aria-valuenow absent.

Vérifié par le banc de conformité — Ces scénarios sont joués, à l’identique, sur chaque rendu déclaré (angular, react, vue, elements) à chaque push :

  • progress/value-bounds-and-indeterminate

Jetons de thème

Jetons --poad-* lus par la feuille @poadio/ui-core/progress.css de @poadio/ui-core. Les redéfinir (globalement ou sur un conteneur) suffit à thémer le composant, dans tous les frameworks à la fois.

--poad-accent --poad-font --poad-success --poad-warning --poad-danger --poad-info --poad-font-size-sm --poad-fg-secondary --poad-font-mono --poad-fg --poad-elevated --poad-ease
