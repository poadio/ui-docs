Info-bulle

Un court texte qui décrit un élément au survol et au focus clavier : délais d’apparition et de disparition, retournement contre le bord de la fenêtre, Échap la cache.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular

Une directive sur l’élément décrit ([poadTooltip]) ; l’info-bulle est rendue dans l’overlay du CDK.

import { Component } from '@angular/core';
import { PoadButtonComponent, PoadTooltipDirective } from '@poadio/ui-angular';

@Component({
  selector: 'app-tooltip-demo',
  imports: [PoadButtonComponent, PoadTooltipDirective],
  template: `
    <div class="demo-row">
      <button poadButton variant="outline" poadTooltip="Restart the pods">Restart</button>
      <button poadButton variant="outline" poadTooltip="Shown below" tooltipPosition="bottom">Below</button>
      <button poadButton variant="outline" poadTooltip="On the end side, after 100 ms" tooltipPosition="right" [tooltipDelay]="100">End</button>
      <button poadButton variant="outline" poadTooltip="Never shown" tooltipDisabled>Disabled</button>
    </div>
  `,
})
export default class TooltipDemo {}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/tooltip-demo.tsx — composant client (état, gestionnaires)
'use client';

import { PoadButton, PoadTooltip } from '@poadio/ui-react';

export default function TooltipDemo() {
  return (
    <div className="demo-row">
      <PoadTooltip content="Restart the pods"><PoadButton variant="outline">Restart</PoadButton></PoadTooltip>
      <PoadTooltip content="Shown below" placement="bottom"><PoadButton variant="outline">Below</PoadButton></PoadTooltip>
      <PoadTooltip content="On the end side, after 100 ms" placement="right" delay={100}><PoadButton variant="outline">End</PoadButton></PoadTooltip>
      <PoadTooltip content="Never shown" disabled><PoadButton variant="outline">Disabled</PoadButton></PoadTooltip>
    </div>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import TooltipDemo from './tooltip-demo';

export default function Page() {
  return <TooltipDemo />;
}

Rendu par Vue

PoadTooltip enveloppe un seul élément (slot par défaut), qui reçoit les écouteurs et aria-describedby ; slot content pour un contenu riche.

<script setup lang="ts">
import { PoadButton, PoadTooltip } from '@poadio/ui-vue';
</script>

<template>
  <div class="demo-row">
    <PoadTooltip content="Restart the pods"><PoadButton variant="outline">Restart</PoadButton></PoadTooltip>
    <PoadTooltip content="Shown below" placement="bottom"><PoadButton variant="outline">Below</PoadButton></PoadTooltip>
    <PoadTooltip content="On the end side, after 100 ms" placement="right" :delay="100"><PoadButton variant="outline">End</PoadButton></PoadTooltip>
    <PoadTooltip content="Never shown" disabled><PoadButton variant="outline">Disabled</PoadButton></PoadTooltip>
  </div>
</template>
Rendu par Vanilla

Le premier élément écrit dans <poad-tooltip> est l’ancre ; le texte est l’attribut text (sur nos éléments, content désigne le contenu écrit dans l’élément).

<script type="module">import '@poadio/ui-elements/define';</script>

<div class="demo-row">
  <poad-tooltip text="Restart the pods"><poad-button variant="outline">Restart</poad-button></poad-tooltip>
  <poad-tooltip text="Shown below" placement="bottom"><poad-button variant="outline">Below</poad-button></poad-tooltip>
  <poad-tooltip text="On the end side, after 100 ms" placement="right" delay="100"><poad-button variant="outline">End</poad-button></poad-tooltip>
  <poad-tooltip text="Never shown" disabled><poad-button variant="outline">Disabled</poad-button></poad-tooltip>
</div>

À quoi ça sert

Pour nommer un bouton d’icône ou préciser une action. Jamais pour une information indispensable : elle n’existe pas au toucher sans survol, ni pour un contenu interactif (préférer un popover).

Clavier

ToucheEffet

ÉchapCache l’info-bulle.

Accessibilité

  • Info-bulle role="tooltip" ; affichée, elle décrit son élément (aria-describedby), qui garde ses propres descriptions.
  • Affichée au focus clavier comme au survol ; Échap la cache sans déplacer le focus.

Vérifié par le banc de conformité — Ces scénarios sont joués, à l’identique, sur chaque rendu déclaré (angular, react, vue, elements) à chaque push :

  • tooltip/hover-focus-escape-flip

Textes du catalogue

Aucun texte de la bibliothèque : tout ce qui s'affiche vient de l'application.

Jetons de thème

Jetons --poad-* lus par la feuille @poadio/ui-core/tooltip.css, @poadio/ui-core/floating.css de @poadio/ui-core. Les redéfinir (globalement ou sur un conteneur) suffit à thémer le composant, dans tous les frameworks à la fois.

--poad-tooltip-bg --poad-tooltip-fg --poad-font --poad-shadow-lg --poad-ease --poad-z-overlay
