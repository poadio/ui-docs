Panneaux de carte

<poad-map-panel>

Un rail d’icônes sur le bord de la carte, qui ouvre et ferme des panneaux accolés, découpés en sections repliables : l’ossature d’une application cartographique, à la souris comme au clavier, jusqu’à 390 px de large.

export default class MapPanelsDemo {
  readonly river = river;
  readonly bridges = bridges;
  readonly center: [number, number] = [4.84, 45.76];
  readonly open = signal('none');
  readonly recentred = signal(0);
  private readonly map = viewChild.required<PoadMapComponent>('map');
  constructor() {
    inject(PoadMapBasemapRegistry).registerAll([
      { id: 'paper', label: 'Paper', kind: 'vector', style: paper(false) },
      { id: 'night', label: 'Night', kind: 'vector', style: paper(true), dark: true },

  closed(id: string): void { if (this.open() === id) this.open.set('none'); }

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

Composants clients, comme la carte : le rail et les panneaux se rendent au serveur fermés, puis prennent vie au montage.

// app/map-panels-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useRef, useState } from 'react';
import { PoadMap, PoadMapLayer, PoadMapLegend, PoadMapPanel, PoadMapRail, PoadMapRailItem, PoadMapSection, poadBasemaps, type PoadMapApi } from '@poadio/ui-react';

  { id: 'paper', label: 'Paper', kind: 'vector', style: paper(false) },
  { id: 'night', label: 'Night', kind: 'vector', style: paper(true), dark: true },
]);
const river = { type: 'Feature', properties: { name: 'River' }, geometry: { type: 'LineString', coordinates: [[4.78, 45.72], [4.81, 45.745], [4.835, 45.755], [4.84, 45.76], [4.86, 45.775], [4.9, 45.79]] } };

const bridges = { type: 'FeatureCollection', features: [bridge('Bridge A', 4.84, 45.76), bridge('Bridge B', 4.81, 45.745), bridge('Bridge C', 4.86, 45.775), bridge('Bridge D', 4.79, 45.73)] };
const center: [number, number] = [4.84, 45.76];
const controls = ['zoom', 'scale'] as const;

export default function MapPanelsDemo() {
  const map = useRef<PoadMapApi>(null);
  const [open, setOpen] = useState('none');
  const [recentred, setRecentred] = useState(0);

  return (
    <>
      <div className="demo-wide">
        <PoadMap apiRef={map} basemap="paper" basemaps={['paper', 'night']} followTheme center={center} zoom={12} height="360px" controls={controls} ariaLabel="Bridges along the river">

          <PoadMapRail bottom="v1.0">
            <PoadMapRailItem icon="layers" label="Layers" panel="layers" />
            <PoadMapRailItem icon="info" label="About" panel="about" />
            <PoadMapRailItem icon="home" label="Recentre" onClick={() => { map.current?.flyTo(center, 12); setRecentred((n) => n + 1); }} />
          </PoadMapRail>
          <PoadMapPanel id="layers" header="Layers" icon="layers" width={280} onOpenChange={track('layers')}>

          </PoadMapPanel>
        </PoadMap>
      </div>
      <code>open={open} recentred={recentred}</code>
    </>
  );
}

À quoi ça sert

Une entrée du rail nomme son panneau (panel) ; sans panneau, c’est une action libre (recentrer, imprimer…). Un seul panneau ouvert par côté ; le rail et le panneau ouvert écartent les contrôles et les coins de la carte, qui restent visibles. Le panneau garde toujours 50 px de carte à côté de lui. Pour une configuration en JSON (rail, panneaux, sections et blocs), le menu de carte ; pour la recherche ou la légende seules, posez-les dans un coin.

Accessibilité

  • Le rail est une barre d’outils verticale nommée (« Panneaux de la carte ») ; chaque entrée est nommée par son libellé, que l’info-bulle répète.
  • Une entrée qui ouvre un panneau dit s’il est ouvert (aria-expanded) et lequel (aria-controls). Le panneau est une région nommée par son titre ; fermé, il sort de l’arbre et du focus (aria-hidden, inert).
  • Échap ou × : le focus n’est jamais perdu, il revient à l’entrée du rail. L’en-tête d’une section est un bouton aria-expanded / aria-controls ; repliée, son contenu est inerte.

/* Toute l’application */
:root {
