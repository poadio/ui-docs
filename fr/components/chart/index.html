<poad-chart>

Barres, courbes, secteurs, radar, nuages de points : Chart.js 4, habillé par le thème (police, grille, infobulle, palette) et accompagné de sa table de données, l’alternative accessible au dessin.

import { PoadChartComponent, PoadSegmentedComponent, type PoadChartClickEvent, type PoadChartType } from '@poadio/ui-angular';

@Component({

  template: `

    <div class="demo-wide">
      <poad-chart [type]="type()" [data]="data" ariaLabel="Readings per month" tableToggle height="260px" (chartClick)="pick($event)" />
    </div>
    <code>last={{ last() }}</code>
  `,
})
export default class ChartDemo {
  readonly types = [{ label: 'Bars', value: 'bar' }, { label: 'Lines', value: 'line' }, { label: 'Doughnut', value: 'doughnut' }];
  readonly type = signal<PoadChartType>('bar');
  readonly data = {
    labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'],
    datasets: [{ label: 'Inspections', data: [12, 19, 8, 15, 11, 17] }, { label: 'Alerts', data: [3, 5, 2, 6, 4, 3] }],
  };
  readonly last = signal('—');
  pick(e: PoadChartClickEvent): void { this.last.set(`${e.label} ${e.value}`); }
}

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

Composant client ('use client') : Chart.js n’est importé qu’au montage, le rendu serveur ne produit que la table et le canevas vide.

// app/chart-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadChart, PoadSegmented, type PoadChartType } from '@poadio/ui-react';

const types = [{ label: 'Bars', value: 'bar' }, { label: 'Lines', value: 'line' }, { label: 'Doughnut', value: 'doughnut' }];
const data = {
  labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'],
  datasets: [{ label: 'Inspections', data: [12, 19, 8, 15, 11, 17] }, { label: 'Alerts', data: [3, 5, 2, 6, 4, 3] }],
};

export default function ChartDemo() {
  const [type, setType] = useState<PoadChartType>('bar');
  const [last, setLast] = useState('—');
  return (
    <>
      <PoadSegmented options={types} value={type} onValueChange={(v) => setType(v as PoadChartType)} size="sm" aria-label="Chart type" />
      <div className="demo-wide">
        <PoadChart type={type} data={data} ariaLabel="Readings per month" tableToggle height="260px" onChartClick={(e) => setLast(`${e.label} ${e.value}`)} />
      </div>
      <code>last={last}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import ChartDemo from './chart-demo';

export default function Page() {
  return <ChartDemo />;
}

À quoi ça sert

chart.js est une dépendance FACULTATIVE : npm i chart.js ; il n’est chargé qu’au montage du premier graphique (jamais au rendu serveur), et s’il manque, le composant dit quel paquet installer au lieu de casser la page. Les données ont la forme de Chart.js (labels, datasets) ; les options passées sont fusionnées par-dessus le thème. Pour un seul chiffre, une jauge (meter) ou une étiquette suffisent.

Clavier

ToucheEffet
TabAtteint le bouton « Afficher le tableau des données » (tableToggle). Le canevas, lui, n’est pas focalisable : la table porte les valeurs.
Entrée EspaceSur le bouton : montre la table de données à la place du dessin, puis revient au graphique.

Accessibilité

  • Canevas role="img" nommé par ariaLabel : un lecteur d’écran annonce ce que le graphique représente.
  • Table de données TOUJOURS dans le DOM (accessibleTable, actif par défaut) : légende = le nom du graphique, une colonne par libellé (th scope="col"), une ligne par série (th scope="row"), nombres dans la langue. Masquée visuellement, elle reste lue par les technologies d’assistance ; showTable ou le bouton (tableToggle) la montrent à la place du canevas, pour tous.
  • Couleurs relues sur les jetons quand la page change de thème (clair / sombre) ; palette par défaut contrastée sur les deux fonds.

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius-sm: 2px;         /* Petit arrondi : options d’une liste, petits éléments */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius-sm: 0;           /* Petit arrondi : options d’une liste, petits éléments */
}
