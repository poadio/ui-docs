Filtre de touches

Empêche certaines frappes dans un champ libre : chiffres seuls, hexadécimal, lettres… Le texte reste libre en longueur et en forme, seuls les caractères sont filtrés ; un collage est nettoyé.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular

Avec un formulaire, la directive valide aussi la valeur entière (erreur keyfilter).

import { Component } from '@angular/core';
import { PoadFieldComponent, PoadInputDirective, PoadKeyFilterDirective } from '@poadio/ui-angular';

@Component({
  selector: 'app-key-filter-demo',
  imports: [PoadFieldComponent, PoadInputDirective, PoadKeyFilterDirective],
  template: `
    <div class="demo-col">
      <poad-field label="Quantity" hint="Integers only (int)">
        <input poadInput poadKeyFilter="int" />
      </poad-field>
      <poad-field label="Colour" hint="Hexadecimal (hex)">
        <input poadInput poadKeyFilter="hex" mono />
      </poad-field>
      <poad-field label="Code" hint="Letters and digits (alphanum)">
        <input poadInput poadKeyFilter="alphanum" />
      </poad-field>
    </div>
  `,
})
export default class KeyFilterDemo {}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/key-filter-demo.tsx — composant client (état, gestionnaires)
'use client';

import { PoadField, PoadInput, usePoadKeyFilter } from '@poadio/ui-react';

export default function KeyFilterDemo() {
  const int = usePoadKeyFilter('int');
  const hex = usePoadKeyFilter('hex');
  const code = usePoadKeyFilter('alphanum');
  return (
    <div className="demo-col">
      <PoadField label="Quantity" hint="Integers only (int)">
        <PoadInput {...int.inputProps} />
      </PoadField>
      <PoadField label="Colour" hint="Hexadecimal (hex)">
        <PoadInput {...hex.inputProps} mono />
      </PoadField>
      <PoadField label="Code" hint="Letters and digits (alphanum)">
        <PoadInput {...code.inputProps} />
      </PoadField>
    </div>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import KeyFilterDemo from './key-filter-demo';

export default function Page() {
  return <KeyFilterDemo />;
}

À quoi ça sert

Quand la valeur n’a pas de format fixe (sinon : masque de saisie). Ce n’est pas une validation : vérifier aussi la valeur à l’envoi (validateOnly + valid()).

Clavier

Aucune interaction clavier : composant d’affichage.

Accessibilité

  • Le champ reste natif (nom, aide, formulaire inchangés) ; une frappe refusée est simplement empêchée.
  • Annoncer la règle dans l’aide du champ : rien d’autre ne dit à l’utilisateur pourquoi sa touche n’a pas d’effet.
