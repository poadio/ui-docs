Remonter en haut

<poad-scroll-top>

Un bouton rond, fixé en bas de l’écran, qui paraît quand la page (ou une zone) a défilé au-delà d’un seuil et la ramène en haut d’un clic.

Disponible en····

Démonstration

Angularrendu par @poadio/ui-angularNext.jsrendu par @poadio/ui-reactReactrendu par @poadio/ui-reactVuerendu par @poadio/ui-vueVanillarendu par @poadio/ui-elements

Votre réglage : :root { }

Réglage en direct, dans la démo seulement : rien n’est enregistré.

Chargement de la démo…

La démo ne s’est pas chargée. Une nouvelle version du site vient peut-être d’être publiée.

[target] reçoit l’élément qui défile (référence de gabarit #box), lu au premier rendu.

import { Component } from '@angular/core';
import { PoadScrollTopComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-scroll-top-demo',
  imports: [PoadScrollTopComponent],
  template: `
    <div #box class="demo-scroller" tabindex="0" aria-label="Release notes">
      @for (n of notes; track n) {<p>Release {{ n }} — fixes and improvements.</p>}
    </div>
    <poad-scroll-top [target]="box" [threshold]="100" />
  `,
})
export default class ScrollTopDemo {
  readonly notes = Array.from({ length: 30 }, (_, i) => `1.${30 - i}`);
}

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/scroll-top-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useRef } from 'react';
import { PoadScrollTop } from '@poadio/ui-react';

const notes = Array.from({ length: 30 }, (_, i) => `1.${30 - i}`);

export default function ScrollTopDemo() {
  const box = useRef<HTMLDivElement>(null);
  return (
    <>
      <div ref={box} className="demo-scroller" tabIndex={0} aria-label="Release notes">
        {notes.map((n) => <p key={n}>Release {n} — fixes and improvements.</p>)}
      </div>
      <PoadScrollTop target={() => box.current} threshold={100} />
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import ScrollTopDemo from './scroll-top-demo';

export default function Page() {
  return <ScrollTopDemo />;
}

À quoi ça sert

Pour une longue page ou une longue liste qu’on parcourt de haut en bas. Inutile sur une page courte.

Accessibilité

  • Un vrai <button>, nommé par le catalogue (« Remonter en haut ») ou aria-label.
  • Caché sous le seuil : transparent, sans pointeur et hors de la tabulation (tabindex="-1").
  • Défilement doux, immédiat sous prefers-reduced-motion ; fondu coupé aussi.

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}
