Éditeur de blocs

<poad-block-editor>

Un éditeur par blocs à la Notion sur Editor.js — menu « / », titres, paragraphes, listes (à puces, numérotées, de cases), code, encadrés, séparateurs, vidéos YouTube, images et liens choisis par l’application — dont la valeur est le JSON Editor.js.

À quoi ça sert

Pour rédiger un document fait de blocs (documentation, rapport illustré) ; l’affichage de blocs le relit. Editor.js et ses extensions sont des dépendances FACULTATIVES (npm i @editorjs/editorjs @editorjs/header @editorjs/underline @editorjs/delimiter @editorjs/list @calumk/editorjs-codecup editorjs-alert), chargées au montage du premier éditeur (jamais au rendu serveur), une fois pour la page, depuis le paquet de l’application — jamais un CDN ; absentes, l’éditeur dit lequel installer ; sans @editorjs/list seul, il fonctionne sans proposer de liste. Les outils de la bibliothèque (alignement, YouTube, image, lien) et le dictionnaire de l’interface viennent du catalogue de messages. Pour un texte court mis en forme, préférer le texte riche.

Accessibilité

  • Zone role="group" nommée par ariaLabel (ou « Éditeur de blocs »), consigne clavier (« / », Ctrl+/, Tab) liée par aria-describedby. Chargement annoncé, échec en role="alert" avec « Réessayer ».
  • Outils de la bibliothèque : boutons et champs nommés (légende, adresse YouTube, recadrer, changer d’image), poignée de largeur au clavier, icônes aria-hidden.
  • Limites d’Editor.js, honnêtement : les blocs sont des zones éditables sans nom propre ni rôle ; les boutons « + » et la poignée ⋮⋮ ne sont pas dans l’ordre de tabulation (« / » et Ctrl+/ les remplacent) ; le glisser-déposer des blocs n’existe qu’à la souris (Monter / Descendre au clavier) ; l’ouverture des menus n’est pas annoncée par les lecteurs d’écran.

À quoi ça sert

Pour afficher ce que l’éditeur de blocs a produit (page de documentation, rapport, fiche) : aucune dépendance, le JSON { time, blocks, version } suffit, rendu serveur compris. Les titres reçoivent des ancres uniques et le composant émet le sommaire (toc). Un type de bloc propre à l’application s’affiche par un gabarit (Angular poadBlockTemplate, React et composants web renderBlock, Vue emplacement block-<type>). Sécurité : chaque bloc passe par le modèle de rendu d’ui-core — le texte en ligne est relu par les règles du texte riche (marques b i u s code mark, lien au href sûr, rien d’autre), une image n’est affichée que si son adresse est sûre, une vidéo que si c’est YouTube (adresse reconstruite), le code reste du texte, la coloration fournie par l’application (highlight) est nettoyée.

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius: 4px;            /* Arrondi des coins des contrôles */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius: 0;              /* Arrondi des coins des contrôles */
}
