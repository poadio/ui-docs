Jauge

Montre une mesure dans des bornes connues, découpée en segments : espace disque, quota, budget consommé.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular
import { Component } from '@angular/core';
import { PoadMeterComponent, type PoadMeterValue } from '@poadio/ui-angular';

@Component({
  selector: 'app-meter-demo',
  imports: [PoadMeterComponent],
  template: `
    <div class="demo-col" style="width: min(100%, 480px)">
      <poad-meter [values]="disk" unit="Gi" showRemaining ariaLabel="Disk" />
      <poad-meter [values]="[{ label: 'CPU', value: 72, severity: 'warning' }]" unit="%" size="sm" ariaLabel="CPU" />
    </div>
  `,
})
export default class MeterDemo {
  readonly disk: PoadMeterValue[] = [
    { label: 'Database', value: 42, severity: 'primary' },
    { label: 'Storage', value: 18.5, severity: 'info' },
    { label: 'Logs', value: 6, severity: 'warning' },
  ];
}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/meter-demo.tsx — composant client (état, gestionnaires)
'use client';

import { PoadMeter } from '@poadio/ui-react';

const disk = [
  { label: 'Database', value: 42, severity: 'primary' as const },
  { label: 'Storage', value: 18.5, severity: 'info' as const },
  { label: 'Logs', value: 6, severity: 'warning' as const },
];

export default function MeterDemo() {
  return (
    <div className="demo-col" style={{ width: 'min(100%, 480px)' }}>
      <PoadMeter values={disk} unit="Gi" showRemaining aria-label="Disk" />
      <PoadMeter values={[{ label: 'CPU', value: 72, severity: 'warning' }]} unit="%" size="sm" aria-label="CPU" />
    </div>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import MeterDemo from './meter-demo';

export default function Page() {
  return <MeterDemo />;
}

À quoi ça sert

Pour une quantité, pas pour une tâche qui avance (préférer la barre de progression). La légende met les nombres en forme dans la langue courante ; le « reste » vient du catalogue.

Clavier

Aucune interaction clavier : composant d’affichage.

Accessibilité

  • role="meter" avec aria-valuenow (total des segments), aria-valuemin, aria-valuemax, nommé par aria-label.
  • Chaque segment a un titre complet (« Used: 62 Gi (62%) ») ; la légende répète valeur et pourcentage en texte.
