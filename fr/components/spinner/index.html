Indicateur de chargement

Un cercle qui tourne pendant une attente courte et non mesurable ; annoncé « Chargement » par le catalogue.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular
import { Component } from '@angular/core';
import { PoadSpinnerComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-spinner-demo',
  imports: [PoadSpinnerComponent],
  template: `
    <div class="demo-row">
      <poad-spinner />
      <poad-spinner [size]="32" severity="success" ariaLabel="Saving" />
      <poad-spinner [size]="16" [strokeWidth]="2" severity="secondary" />
      <span class="demo-row" style="color: var(--poad-danger)">
        <poad-spinner [size]="18" severity="inherit" /> Deleting…
      </span>
    </div>
  `,
})
export default class SpinnerDemo {}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/spinner-demo.tsx — composant client (état, gestionnaires)
'use client';

import { PoadSpinner } from '@poadio/ui-react';

export default function SpinnerDemo() {
  return (
    <div className="demo-row">
      <PoadSpinner />
      <PoadSpinner size={32} severity="success" aria-label="Saving" />
      <PoadSpinner size={16} strokeWidth={2} severity="secondary" />
      <span className="demo-row" style={{ color: 'var(--poad-danger)' }}>
        <PoadSpinner size={18} severity="inherit" /> Deleting…
      </span>
    </div>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import SpinnerDemo from './spinner-demo';

export default function Page() {
  return <SpinnerDemo />;
}

À quoi ça sert

Dans un bouton, une cellule, une zone qui se recharge. Pour une tâche mesurable, la barre de progression ; pour la forme d’un contenu à venir, le squelette.

Clavier

Aucune interaction clavier : composant d’affichage.

Accessibilité

  • role="status", nommé « Chargement » par le catalogue (dans la langue de l’application), ou par aria-label.
  • Mouvement réduit : la rotation ralentit quand le système le demande (progress.css).

Vérifié par le banc de conformité — Ces scénarios sont joués, à l’identique, sur chaque rendu déclaré (angular, react, vue, elements) à chaque push :

Jetons de thème

Jetons --poad-* lus par la feuille @poadio/ui-core/progress.css de @poadio/ui-core. Les redéfinir (globalement ou sur un conteneur) suffit à thémer le composant, dans tous les frameworks à la fois.
