Tableau de tâches

<poad-taskboard>

Un tableau en colonnes (kanban) : les tâches d’un document de planification rangées par colonne et par rang, déplacées à la souris, au doigt ou au clavier, avec une limite de travail en cours qui alerte sans bloquer. Sur un téléphone, il devient une liste groupée.

    { id: 't4', label: 'Traffic count', bucket: 'doing', rank: 'd', progress: 0.7, tags: ['data'], assignments: [{ resource: 'ana' }] },

@Component({
  selector: 'app-taskboard-demo',
  imports: [PoadTaskboardComponent],
  template: `
    <poad-taskboard class="demo-taskboard" [plan]="plan()" ariaLabel="Project tasks" (taskMove)="onMove($event)" />
    <code>{{ last() }}</code>
  `,
})
export default class TaskboardDemo {
  readonly plan = signal(PLAN);
  readonly last = signal('moved=—');
  /** The board never writes: the application applies the move to its own document. */
  onMove(e: PoadTaskMoveEvent): void {
    this.plan.update((p) => ({ ...p, tasks: p.tasks!.map((t) => (t.id === e.id ? { ...t, bucket: e.to, rank: e.rank } : t)) }));
    this.last.set(`moved=${e.task.label} → ${e.to}`);
  }
}

À quoi ça sert

Pour suivre l’avancement d’un lot de tâches par étapes (à faire, en cours, fait) ou par personne (liste groupée par personne : le même geste réaffecte). Le tableau n’écrit jamais : il émet l’intention (colonne et nouveau rang) et garde l’affichage à jour le temps que l’application l’applique ou la refuse. Pour des tâches datées, le Gantt ou le planificateur.

Clavier

ToucheEffet
TabPasse d’une carte à l’autre (chaque carte est dans l’ordre de tabulation).
Entrée EspaceOuvre la tâche (évènement taskOpen).
Ctrl ← →Ctrl (⌘ sur Mac) + ← / → : passe la tâche dans la colonne précédente / suivante, à la même hauteur (inversées de droite à gauche). En liste, vers le groupe précédent / suivant.
Ctrl ↑ ↓Ctrl (⌘) + ↑ / ↓ : monte / descend la tâche d’une place dans sa colonne. Le focus suit la carte.
ÉchapPendant un glisser à la souris ou au doigt : annule, la carte reste où elle était.

Accessibilité

  • Chaque carte est un role="button" décrit par l’aide clavier (aria-describedby) ; chaque colonne est un role="group" nommé par son titre.
  • Chaque déplacement est annoncé dans une région aria-live : OÙ et À QUELLE PLACE (« Survey report — moved to Doing, position 2 of 3. »), pas seulement « déplacé ».
  • Glisser à la souris : la carte saisie reste en place, estompée, un aperçu flottant suit le pointeur et un trait montre où elle tombera. Au doigt, un appui long saisit la carte ; un glissement court fait défiler la page comme d’habitude.
  • La limite de travail en cours se lit dans le compte (2/3) et sa couleur (atteinte, dépassée) ; elle ne bloque jamais un geste. Une tâche dont la colonne n’existe pas rejoint la première, marquée, jamais escamotée.

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius: 4px;            /* Arrondi des coins des contrôles */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius: 0;              /* Arrondi des coins des contrôles */
}
