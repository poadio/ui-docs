Pastille

Un petit compteur ou un point d’état, à poser à côté d’un libellé ou d’une icône : notifications, éléments en attente.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular

Angular a aussi la directive [poadBadge], qui pose la pastille sur un autre élément : elle n’est pas encore portée sur les autres frameworks.

import { Component, signal } from '@angular/core';
import { PoadBadgeComponent, PoadButtonComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-badge-demo',
  imports: [PoadBadgeComponent, PoadButtonComponent],
  template: `
    <div class="demo-row">
      <poad-badge [value]="count()" />
      <poad-badge [value]="120" />
      <poad-badge [value]="120" [max]="999" severity="info" />
      <poad-badge value="new" severity="success" />
      <poad-badge [value]="7" severity="neutral" size="sm" />
      <poad-badge dot severity="success" ariaLabel="Online" />
      <button poadButton size="sm" severity="secondary" (click)="count.set(count() + 1)">+1</button>
    </div>
  `,
})
export default class BadgeDemo {
  readonly count = signal(3);
}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

PoadBadge n’a pas d’état : il se rend aussi dans un composant serveur.

// app/badge-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadBadge, PoadButton } from '@poadio/ui-react';

export default function BadgeDemo() {
  const [count, setCount] = useState(3);
  return (
    <div className="demo-row">
      <PoadBadge value={count} />
      <PoadBadge value={120} />
      <PoadBadge value={120} max={999} severity="info" />
      <PoadBadge value="new" severity="success" />
      <PoadBadge value={7} severity="neutral" size="sm" />
      <PoadBadge dot severity="success" aria-label="Online" />
      <PoadButton size="sm" severity="secondary" onClick={() => setCount(count + 1)}>+1</PoadButton>
    </div>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import BadgeDemo from './badge-demo';

export default function Page() {
  return <BadgeDemo />;
}

À quoi ça sert

Au-delà de max (99 par défaut), la valeur est plafonnée (99+). Un point (dot) n’affiche rien : donnez-lui un nom accessible s’il porte une information.

Options principales

Clavier

Aucune interaction clavier : composant d’affichage.

Accessibilité

  • Le texte affiché est la valeur plafonnée (99+) : c’est elle qu’un lecteur d’écran lit.
  • Sans aria-label, aucun attribut aria-label n’est posé ; avec, la pastille est nommée par lui.
  • La couleur seule ne porte pas l’information : doublez-la d’un texte ou d’un nom.

Vérifié par le banc de conformité — Ces scénarios sont joués, à l’identique, sur chaque rendu déclaré (angular, react, vue, elements) à chaque push :

  • badge/capped-text-dot-and-name

Attributs vérifiés : aria-label

Textes du catalogue

Aucun texte de la bibliothèque : tout ce qui s'affiche vient de l'application.

Jetons de thème

Jetons --poad-* lus par la feuille @poadio/ui-core/badge.css de @poadio/ui-core. Les redéfinir (globalement ou sur un conteneur) suffit à thémer le composant, dans tous les frameworks à la fois.

--poad-danger --poad-radius-pill --poad-font-mono --poad-accent --poad-success --poad-warning --poad-info --poad-fg-secondary
