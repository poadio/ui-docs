Message

<poad-message>

Un message dans la page — information, succès, avertissement, erreur — avec l’icône de sa sévérité et, au besoin, un bouton de fermeture.

Angularrendu par @poadio/ui-angularNext.jsrendu par @poadio/ui-reactReactrendu par @poadio/ui-reactVuerendu par @poadio/ui-vueVanillarendu par @poadio/ui-elements

import { Component, signal } from '@angular/core';
import { PoadMessageComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-message-demo',
  imports: [PoadMessageComponent],
  template: `
    <div class="demo-col">
      <poad-message severity="info" text="A new version is available." />
      <poad-message severity="success" closable [(open)]="saved" (closed)="closed.set(closed() + 1)">Changes saved.</poad-message>
      <poad-message severity="warning" variant="outline">The certificate expires in 6 days.</poad-message>
      <poad-message severity="danger" size="sm" icon="" text="Connection lost (no icon)." />
    </div>
    <code>closed={{ closed() }} · open={{ saved() }}</code>
  `,
})
export default class MessageDemo {
  readonly closed = signal(0);
  readonly saved = signal(true);
}

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/message-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadMessage } from '@poadio/ui-react';

export default function MessageDemo() {
  const [closed, setClosed] = useState(0);
  return (
    <>
      <div className="demo-col">
        <PoadMessage severity="info" text="A new version is available." />
        <PoadMessage severity="success" closable onClose={() => setClosed((n) => n + 1)}>Changes saved.</PoadMessage>
        <PoadMessage severity="warning" variant="outline">The certificate expires in 6 days.</PoadMessage>
        <PoadMessage severity="danger" size="sm" icon="" text="Connection lost (no icon)." />
      </div>
      <code>closed={closed}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import MessageDemo from './message-demo';

export default function Page() {
  return <MessageDemo />;
}

À quoi ça sert

Pour un état qui reste à l’écran tant qu’il est vrai (un quota atteint, un certificat qui expire). Pour une confirmation passagère, une notification.

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-danger: #c62828;        /* Danger : erreur, champ invalide, action destructrice */
  --poad-radius: 4px;            /* Arrondi des coins des contrôles */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-danger: #ff6b6b;        /* Danger : erreur, champ invalide, action destructrice */
}

/* Une zone seulement */
.checkout {
  --poad-radius: 0;              /* Arrondi des coins des contrôles */
}

import { Component, inject, signal } from '@angular/core';
import { PoadButtonComponent, PoadToastComponent, PoadToastService } from '@poadio/ui-angular';

@Component({
  selector: 'app-toast-demo',
  imports: [PoadButtonComponent, PoadToastComponent],
  template: `
    <div class="demo-row">
      <button poadButton (click)="deployed()">Notify</button>
      <button poadButton severity="danger" variant="outline" (click)="failed()">Fail</button>
    </div>
    <code>sent={{ sent() }}</code>
    <!-- once in the application -->
    <poad-toast position="top-right" showProgress />
  `,
})
export default class ToastDemo {
  private readonly toast = inject(PoadToastService);
  readonly sent = signal(0);

  deployed(): void {
    this.toast.success('Deployed', 'api v1.4 is live');
    this.sent.update((n) => n + 1);
  }
  failed(): void {
    this.toast.error('Build failed', 'Step “test” exited with code 1');
    this.sent.update((n) => n + 1);
  }
}

}

.checkout {
