Groupe de boutons

Rassemble des boutons liés, accolés ou en pilule. Sélectionnable, il devient un choix unique ou multiple : les boutons qui portent une value s’enfoncent selon la valeur du groupe.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular
import { Component, signal } from '@angular/core';
import { PoadButtonComponent, PoadButtonGroupComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-button-group-demo',
  imports: [PoadButtonGroupComponent, PoadButtonComponent],
  template: `
    <poad-button-group selectable="single" [(value)]="range" ariaLabel="Range">
      <button poadButton value="day">Day</button>
      <button poadButton value="week">Week</button>
      <button poadButton value="month">Month</button>
    </poad-button-group>
    <poad-button-group selectable="multiple" [(value)]="styles" look="attached" size="sm" ariaLabel="Text style">
      <button poadButton value="bold">Bold</button>
      <button poadButton value="italic">Italic</button>
      <button poadButton value="underline">Underline</button>
    </poad-button-group>
    <poad-button-group look="attached" ariaLabel="History">
      <button poadButton severity="secondary">Undo</button>
      <button poadButton severity="secondary">Redo</button>
    </poad-button-group>
    <code>range={{ range() }} · styles={{ styles() }}</code>
  `,
})
export default class ButtonGroupDemo {
  readonly range = signal<unknown>('week');
  readonly styles = signal<unknown>(['bold']);
}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/button-group-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadButton, PoadButtonGroup } from '@poadio/ui-react';

export default function ButtonGroupDemo() {
  const [range, setRange] = useState<unknown>('week');
  const [styles, setStyles] = useState<unknown>(['bold']);
  return (
    <>
      <PoadButtonGroup selectable="single" value={range} onValueChange={setRange} aria-label="Range">
        <PoadButton value="day">Day</PoadButton>
        <PoadButton value="week">Week</PoadButton>
        <PoadButton value="month">Month</PoadButton>
      </PoadButtonGroup>
      <PoadButtonGroup selectable="multiple" value={styles} onValueChange={setStyles} look="attached" size="sm" aria-label="Text style">
        <PoadButton value="bold">Bold</PoadButton>
        <PoadButton value="italic">Italic</PoadButton>
        <PoadButton value="underline">Underline</PoadButton>
      </PoadButtonGroup>
      <PoadButtonGroup look="attached" aria-label="History">
        <PoadButton severity="secondary">Undo</PoadButton>
        <PoadButton severity="secondary">Redo</PoadButton>
      </PoadButtonGroup>
      <code>range={String(range)} · styles={String(styles)}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import ButtonGroupDemo from './button-group-demo';

export default function Page() {
  return <ButtonGroupDemo />;
}

<code id="group-out">range=week · styles=bold</code>

<script type="module">
  const range = document.querySelector('#range');
  const styles = document.querySelector('#styles');
  const show = () => {
    document.querySelector('#group-out').textContent = `range=${range.value} · styles=${styles.value}`;
  };
  range.addEventListener('change', show);
  styles.addEventListener('change', show);
</script>

À quoi ça sert

Pour des actions voisines (annuler / rétablir) ou un petit choix visuel (période, style de texte). Pour un choix exclusif de valeurs, le choix segmenté offre en plus la navigation aux flèches.

Accessibilité

  • Racine role="group", nommée par aria-label.
  • Sélectionnable : chaque option porte aria-pressed (et la classe is-pressed) selon la valeur du groupe ; non sélectionnable, aucun aria-pressed.

Vérifié par le banc de conformité — Ces scénarios sont joués, à l’identique, sur chaque rendu déclaré (angular, react, vue, elements) à chaque push :

  • button-group/selectable-single-and-multiple

Attributs vérifiés : role accessible name aria-pressed

Textes du catalogue

Aucun texte de la bibliothèque : tout ce qui s'affiche vient de l'application.

Jetons de thème

Jetons --poad-* lus par la feuille @poadio/ui-core/button-group.css, @poadio/ui-core/button.css de @poadio/ui-core. Les redéfinir (globalement ou sur un conteneur) suffit à thémer le composant, dans tous les frameworks à la fois.
