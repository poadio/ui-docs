Popover

Un panneau flottant ancré sur une cible, pour un contenu interactif court (filtres, réglages) : retourné contre le bord de la fenêtre, fermé par un appui extérieur ou Échap, focus piégé en option, feuille basse sur petit écran.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular

Le panneau est rendu dans l’overlay du CDK ; la cible est passée à toggle($event) ou open(cible).

import { Component, signal } from '@angular/core';
import { PoadButtonComponent, PoadPopoverComponent, PoadSwitchComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-popover-demo',
  imports: [PoadButtonComponent, PoadPopoverComponent, PoadSwitchComponent],
  template: `
    <div class="demo-row">
      <button poadButton variant="outline" (click)="filters.toggle($event)">Filters</button>
      <poad-popover #filters align="start" focusTrap mobile="sheet" sheetTitle="Filters" (opened)="open.set(true)" (closed)="open.set(false)">
        <div style="display: grid; gap: 8px; padding: 12px">
          <poad-switch [(value)]="running" label="Running only" />
          <poad-switch [(value)]="mine" label="Mine" />
        </div>
      </poad-popover>
    </div>
    <code>open={{ open() }} · running={{ running() }} · mine={{ mine() }}</code>
  `,
})
export default class PopoverDemo {
  readonly open = signal(false);
  readonly running = signal(true);
  readonly mine = signal(false);
}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/popover-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadButton, PoadPopover, PoadSwitch } from '@poadio/ui-react';

export default function PopoverDemo() {
  const [open, setOpen] = useState(false);
  const [running, setRunning] = useState(true);
  const [mine, setMine] = useState(false);
  return (
    <>
      <div className="demo-row">
        <PoadPopover
          trigger={<PoadButton variant="outline">Filters</PoadButton>} align="start" focusTrap mobile="sheet" sheetTitle="Filters"
          open={open} onOpenChange={setOpen}
        >
          <div style={{ display: 'grid', gap: 8, padding: 12 }}>
            <PoadSwitch label="Running only" checked={running} onCheckedChange={setRunning} />
            <PoadSwitch label="Mine" checked={mine} onCheckedChange={setMine} />
          </div>
        </PoadPopover>
      </div>
      <code>open={String(open)} · running={String(running)} · mine={String(mine)}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import PopoverDemo from './popover-demo';

export default function Page() {
  return <PopoverDemo />;
}

Rendu par Vanilla

L’enfant slot="trigger" est la cible ; les autres enfants sont posés dans le panneau à l’ouverture (fermé, ils restent dans l’élément, cachés).

<script type="module">import '@poadio/ui-elements/define';</script>

<div class="demo-row">
  <poad-popover id="filters" align="start" focus-trap mobile="sheet" sheet-title="Filters">
    <poad-button slot="trigger" variant="outline">Filters</poad-button>
    <div style="display: grid; gap: 8px; padding: 12px">
      <poad-switch id="running" label="Running only" checked></poad-switch>
      <poad-switch id="mine" label="Mine"></poad-switch>
    </div>
  </poad-popover>
</div>
<code id="popover-out">open=false · running=true · mine=false</code>

<script type="module">
  const filters = document.querySelector('#filters');
  const running = document.querySelector('#running');
  const mine = document.querySelector('#mine');
  const show = () => {
    document.querySelector('#popover-out').textContent = `open=${!!filters.open} · running=${running.checked} · mine=${!!mine.checked}`;
  };
  filters.addEventListener('openchange', show);
  filters.addEventListener('change', show);
</script>

À quoi ça sert

Pour quelques contrôles liés à un bouton. Pour une simple description, une info-bulle ; pour une tâche qui bloque la page, une boîte de dialogue.

Clavier

ToucheEffet
Entrée EspaceSur la cible : ouvre ou ferme.
TabAvec focusTrap : tourne dans le panneau.
ÉchapFerme ; avec focusTrap, le focus revient à la cible.

Accessibilité

  • Cible : aria-haspopup="dialog", aria-expanded, et aria-controls vers le panneau ouvert.
  • Panneau role="dialog" ; avec focusTrap, aria-modal="true" et focus piégé.

Vérifié par le banc de conformité — Ces scénarios sont joués, à l’identique, sur chaque rendu déclaré (angular, react, vue, elements) à chaque push :

  • popover/focus-trap-dismiss-flip

Attributs vérifiés : role aria-modal aria-haspopup aria-expanded aria-controls

Jetons de thème

Jetons --poad-* lus par la feuille @poadio/ui-core/popover.css, @poadio/ui-core/floating.css, @poadio/ui-core/sheet.css de @poadio/ui-core. Les redéfinir (globalement ou sur un conteneur) suffit à thémer le composant, dans tous les frameworks à la fois.
