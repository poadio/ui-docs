Sélecteur de couleur

<poad-colorpicker>

Choisit une couleur : zone saturation / luminosité, teinte et opacité au pointeur ou au clavier, champs HEX et RVB, palette, pipette du navigateur. Valeur en texte CSS.

Angularrendu par @poadio/ui-angularNext.jsrendu par @poadio/ui-reactReactrendu par @poadio/ui-reactVuerendu par @poadio/ui-vueVanillarendu par @poadio/ui-elements

Votre réglage : :root { }

Réglage en direct, dans la démo seulement : rien n’est enregistré.

import { Component, signal } from '@angular/core';
import { PoadColorpickerComponent } from '@poadio/ui-angular';

@Component({

  template: `

      <poad-colorpicker [(value)]="overlay" format="rgb" alpha ariaLabel="Overlay" style="width: 240px" />
      <poad-colorpicker [value]="'#16a34a'" ariaLabel="Disabled" disabled style="width: 200px" />

  `,
})
export default class ColorpickerDemo {
  readonly accent = signal<string | null>('#2f6feb');
  readonly overlay = signal<string | null>('rgba(15, 23, 42, 0.6)');
}

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/colorpicker-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadColorpicker } from '@poadio/ui-react';

export default function ColorpickerDemo() {
  const [accent, setAccent] = useState<string | null>('#2f6feb');
  const [overlay, setOverlay] = useState<string | null>('rgba(15, 23, 42, 0.6)');
  return (
    <>
      <div className="demo-row">
        <PoadColorpicker value={accent} onChange={setAccent} aria-label="Accent" clearable style={{ width: 200 }} />
        <PoadColorpicker value={overlay} onChange={setOverlay} format="rgb" alpha aria-label="Overlay" style={{ width: 240 }} />
        <PoadColorpicker defaultValue="#16a34a" aria-label="Disabled" disabled style={{ width: 200 }} />
      </div>
      <code>accent={String(accent)} · overlay={String(overlay)}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import ColorpickerDemo from './colorpicker-demo';

export default function Page() {
  return <ColorpickerDemo />;
}

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius: 4px;            /* Arrondi des coins des contrôles */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius: 0;              /* Arrondi des coins des contrôles */
}

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-fg: #0f172a;            /* Texte principal */
  --poad-font-size: 0.875rem;    /* Taille de texte de base */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-fg: #f8fafc;            /* Texte principal */
}

/* Une zone seulement */
.checkout {
  --poad-font-size: 1rem;        /* Taille de texte de base */
}
