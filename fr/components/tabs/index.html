Onglets

<poad-tabs>

Plusieurs panneaux au même endroit, un seul visible : une barre d’onglets avec un seul arrêt de tabulation, les flèches dans le sens de lecture, des panneaux rendus à la demande.

Angularrendu par @poadio/ui-angularNext.jsrendu par @poadio/ui-reactReactrendu par @poadio/ui-reactVuerendu par @poadio/ui-vueVanillarendu par @poadio/ui-elements

Votre réglage : :root { }

Réglage en direct, dans la démo seulement : rien n’est enregistré.

Chargement de la démo…

La démo ne s’est pas chargée. Une nouvelle version du site vient peut-être d’être publiée.

import { Component, signal } from '@angular/core';
import { PoadTabComponent, PoadTabsComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-tabs-demo',
  imports: [PoadTabsComponent, PoadTabComponent],
  template: `
    <poad-tabs [(value)]="tab">
      <poad-tab value="res" label="Resources" [count]="12" icon="database"><p>12 resources in this project.</p></poad-tab>
      <poad-tab value="logs" label="Logs"><p>No new logs.</p></poad-tab>
      <poad-tab value="settings" label="Settings" disabled><p>Settings.</p></poad-tab>
    </poad-tabs>
    <code>tab={{ tab() }}</code>
  `,
})
export default class TabsDemo {
  readonly tab = signal<unknown>('res');
}

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/tabs-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadTab, PoadTabs } from '@poadio/ui-react';

export default function TabsDemo() {
  const [tab, setTab] = useState<unknown>('res');
  return (
    <>
      <PoadTabs value={tab} onValueChange={setTab}>
        <PoadTab value="res" label="Resources" count={12} icon="database"><p>12 resources in this project.</p></PoadTab>
        <PoadTab value="logs" label="Logs"><p>No new logs.</p></PoadTab>
        <PoadTab value="settings" label="Settings" disabled><p>Settings.</p></PoadTab>
      </PoadTabs>
      <code>tab={String(tab)}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import TabsDemo from './tabs-demo';

export default function Page() {
  return <TabsDemo />;
}

À quoi ça sert

Pour des vues sœurs d’un même objet (ressources, journaux, réglages). Pour des sections qu’on veut pouvoir ouvrir ensemble, un accordéon ; pour une suite ordonnée, des étapes.

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius: 4px;            /* Arrondi des coins des contrôles */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius: 0;              /* Arrondi des coins des contrôles */
}
