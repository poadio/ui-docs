Date

<poad-datepicker>

Une date, un intervalle ou une date et une heure, saisis au clavier ou choisis dans un calendrier, dans la langue et le format de la page.

Sélecteur de date

<poad-datepicker>

Un champ de date avec son calendrier : grille de six semaines dans la langue de la page (noms, premier jour, format par Intl), clavier WAI-ARIA, une date, un intervalle ou plusieurs, bornes, saisie au clavier, heure, en ligne ou en feuille basse sur petit écran.

Angularrendu par @poadio/ui-angularNext.jsrendu par @poadio/ui-reactReactrendu par @poadio/ui-reactVuerendu par @poadio/ui-vueVanillarendu par @poadio/ui-elements

Votre réglage : :root { }

Réglage en direct, dans la démo seulement : rien n’est enregistré.

Le calendrier est rendu dans l’overlay du CDK ; le champ est un contrôle de formulaire (ngModel, formControl).

import { Component, signal } from '@angular/core';
import { PoadDatepickerComponent, type PoadDateValue } from '@poadio/ui-angular';

@Component({
  selector: 'app-datepicker-demo',
  imports: [PoadDatepickerComponent],
  template: `
    <div class="demo-row">
      <poad-datepicker [(value)]="day" [firstDayOfWeek]="1" clearable placeholder="Pick a day" style="width: 220px" />
    </div>
    <code>day={{ day() ?? 'none' }}</code>
  `,
})
export default class DatepickerDemo {
  readonly day = signal<PoadDateValue>('2026-11-24');
}

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/datepicker-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadDatepicker } from '@poadio/ui-react';

export default function DatepickerDemo() {
  const [day, setDay] = useState<unknown>('2026-11-24');
  return (
    <>
      <div className="demo-row">
        <div style={{ width: 220 }}>
          <PoadDatepicker value={day as string | null} onChange={setDay} firstDayOfWeek={1} clearable placeholder="Pick a day" aria-label="Day" />
        </div>
      </div>
      <code>day={String(day ?? 'none')}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import DatepickerDemo from './datepicker-demo';

export default function Page() {
  return <DatepickerDemo />;
}

À quoi ça sert

Pour une date proche ou à situer dans la semaine. Pour une date de naissance, un champ masqué se tape plus vite.

Brancher sur un store

Déclarer le store une fois, puis le donner au composant : store (l’objet, ou son nom) et field ou fields. Lecture et écriture passent sous le RLS de l’utilisateur connecté. Tout le détail : Stores (@poadio/data).

import { store } from '@poadio/data';

// un enregistrement
const chantier = store.table('chantier', 'chantiers', { key: 42, version: 'version' });
// ou un store de LIGNES : le champ de son enregistrement courant (curseur : first, next, prior, last)
// const chantier = store.table('chantier', 'chantiers', { save: 'batch', version: 'version' });
Angular
<!-- chantier : le store (propriété du composant) ou son nom -->
<poad-datepicker [store]="chantier" field="debut" />
React · Next.js
<PoadDatepicker store={chantier} field="debut" />
Vue · Nuxt
<PoadDatepicker :store="chantier" field="debut" />
Vanilla
<!-- le store par son nom, déclaré avant le chargement des composants (ou el.store = l’objet) -->
<poad-datepicker store="chantier" field="debut"></poad-datepicker>

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius: 4px;            /* Arrondi des coins des contrôles */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius: 0;              /* Arrondi des coins des contrôles */
}
