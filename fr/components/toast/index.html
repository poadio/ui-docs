Toasts

<poad-toast>

De courts messages empilés dans un coin de la fenêtre, envoyés par le code : statut ou alerte selon la sévérité, durée de vie (en pause au survol), trop-plein (les plus anciens sortent), doublons, actions, sortie animée.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular
import { Component, inject, signal } from '@angular/core';
import { PoadButtonComponent, PoadToastComponent, PoadToastService } from '@poadio/ui-angular';

@Component({
  selector: 'app-toast-demo',
  imports: [PoadButtonComponent, PoadToastComponent],
  template: `
    <div class="demo-row">
      <button poadButton (click)="deployed()">Notify</button>
      <button poadButton severity="danger" variant="outline" (click)="failed()">Fail</button>
    </div>
    <code>sent={{ sent() }}</code>
    <!-- once in the application -->
    <poad-toast position="top-right" showProgress />
  `,
})
export default class ToastDemo {
  private readonly toast = inject(PoadToastService);
  readonly sent = signal(0);

  deployed(): void {
    this.toast.success('Deployed', 'api v1.4 is live');
    this.sent.update((n) => n + 1);
  }
  failed(): void {
    this.toast.error('Build failed', 'Step “test” exited with code 1');
    this.sent.update((n) => n + 1);
  }
}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/toast-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadButton, PoadToast, poadToast } from '@poadio/ui-react';

export default function ToastDemo() {
  const [sent, setSent] = useState(0);
  return (
    <>
      <div className="demo-row">
        <PoadButton onClick={() => { poadToast.success('Deployed', 'api v1.4 is live'); setSent(sent + 1); }}>Notify</PoadButton>
        <PoadButton severity="danger" variant="outline" onClick={() => { poadToast.error('Build failed', 'Step “test” exited with code 1'); setSent(sent + 1); }}>
          Fail
        </PoadButton>
      </div>
      <code>sent={sent}</code>
      {/* once in the application */}
      <PoadToast position="top-right" showProgress />
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import ToastDemo from './toast-demo';

export default function Page() {
  return <ToastDemo />;
}

Rendu par Vue

useToast() rend la file fournie par provideToast(), sinon poadToast ; <PoadToast /> une fois dans l’application.

<script setup lang="ts">
import { ref } from 'vue';
import { PoadButton, PoadToast, useToast } from '@poadio/ui-vue';

const toast = useToast();
const sent = ref(0);
function deployed() {
  toast.success('Deployed', 'api v1.4 is live');
  sent.value++;
}
function failed() {
  toast.error('Build failed', 'Step “test” exited with code 1');
  sent.value++;
}
</script>

<template>
  <div class="demo-row">
    <PoadButton @click="deployed">Notify</PoadButton>
    <PoadButton severity="danger" variant="outline" @click="failed">Fail</PoadButton>
  </div>
  <code>sent={{ sent }}</code>
  <!-- once in the application (App.vue, Nuxt layout) -->
  <PoadToast position="top-right" show-progress />
</template>
Rendu par Vanilla

poadToast(message) est une fonction et la file à la fois ; sans <poad-toast> dans la page, un est ajouté à la fin de body.

<script type="module">import '@poadio/ui-elements/define';</script>

<div class="demo-row">
  <poad-button id="notify">Notify</poad-button>
  <poad-button id="fail" severity="danger" variant="outline">Fail</poad-button>
</div>
<code id="toast-out">sent=0</code>
<!-- optional: without it, poadToast adds one at the end of <body> -->
<poad-toast position="top-right" show-progress></poad-toast>

<script type="module">
  import { poadToast } from '@poadio/ui-elements';

  let sent = 0;
  const count = () => { document.querySelector('#toast-out').textContent = `sent=${++sent}`; };
  document.querySelector('#notify').addEventListener('click', () => { poadToast.success('Deployed', 'api v1.4 is live'); count(); });
  document.querySelector('#fail').addEventListener('click', () => { poadToast.error('Build failed', 'Step “test” exited with code 1'); count(); });
</script>

À quoi ça sert

Pour le retour d’une action terminée (« Déployé »). Pour un message qui doit rester dans la page, un message ; pour une question, une confirmation.

Accessibilité

  • Succès, information : role="status" et aria-live="polite" ; erreur, avertissement : role="alert" et aria-live="assertive".
  • Durée en pause au survol ; croix nommée par le catalogue.

Vérifié par le banc de conformité — Ces scénarios sont joués, à l’identique, sur chaque rendu déclaré (angular, react, vue, elements) à chaque push :
