Curseur

Choisit une valeur, ou un intervalle avec deux poignées, en glissant sur une piste ; au pas, borné, avec graduations facultatives.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular
import { Component, signal } from '@angular/core';
import { PoadSliderComponent, type PoadSliderMark, type PoadSliderValue } from '@poadio/ui-angular';

@Component({
  selector: 'app-slider-demo',
  imports: [PoadSliderComponent],
  template: `
    <div class="demo-col">
      <poad-slider [(value)]="volume" [step]="5" showValue="always" ariaLabel="Volume" />
      <poad-slider [(value)]="price" range label="Price" [marks]="marks" [formatValue]="euros" (changed)="saved.set($event)" />
    </div>
    <code>volume={{ volume() }} · price={{ price() }} · changed={{ saved() }}</code>
  `,
})
export default class SliderDemo {
  readonly volume = signal<PoadSliderValue | null>(40);
  readonly price = signal<PoadSliderValue | null>([20, 60]);
  readonly saved = signal<PoadSliderValue | null>(null);
  readonly marks: PoadSliderMark[] = [0, 50, { value: 100, label: 'Max' }];
  readonly euros = (v: number) => `${v} €`;
}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/slider-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadSlider, type SliderMark, type SliderValue } from '@poadio/ui-react';

const marks: SliderMark[] = [0, 50, { value: 100, label: 'Max' }];
const euros = (v: number) => `${v} €`;

export default function SliderDemo() {
  const [volume, setVolume] = useState<SliderValue>(40);
  const [price, setPrice] = useState<SliderValue>([20, 60]);
  const [saved, setSaved] = useState<SliderValue | null>(null);
  return (
    <>
      <div className="demo-col">
        <PoadSlider value={volume} onValueChange={setVolume} step={5} showValue="always" aria-label="Volume" />
        <PoadSlider value={price} onValueChange={setPrice} onChange={setSaved} range label="Price" marks={marks} formatValue={euros} />
      </div>
      <code>volume={String(volume)} · price={String(price)} · changed={String(saved)}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import SliderDemo from './slider-demo';

export default function Page() {
  return <SliderDemo />;
}

  const price = document.querySelector('#price');
  price.formatValue = (v) => `${v} €`;
  // input : pendant le geste ; change : au relâchement
  price.addEventListener('change', (e) => {
    document.querySelector('#price-out').textContent = `price=${e.detail}`;
  });
</script>

À quoi ça sert

Quand la valeur approximative compte plus que le chiffre exact (volume, prix maximum). Pour une saisie précise, le champ numérique.

Début FinMinimum, maximum (en intervalle : bornés par l’autre poignée).

Accessibilité

  • Chaque poignée est un role="slider" focalisable : aria-valuenow, aria-valuemin / aria-valuemax (en intervalle, bornés par l’autre poignée), aria-valuetext mis en forme, aria-orientation.
  • Nommé par son libellé visible (aria-labelledby) ou par aria-label.
  • Désactivé : aria-disabled="true", tabindex="-1". Miroir complet de droite à gauche.

Vérifié par le banc de conformité — Ces scénarios sont joués, à l’identique, sur chaque rendu déclaré (angular, react, vue, elements) à chaque push :

  • slider/keyboard-pointer-range-and-rtl
  • slider/lazy-draft-and-label

Jetons de thème
