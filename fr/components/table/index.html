Table de données

<poad-table>

Des lignes et des colonnes : tri au clic (simple ou multiple, dans l’ordre de la langue), pagination, données venues d’un serveur, sélection de lignes avec plage à la Maj, états vide et chargement. Avec une sélection, la table devient une grille dont la ligne se parcourt au clavier.

À quoi ça sert

Pour comparer des enregistrements de même forme (projets, déploiements, utilisateurs). Cette page couvre colonnes, tri, pages et sélection ; les filtres (recherche globale, ligne de filtres, pied des comptes), le panneau latéral, la puce de filtre, la ligne de détail, les groupes de lignes et la table en arbre ont leurs pages. Les colonnes figées, l’édition et le menu de colonne arrivent par tranches. Pour une liste de cartes, un simple v-for / map.

Accessibilité

  • Sans sélection : une <table> native (en-têtes scope="col"). Avec sélection : role="grid" (aria-multiselectable en multiple), aria-selected sur les lignes, une seule ligne atteignable à la tabulation.

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius: 4px;            /* Arrondi des coins des contrôles */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius: 0;              /* Arrondi des coins des contrôles */
}
