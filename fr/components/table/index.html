Table de données

<poad-table>

Des lignes et des colonnes : tri au clic (simple ou multiple, dans l’ordre de la langue), pagination, données venues d’un serveur, sélection de lignes avec plage à la Maj, états vide et chargement. Avec une sélection, la table devient une grille dont la ligne se parcourt au clavier.

interface Project { id: number; name: string; env: string; pods: number }

@Component({
  selector: 'app-table-demo',
  imports: [PoadTableComponent, PoadColumnComponent, PoadCellTemplateDirective],
  template: `
    <div class="demo-wide">
      <poad-table [value]="projects" dataKey="id" title="Projects" selectionMode="multiple" [(selection)]="selection"
        paginator [rows]="5" [rowsPerPageOptions]="[5, 10]">
        <poad-column field="name" header="Name" sortable>
          <ng-template poadCellTemplate let-row><strong>{{ row.name }}</strong></ng-template>
        </poad-column>
        <poad-column field="env" header="Env" />
        <poad-column field="pods" header="Pods" dataType="number" sortable />
      </poad-table>
    </div>
    <code>selected={{ ids() }}</code>
  `,
})
export default class TableDemo {
  readonly projects: Project[] = [
    { id: 1, name: 'gestion', env: 'recette', pods: 4 }, { id: 2, name: 'inventaire', env: 'neo', pods: 0 },
    { id: 3, name: 'demo2', env: 'neo', pods: 2 }, { id: 4, name: 'best', env: 'recette', pods: 12 },

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/table-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadTable, type PoadTableColumn } from '@poadio/ui-react';

interface Project { id: number; name: string; env: string; pods: number }
const projects: Project[] = [
  { id: 1, name: 'gestion', env: 'recette', pods: 4 }, { id: 2, name: 'inventaire', env: 'neo', pods: 0 },
  { id: 3, name: 'demo2', env: 'neo', pods: 2 }, { id: 4, name: 'best', env: 'recette', pods: 12 },
  { id: 5, name: 'demo10', env: 'recette', pods: 1 }, { id: 6, name: 'atlas', env: 'neo', pods: 7 },
  { id: 7, name: 'zephyr', env: 'neo', pods: 3 }, { id: 8, name: 'cartographie', env: 'recette', pods: 5 },
];
const columns: PoadTableColumn<Project>[] = [
  { field: 'name', header: 'Name', sortable: true, cell: ({ row }) => <strong>{row.name}</strong> },
  { field: 'env', header: 'Env' },
  { field: 'pods', header: 'Pods', dataType: 'number', sortable: true },
];

export default function TableDemo() {
  const [selection, setSelection] = useState<Project[]>([]);
  return (
    <>
      <div className="demo-wide">
        <PoadTable value={projects} columns={columns} dataKey="id" title="Projects" selectionMode="multiple" selection={selection}
          onSelectionChange={(s) => setSelection(s as Project[])} paginator defaultRows={5} rowsPerPageOptions={[5, 10]} />
      </div>
      <code>selected={selection.map((p) => p.id).join(',') || 'none'}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import TableDemo from './table-demo';

export default function Page() {
  return <TableDemo />;
}

À quoi ça sert

Pour comparer des enregistrements de même forme (projets, déploiements, utilisateurs). Cette première tranche couvre colonnes, tri, pages et sélection ; les filtres, l’arbre, les groupes, les colonnes figées, l’édition et le menu de colonne arrivent par tranches. Pour une liste de cartes, un simple v-for / map.

Accessibilité

  • Sans sélection : une <table> native (en-têtes scope="col"). Avec sélection : role="grid" (aria-multiselectable en multiple), aria-selected sur les lignes, une seule ligne atteignable à la tabulation.
  • aria-sort sur la première colonne triée (none sur les autres triables) ; boutons de tri nommés « Trier par … ».
  • aria-rowcount (lignes + en-tête) et aria-rowindex compte tenu de la page ; aria-busy pendant le chargement ; barre de sélection en aria-live.

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius: 4px;            /* Arrondi des coins des contrôles */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius: 0;              /* Arrondi des coins des contrôles */
}
