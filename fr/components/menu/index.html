Menu

<poad-menu>

Une liste d’actions, en ligne ou flottante contre un bouton (ou aux coordonnées d’un clic droit) : raccourcis, icônes, sous-menus, séparateurs, actions dangereuses. Feuille basse sur petit écran.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular

Menu flottant : popup, ouvert par toggle($event) depuis le déclencheur ; rendu dans l’overlay du CDK. routerLink sur un élément passe par le routeur.

import { Component, signal } from '@angular/core';
import { PoadButtonComponent, PoadMenuComponent, type PoadMenuItem } from '@poadio/ui-angular';

@Component({
  selector: 'app-menu-demo',
  imports: [PoadButtonComponent, PoadMenuComponent],
  template: `
    <div class="demo-row">
      <button poadButton variant="outline" (click)="actions.toggle($event)">Actions</button>
      <poad-menu #actions popup [items]="items" ariaLabel="Project actions" (itemClick)="last.set($event.item.label ?? '')" />
    </div>
    <code>last={{ last() }}</code>
  `,
})
export default class MenuDemo {
  readonly items: PoadMenuItem[] = [
    { label: 'Open', icon: 'folder-open', shortcut: '⌘O' },
    { label: 'Export', icon: 'download', items: [{ label: 'CSV' }, { label: 'JSON' }] },
    { separator: true },
    { label: 'Delete', icon: 'trash-2', severity: 'danger' },
  ];
  readonly last = signal('none');
}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/menu-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadButton, PoadMenu, type PoadMenuItem } from '@poadio/ui-react';

const items: PoadMenuItem[] = [
  { label: 'Open', icon: 'folder-open', shortcut: '⌘O' },
  { label: 'Export', icon: 'download', items: [{ label: 'CSV' }, { label: 'JSON' }] },
  { separator: true },
  { label: 'Delete', icon: 'trash-2', severity: 'danger' },
];

export default function MenuDemo() {
  const [last, setLast] = useState('none');
  return (
    <>
      <div className="demo-row">
        <PoadMenu
          items={items} trigger={<PoadButton variant="outline">Actions</PoadButton>} aria-label="Project actions"
          onItemClick={({ item }) => setLast(item.label ?? '')}
        />
      </div>
      <code>last={last}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import MenuDemo from './menu-demo';

export default function Page() {
  return <MenuDemo />;
}

Rendu par Vue
<script setup lang="ts">
import { ref } from 'vue';
import { PoadButton, PoadMenu, type PoadMenuItem } from '@poadio/ui-vue';

const items: PoadMenuItem[] = [
  { label: 'Open', icon: 'folder-open', shortcut: '⌘O' },
  { label: 'Export', icon: 'download', items: [{ label: 'CSV' }, { label: 'JSON' }] },
  { separator: true },
  { label: 'Delete', icon: 'trash-2', severity: 'danger' },
];
const last = ref('none');
</script>

<template>
  <div class="demo-row">
    <PoadMenu :items="items" aria-label="Project actions" @item-click="({ item }) => (last = item.label ?? '')">
      <template #trigger><PoadButton variant="outline">Actions</PoadButton></template>
    </PoadMenu>
  </div>
  <code>last={{ last }}</code>
</template>
Rendu par Vanilla

L’enfant slot="trigger" bascule le menu ; des éléments avec command se donnent en propriété (menu.items = […]).

<script type="module">import '@poadio/ui-elements/define';</script>

<div class="demo-row">
  <poad-menu id="actions" aria-label="Project actions"
    items='[{"label":"Open","icon":"folder-open","shortcut":"⌘O"},{"label":"Export","icon":"download","items":[{"label":"CSV"},{"label":"JSON"}]},{"separator":true},{"label":"Delete","icon":"trash-2","severity":"danger"}]'>
    <poad-button slot="trigger" variant="outline">Actions</poad-button>
  </poad-menu>
</div>
<code id="menu-out">last=none</code>

<script type="module">
  document.querySelector('#actions').addEventListener('itemclick', (e) => {
    document.querySelector('#menu-out').textContent = `last=${e.detail.item.label}`;
  });
</script>

À quoi ça sert

Pour des actions sur un objet qui ne tiennent pas en boutons. Pour choisir une valeur, une liste déroulante ; pour une action principale et ses variantes, un bouton scindé.

Clavier

ToucheEffet
↓ ↑Élément suivant / précédent, en boucle, en sautant séparateurs et désactivés.
Début FinPremier / dernier élément.
→Sur un élément à sous-menu : l’ouvre et focalise son premier élément.
←Dans un sous-menu : le ferme, le focus revient à son élément.
Entrée EspaceChoisit l’élément (et ferme le menu flottant).
ÉchapFerme le sous-menu, puis le menu ; le focus revient au déclencheur.

Accessibilité

  • Panneau role="menu", éléments role="menuitem" (des boutons), séparateurs role="separator".
  • Ouvert, le focus va au premier élément ; focus itinérant (tabindex="0" sur l’élément actif seulement).
  • Élément à sous-menu : aria-haspopup="menu" et aria-expanded.
