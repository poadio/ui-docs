Chrome de carte

<poad-map-chrome>

Tout l’habillage d’une carte en un seul composant : fonds, couches (symbologie, import d’un GeoJSON), outils (mesure, dessin, interrogation, comparaison) et export (image PNG, GeoJSON, lien, impression).

export default class MapChromeDemo {
  readonly bridges = bridges;
  readonly zone = zone;
  readonly open = signal(false);
  readonly imported = signal('none');
  readonly shapes = signal(0);

À quoi ça sert

Enfant de la carte. mode choisit la présentation : drawer (un bouton ouvre un tiroir à onglets), toolbar (un bouton par onglet) ou rail (le rail et les panneaux de la carte). Sur un petit écran, le tiroir devient une feuille basse. L’onglet Couches liste les couches de la carte ; le bouton palette d’une couche ouvre sa symbologie (couleur, couleur par champ, étiquette), posée à chaud et retirée par « Rétablir ». Un fichier GeoJSON importé devient une couche. L’export ne fait aucune requête : l’image vient du canevas (screenshotable sur la carte), le GeoJSON des couches, le lien de la vue. Une étiquette tirée d’un champ lit les glyphes de la carte (glyphs). L’étiquette depuis un champ (symbologie d’une couche) et les mesures écrivent avec les polices de la carte : voir glyphs sur la carte.

Accessibilité

  • Le bouton d’ouverture dit l’état du tiroir (aria-expanded, aria-controls) ; le tiroir est un dialog nommé, inert une fois fermé.
  • Les onglets forment un tablist (un seul arrêt de tabulation, aria-selected, aria-controls) ; seul le panneau courant est visible.
  • Les outils sont une toolbar nommée ; la mesure, l’import, le lien copié et « rien ici » sont annoncés (role="status") dans la langue.
  • La popup d’interrogation est faite de tableaux posés en texte seul (jamais de HTML venu des données).

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius-lg: 16px;        /* Grand arrondi : cartes, dialogues, panneaux */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius-lg: 0;           /* Grand arrondi : cartes, dialogues, panneaux */
}
