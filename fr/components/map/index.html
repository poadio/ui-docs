À quoi ça sert

maplibre-gl est une dépendance FACULTATIVE : npm i maplibre-gl ; il n’est chargé qu’au montage de la première carte (jamais au rendu serveur), et s’il manque, la carte dit quel paquet installer au lieu de casser la page. Les fonds viennent d’un registre (IGN Géoplateforme, OpenStreetMap, vectoriels clair et sombre par défaut) que l’application complète : un fond peut être un style MapLibre local, sans aucune tuile distante, comme dans cette démo. Les couches sont des enfants de la carte ; center et zoom ne sont imposés que quand l’application les change. Pour un simple point sur un plan statique, une image suffit. Étiquettes : une étiquette (champ d’une couche, mesure, nombre d’une grappe) a besoin de polices. Un style donné par son adresse apporte les siennes ; pour un fond raster ou un style objet sans glyphs, la carte prend son entrée glyphs (Angular : le jeton POAD_MAP_GLYPHS), par défaut les polices d’OpenFreeMap — une requête vers un service externe, faite seulement quand une étiquette s’affiche. Pour tout servir soi-même, déposez les fichiers {fontstack}/{range}.pbf (police « Noto Sans Regular ») sur votre site et donnez leur modèle d’adresse, comme le font les démos des outils et du chrome de carte.

Accessibilité

  • Le canevas est une région (role="region") nommée par ariaLabel (« Carte » sinon), atteinte à la tabulation ; son focus est montré par un anneau aux couleurs du thème.
  • Les contrôles (zoom, boussole, plein écran, géolocalisation, attributions) sont des boutons nommés dans la langue de l’application ; l’échelle suit le zoom.
  • Le chargement est annoncé (« Chargement de la carte… »), une erreur (paquet manquant) est affichée en clair.
  • Contrôles, popups, info-bulles et marqueurs suivent les jetons (clair / sombre) ; followTheme choisit le fond clair ou sombre du registre selon le thème de la page.

/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius-lg: 16px;        /* Grand arrondi : cartes, dialogues, panneaux */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius-lg: 0;           /* Grand arrondi : cartes, dialogues, panneaux */
