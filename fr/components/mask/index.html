Masque de saisie

Guide la frappe dans un format fixe (téléphone, date, SIRET…) : les places libres s’affichent, les caractères refusés n’entrent pas, le curseur saute les littéraux. Se pose sur un <input> existant.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular
import { Component, signal } from '@angular/core';
import { FormsModule } from '@angular/forms';
import { PoadFieldComponent, PoadInputDirective, PoadMaskDirective } from '@poadio/ui-angular';

@Component({
  selector: 'app-mask-demo',
  imports: [FormsModule, PoadFieldComponent, PoadInputDirective, PoadMaskDirective],
  template: `
    <div class="demo-col">
      <poad-field label="Phone" hint="Preset « phone »">
        <input poadInput poadMaskPreset="phone" [(ngModel)]="phone" />
      </poad-field>
      <poad-field label="Date" hint="Raw value (unmask), cleared if incomplete (autoClear)">
        <input poadInput poadMask="99/99/9999" unmask autoClear [(ngModel)]="date" />
      </poad-field>
    </div>
    <code>phone={{ phone() }} · date={{ date() }}</code>
  `,
})
export default class MaskDemo {
  readonly phone = signal<string | null>(null);
  readonly date = signal<string | null>(null);
}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/mask-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadField, PoadInput, usePoadMask } from '@poadio/ui-react';

export default function MaskDemo() {
  const [phone, setPhone] = useState<string | null>(null);
  const [date, setDate] = useState<string | null>(null);
  const tel = usePoadMask({ preset: 'phone', value: phone, onValueChange: setPhone });
  const day = usePoadMask({ mask: '99/99/9999', unmask: true, autoClear: true, value: date, onValueChange: setDate });
  return (
    <>
      <div className="demo-col">
        <PoadField label="Phone" hint="Preset « phone »">
          <PoadInput {...tel.inputProps} />
        </PoadField>
        <PoadField label="Date" hint="Raw value (unmask), cleared if incomplete (autoClear)">
          <PoadInput {...day.inputProps} />
        </PoadField>
      </div>
      <code>phone={String(phone)} · date={String(date)} · complete={String(day.complete)}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import MaskDemo from './mask-demo';

export default function Page() {
  return <MaskDemo />;
}

Rendu par Vue

v-model ne se combine pas avec la directive (il réécrirait le texte masqué) : la valeur entre par value et sort par onValueChange.

<script setup lang="ts">
import { ref } from 'vue';
import { PoadField, PoadInput, vPoadMask } from '@poadio/ui-vue';

const phone = ref<string | null>(null);
const date = ref<string | null>(null);
</script>

<template>
  <div class="demo-col">
    <PoadField label="Phone" hint="Preset « phone »">
      <PoadInput v-poad-mask="{ preset: 'phone', value: phone, onValueChange: (v) => (phone = v) }" />
    </PoadField>
    <PoadField label="Date" hint="Raw value (unmask), cleared if incomplete (autoClear)">
      <PoadInput v-poad-mask="{ mask: '99/99/9999', unmask: true, autoClear: true, value: date, onValueChange: (v) => (date = v) }" />
    </PoadField>
  </div>
  <code>phone={{ phone }} · date={{ date }}</code>
</template>
Rendu par Vanilla

<poad-mask> entoure le champ natif, qui soumet son texte masqué avec le <form>. Sans élément : attachMask(input, options) (et detach()).

<script type="module">import '@poadio/ui-elements/define';</script>

<div class="demo-col">
  <poad-field label="Phone" hint="Preset « phone »">
    <poad-mask id="phone" preset="phone"><input name="phone"></poad-mask>
  </poad-field>
  <poad-field label="Date" hint="Raw value (unmask), cleared if incomplete (autoClear)">
    <poad-mask id="date" mask="99/99/9999" unmask auto-clear><input name="date"></poad-mask>
  </poad-field>
</div>
<code id="mask-out">phone=null · date=null</code>

<script type="module">
  const phone = document.querySelector('#phone');
  const date = document.querySelector('#date');
  const show = () => {
    document.querySelector('#mask-out').textContent = `phone=${phone.value} · date=${date.value}`;
  };
  phone.addEventListener('valuechange', show);
  date.addEventListener('valuechange', show);
</script>

À quoi ça sert

9 : un chiffre, a : une lettre, * : l’un ou l’autre ; le reste est littéral. Préréglages : phone, siret, siren, postal, date, time, iban, plate.

Clavier

Aucune interaction clavier : composant d’affichage.

Accessibilité

  • Le champ indique le format (placeholder : __ __ __ __ __) et le clavier attendu (inputmode="numeric" pour un masque de chiffres).
  • Une frappe refusée n’entre pas ; un collage est relu à travers le masque.
  • Le champ reste un <input> natif : son libellé (champ, <label>) et son formulaire ne changent pas.

Vérifié par le banc de conformité — Ces scénarios sont joués, à l’identique, sur chaque rendu déclaré (angular, react, vue, elements) à chaque push :

  • mask/preset-typing-and-caret
  • mask/unmask-and-auto-clear
