Envoi de fichiers

<poad-upload>

Une zone où déposer des fichiers ou qui ouvre le choix du système : chaque fichier est vérifié (type, poids, nombre), listé avec son poids et son état, retirable, puis envoyé avec sa progression.

Démonstration

Votre réglage : :root { }

Réglage en direct, dans la démo seulement : rien n’est enregistré.

Envoi par url avec HttpClient (provideHttpClient() requis), ou customUpload + (uploadHandler) ; la liste se lit par files() ; gabarits poadUploadItem, poadUploadEmpty, poadUploadContent.

import { Component, signal } from '@angular/core';
import { PoadUploadComponent, type PoadUploadHandlerEvent } from '@poadio/ui-angular';

@Component({
  selector: 'app-upload-demo',
  imports: [PoadUploadComponent],
  template: `
    <poad-upload class="demo-upload" multiple accept="image/*,.pdf" [maxFileSize]="1048576" [maxFiles]="3" customUpload
      hint="PNG, JPG or PDF · 1 MB max · 3 files" (uploadHandler)="send($event)" (uploaded)="last.set($event.file.name)" />
    <poad-upload mode="basic" selectOnly chooseLabel="Attach a file" (select)="picked.set($event[0]?.name ?? '')" />
    <code>uploaded={{ last() }} · attached={{ picked() }}</code>
  `,
})
export default class UploadDemo {
  readonly last = signal('');
  readonly picked = signal('');
  // envoi simulé, sans réseau : la progression avance par quarts, puis le fichier est « envoyé »
  send({ files, progress, done }: PoadUploadHandlerEvent): void {
    files.forEach((_, i) => {
      let pct = 0;
      const timer = setInterval(() => {
        pct += 25;
        if (pct < 100) progress(i, pct);
        else { clearInterval(timer); done(i, true); }
      }, 200);
    });
  }
}

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/upload-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadUpload, type PoadUploadHandlerEvent } from '@poadio/ui-react';

// envoi simulé, sans réseau : la progression avance par quarts, puis le fichier est « envoyé »
function send({ files, progress, done }: PoadUploadHandlerEvent) {
  files.forEach((_, i) => {
    let pct = 0;
    const timer = setInterval(() => {
      pct += 25;
      if (pct < 100) progress(i, pct);
      else { clearInterval(timer); done(i, true); }
    }, 200);
  });
}

export default function UploadDemo() {
  const [last, setLast] = useState('');
  const [picked, setPicked] = useState('');
  return (
    <>
      <PoadUpload
        className="demo-upload" multiple accept="image/*,.pdf" maxFileSize={1048576} maxFiles={3} customUpload
        hint="PNG, JPG or PDF · 1 MB max · 3 files" onUploadHandler={send} onUploaded={({ file }) => setLast(file.name)}
      />
      <PoadUpload mode="basic" selectOnly chooseLabel="Attach a file" onSelect={(files) => setPicked(files[0]?.name ?? '')} />
      <code>uploaded={last} · attached={picked}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import UploadDemo from './upload-demo';

export default function Page() {
  return <UploadDemo />;
}

Participe aux formulaires : avec name, les fichiers valides partent avec le <form> ; required ; form.reset() vide la liste. Envoi par l’application : évènement uploadrequest ({ files, progress, done }).

<script type="module">import '@poadio/ui-elements/define';</script>

<poad-upload id="docs" class="demo-upload" multiple accept="image/*,.pdf" max-file-size="1048576" max-files="3" custom-upload
  hint="PNG, JPG or PDF · 1 MB max · 3 files"></poad-upload>
<form id="attach">
  <poad-upload mode="basic" name="attachment" select-only choose-label="Attach a file"></poad-upload>
</form>
<code id="upload-out">uploaded= · attached=</code>

<script type="module">
  const out = { uploaded: '', attached: '' };
  const show = () => { document.querySelector('#upload-out').textContent = `uploaded=${out.uploaded} · attached=${out.attached}`; };
  // envoi simulé, sans réseau : la progression avance par quarts, puis le fichier est « envoyé »
  document.querySelector('#docs').addEventListener('uploadrequest', ({ detail: { files, progress, done } }) => {
    files.forEach((_, i) => {
      let pct = 0;
      const timer = setInterval(() => {
        pct += 25;
        if (pct < 100) progress(i, pct);
        else { clearInterval(timer); done(i, true); }
      }, 200);
    });
  });
  document.querySelector('#docs').addEventListener('uploaded', ({ detail }) => { out.uploaded = detail.file.name; show(); });
  // le fichier choisi part avec le formulaire (name="attachment") : new FormData(form).get('attachment')
  document.querySelector('#attach poad-upload').addEventListener('fileselect', ({ detail }) => { out.attached = detail[0]?.name ?? ''; show(); });
</script>

À quoi ça sert

Pour joindre un ou plusieurs fichiers à un formulaire ou les envoyer à un serveur. Le mode basic (un bouton) pour un seul fichier dans un formulaire serré ; dropzone quand l’application envoie elle-même, sans boutons.

Clavier

ToucheEffet
Entrée EspaceSur la zone : ouvre le choix des fichiers du système. Sur « Retirer » : retire la ligne, le focus passe au fichier suivant (sinon à la zone).
TabZone, puis les boutons « Retirer » de chaque fichier, puis « Envoyer » et « Tout retirer ». Le champ natif caché n’est pas dans la tabulation.

Accessibilité

  • La zone est un role="button" focalisable, nommé par ses textes ; désactivée, elle sort de la tabulation et porte aria-disabled. Le dépôt n’est jamais le seul moyen : clic et clavier ouvrent le choix.
  • Le <input type="file"> natif choisit les fichiers mais reste caché (aria-hidden, tabindex="-1") : un seul arrêt de tabulation.
  • Chaque bouton de retrait est nommé par son fichier (« Retirer rapport.pdf ») ; la barre de progression est un role="progressbar" nommé par le fichier, avec le pourcentage écrit à côté.
  • Un fichier refusé reste dans la liste avec son message (type, poids, nombre), en texte, pas seulement en couleur ; les refus d’un ajout sont aussi annoncés dans une région polie (role="status", cachée à l’écran).

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius: 4px;            /* Arrondi des coins des contrôles */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius: 0;              /* Arrondi des coins des contrôles */
}
