Mot de passe

Un vrai champ de mot de passe, masqué par défaut, avec un bouton œil pour l’afficher et, au besoin, une jauge de robustesse.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular

Pas encore d’ariaLabel sur poad-password en Angular : nommer le champ par le contexte.

import { Component, signal } from '@angular/core';
import { PoadPasswordComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-password-demo',
  imports: [PoadPasswordComponent],
  template: `
    <div class="demo-col">
      <poad-password [(value)]="password" feedback autocomplete="new-password" placeholder="New password" />
      <poad-password [value]="'secret'" placeholder="Disabled" disabled />
    </div>
    <code>length={{ password()?.length ?? 0 }}</code>
  `,
})
export default class PasswordDemo {
  readonly password = signal<string | null>('');
}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/password-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadPassword } from '@poadio/ui-react';

export default function PasswordDemo() {
  const [password, setPassword] = useState('');
  return (
    <>
      <div className="demo-col">
        <PoadPassword value={password} onValueChange={setPassword} feedback autoComplete="new-password" placeholder="New password" aria-label="New password" />
        <PoadPassword defaultValue="secret" placeholder="Disabled" aria-label="Disabled" disabled />
      </div>
      <code>length={password.length}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import PasswordDemo from './password-demo';

export default function Page() {
  return <PasswordDemo />;
}

Rendu par Vanilla

Le <input type="password"> intérieur porte name et participe lui-même au formulaire : les gestionnaires de mots de passe le reconnaissent.

<script type="module">import '@poadio/ui-elements/define';</script>

<div class="demo-col">
  <poad-password id="pwd" name="password" feedback autocomplete="new-password" placeholder="New password" aria-label="New password"></poad-password>
  <poad-password value="secret" placeholder="Disabled" aria-label="Disabled" disabled></poad-password>
</div>
<code id="pwd-out">length=0</code>

<script type="module">
  document.querySelector('#pwd').addEventListener('input', (e) => {
    document.querySelector('#pwd-out').textContent = `length=${e.detail.length}`;
  });
</script>

À quoi ça sert

La jauge (feedback) sert à la création d’un mot de passe, pas à la connexion. Indiquer autocomplete="new-password" à la création : les gestionnaires de mots de passe s’y retrouvent.

Accessibilité

  • Champ type="password" par défaut, type="text" une fois révélé.
  • L’œil est un bouton nommé par le catalogue (« Afficher / Masquer le mot de passe ») avec aria-pressed.
  • La jauge porte son niveau (data-level) et un libellé lu (aria-live="polite").

Vérifié par le banc de conformité — Ces scénarios sont joués, à l’identique, sur chaque rendu déclaré (angular, react, vue, elements) à chaque push :
