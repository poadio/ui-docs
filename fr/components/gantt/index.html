Gantt

<poad-gantt>

Les tâches d’un document de planification dans la durée, avec leurs dépendances : à gauche la table du framework en arbre, à droite les barres, les récapitulatifs, les jalons et les liens. Zoom au jour, à la semaine ou au mois, trait « aujourd’hui », et, si on le permet, déplacer et redimensionner à la souris, au doigt ou au clavier.

Angularrendu par @poadio/ui-angularNext.jsrendu par @poadio/ui-reactReactrendu par @poadio/ui-reactVuerendu par @poadio/ui-vueVanillarendu par @poadio/ui-elements

Votre réglage : :root { }

Réglage en direct, dans la démo seulement : rien n’est enregistré.

@Component({
  selector: 'app-gantt-demo',
  imports: [PoadGanttComponent, PoadSegmentedComponent],
  template: `
    <poad-segmented [(value)]="scale" [options]="scales" ariaLabel="Zoom" size="sm" />
    <poad-gantt class="demo-gantt" [plan]="plan()" [scale]="scale()" [today]="today" editable ariaLabel="Bridge repair plan"
      (taskMove)="change($event)" (taskResize)="change($event)" />
    <code>{{ last() }}</code>
  `,
})
export default class GanttDemo {
  readonly scales: PoadSegmentOption[] = [{ label: 'Day', value: 'day' }, { label: 'Week', value: 'week' }, { label: 'Month', value: 'month' }];
  readonly scale = signal<PoadGanttScale>('week');
  readonly today = new Date(2026, 8, 15);
  readonly plan = signal(PLAN);
  readonly last = signal('last=—');
  /** The Gantt chart never writes: the application applies the change to its own document. */
  change(e: PoadGanttChangeEvent): void {
    this.plan.update((p) => ({ ...p, tasks: p.tasks!.map((t) => (t.id === e.task.id ? { ...t, start: e.start, end: e.end } : t)) }));
    this.last.set(`last=${e.task.label} ${e.start.getDate()}/${e.start.getMonth() + 1}`);
  }
}

À quoi ça sert

Pour répondre à « si ça glisse, qu’est-ce qui tombe ? ». Pour « qui est libre jeudi ? », le planificateur ; pour l’agenda d’une équipe, le calendrier. Le volet gauche EST la table de la bibliothèque (repli, sélection, clavier de la table) : ses rangées et les barres restent alignées, même quand un libellé passe sur deux lignes, et défilent ensemble. Le Gantt n’écrit jamais : il émet l’intention (nouvelles dates, aimantées au jour) et garde l’affichage à jour le temps que l’application l’applique ; les récapitulatifs suivent. Les liens se lisent ici, ils ne se créent pas.

Brancher sur un store

Déclarer le store une fois, puis le donner au composant : store (l’objet, ou son nom) et field ou fields. Lecture et écriture passent sous le RLS de l’utilisateur connecté. Tout le détail : Stores (@poadio/data).

import { store } from '@poadio/data';

// le composant lit la période ou l’emprise affichée
const chantiers = store.table('chantiers', 'chantiers');

Accessibilité

  • Région nommée ; chaque barre est un bouton dont le nom dit la tâche, ses dates et son avancement (« récapitulatif » pour une barre roulée, « jalon » pour un losange) ; un lien porte son type et son décalage en titre.
  • Édition active : chaque barre manipulable est décrite par l’aide clavier (aria-describedby) ; chaque geste est annoncé dans une région aria-live, avec la date dans la langue (« “Structural diagnosis” moved to Tuesday 15 September ») ; le focus reste sur la barre. Un récapitulatif (dates roulées) et une tâche verrouillée ne bougent pas, et le montrent.
  • Dates en heure locale, changements d’heure compris ; gestes aimantés au jour à tous les niveaux de zoom. Sous le seuil mobile, la table ne garde que la colonne des tâches : les barres gardent la place.

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius: 4px;            /* Arrondi des coins des contrôles */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius: 0;              /* Arrondi des coins des contrôles */
}
