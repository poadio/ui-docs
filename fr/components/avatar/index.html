Avatar

Représente une personne ou une entité : photo, sinon initiales sur une teinte dérivée du nom, sinon une icône.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular
import { Component } from '@angular/core';
import { PoadAvatarComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-avatar-demo',
  imports: [PoadAvatarComponent],
  template: `
    <div class="demo-row">
      <poad-avatar text="Ada Lovelace" />
      <poad-avatar text="Alan Turing" size="lg" />
      <poad-avatar text="Grace Hopper" size="sm" shape="square" />
      <poad-avatar text="LT" color="#2f6feb" label="Linus Torvalds" />
      <poad-avatar icon="user" label="Guest" />
      <poad-avatar [src]="photo" label="Margaret Hamilton" size="lg" />
    </div>
  `,
})
export default class AvatarDemo {

Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

PoadAvatar n’a pas d’état : il se rend aussi dans un composant serveur.

  return <AvatarDemo />;

À quoi ça sert

Les initiales et la couleur se calculent à partir de text : le même nom donne la même teinte dans chaque framework. Plusieurs avatars côte à côte : le groupe d’avatars.

Options principales

AngularReact · Next.jsVueComposant webTypeDescription
texttexttexttextstringNom ou initiales : donne les initiales, la teinte et le nom accessible.
srcsrcsrcsrcstringImage ; son texte alternatif est le libellé.
labellabellabellabelstringNom accessible (sinon text).
iconiconiconiconstring
Défaut 'user'		Icône de repli, sans image ni texte.
sizesizesizesize'sm' | 'md' | 'lg'
Défaut 'md'		Taille.
shapeshapeshapeshape'circle' | 'square'
Défaut 'circle'		Forme.
colorcolorcolorcolorstringFond imposé (sinon dérivé du texte).

Clavier

Aucune interaction clavier : composant d’affichage.

Accessibilité

  • role="img", nommé par label, sinon par text (« Stéphane Zuccatti », pas « SZ »).
  • Avec une image : <img alt> reçoit le libellé.
  • Ni texte ni libellé : icône de repli, et aucun aria-label vide.

Vérifié par le banc de conformité — Ces scénarios sont joués, à l’identique, sur chaque rendu déclaré (angular, react, vue, elements) à chaque push :

  • avatar/initials-image-icon

Attributs vérifiés : role accessible name aria-label

Textes du catalogue

Aucun texte de la bibliothèque : tout ce qui s'affiche vient de l'application.

Jetons de thème

Jetons --poad-* lus par la feuille @poadio/ui-core/avatar.css, @poadio/ui-core/icon.css de @poadio/ui-core. Les redéfinir (globalement ou sur un conteneur) suffit à thémer le composant, dans tous les frameworks à la fois.

--poad-font --poad-elevated --poad-fg --poad-radius-sm --poad-surface
