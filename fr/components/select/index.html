Liste déroulante

Choisit une valeur dans une liste d’options : combobox WAI-ARIA, recherche au clavier, filtre, effacement, groupes, gabarits. Jamais de <select> natif ; sur petit écran, le panneau s’ouvre en feuille basse.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular

Le panneau est rendu dans l’overlay du CDK : charger @angular/cdk/overlay-prebuilt.css (inclus par la feuille de base d’ui-angular).

import { Component, signal } from '@angular/core';
import { PoadSelectComponent } from '@poadio/ui-angular';

interface Runtime { id: number; name: string; disabled?: boolean }

@Component({
  selector: 'app-select-demo',
  imports: [PoadSelectComponent],
  template: `
    <div class="demo-row">
      <poad-select [options]="runtimes" optionLabel="name" optionValue="id" [(value)]="runtime"
        placeholder="Runtime" ariaLabel="Runtime" filter clearable style="width: 240px" />
      <poad-select [options]="sizes" [(value)]="size" ariaLabel="Size" size="sm" style="width: 120px" />
      <poad-select [options]="sizes" [value]="'M'" ariaLabel="Disabled" disabled style="width: 120px" />
    </div>
    <code>runtime={{ runtime() }} · size={{ size() }}</code>
  `,
})
export default class SelectDemo {
  readonly runtimes: Runtime[] = [
    { id: 1, name: 'Serverless' },
    { id: 2, name: 'Node / Bun', disabled: true },
    { id: 3, name: 'Spring Boot' },
    { id: 4, name: 'Python' },
  ];
  readonly sizes = ['S', 'M', 'L', 'XL'];
  readonly runtime = signal<unknown>(3);
  readonly size = signal<unknown>('M');
}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/select-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadSelect } from '@poadio/ui-react';

const runtimes = [
  { id: 1, name: 'Serverless' },
  { id: 2, name: 'Node / Bun', disabled: true },
  { id: 3, name: 'Spring Boot' },
  { id: 4, name: 'Python' },
];
const sizes = ['S', 'M', 'L', 'XL'];

export default function SelectDemo() {
  const [runtime, setRuntime] = useState<unknown>(3);
  const [size, setSize] = useState<unknown>('M');
  return (
    <>
      <div className="demo-row">
        <PoadSelect options={runtimes} optionLabel="name" optionValue="id" value={runtime} onChange={setRuntime}
          placeholder="Runtime" aria-label="Runtime" filter clearable style={{ width: 240 }} />
        <PoadSelect options={sizes} value={size} onChange={setSize} aria-label="Size" size="sm" style={{ width: 120 }} />
        <PoadSelect options={sizes} defaultValue="M" aria-label="Disabled" disabled style={{ width: 120 }} />
      </div>
      <code>runtime={String(runtime)} · size={String(size)}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import SelectDemo from './select-demo';

export default function Page() {
  return <SelectDemo />;
}

Rendu par Vanilla

Options et valeur en attributs JSON, ou en propriétés (select.options = […]) ; la valeur est soumise avec le <form> sous name.

<script type="module">import '@poadio/ui-elements/define';</script>

<div class="demo-row">
  <div style="width: 240px">
    <poad-select id="runtime" name="runtime" placeholder="Runtime" aria-label="Runtime" filter clearable
      option-label="name" option-value="id" value="3"
      options='[{"id":1,"name":"Serverless"},{"id":2,"name":"Node / Bun","disabled":true},{"id":3,"name":"Spring Boot"},{"id":4,"name":"Python"}]'></poad-select>
  </div>
  <div style="width: 120px">
    <poad-select id="size" name="size" aria-label="Size" size="sm" value="M" options='["S","M","L","XL"]'></poad-select>
  </div>
  <div style="width: 120px">
    <poad-select aria-label="Disabled" value="M" options='["S","M","L","XL"]' disabled></poad-select>
  </div>
</div>

<script type="module">
  const runtime = document.querySelector('#runtime');
  const size = document.querySelector('#size');
  const show = () => {
    document.querySelector('#select-out').textContent = `runtime=${runtime.value} · size=${size.value}`;
  };
  runtime.addEventListener('change', show);
  size.addEventListener('change', show);

À quoi ça sert

À partir d’une demi-douzaine d’options, ou quand la place manque. En dessous, un groupe radio ou un choix segmenté montre tout d’un coup d’œil.

Clavier

ToucheEffet

↓ ↑Ouvert : option suivante / précédente, en sautant les options désactivées.
Début FinPremière / dernière option.
Page ↑ Page ↓Saute de plusieurs options.
EntréeOuvert : choisit l’option active et ferme.
ÉchapFerme sans choisir ; le focus revient au déclencheur (même depuis le filtre).

a–zRecherche au clavier : fermé, choisit directement l’option qui commence ainsi.
SupprAvec clearable : efface la valeur.

Accessibilité

  • Déclencheur role="combobox" (aria-haspopup="listbox", aria-expanded, aria-controls), liste role="listbox", options role="option" avec aria-selected et aria-disabled.
  • Option active annoncée par aria-activedescendant : le focus reste sur le déclencheur (ou dans le filtre, role="searchbox" lié à la liste).
  • Désactivé : aria-disabled="true" et tabindex="-1", ni clic ni clavier.
  • Liste vide ou filtre sans résultat : un message du catalogue dans la liste.

Vérifié par le banc de conformité — Ces scénarios sont joués, à l’identique, sur chaque rendu déclaré (angular, react, vue, elements) à chaque push :
