Groupe d’avatars

Empile des avatars qui se chevauchent ; au-delà de max, les suivants sont résumés par un avatar « +N ».

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular
import { Component, signal } from '@angular/core';
import { PoadAvatarComponent, PoadAvatarGroupComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-avatar-group-demo',
  imports: [PoadAvatarGroupComponent, PoadAvatarComponent],
  template: `
    <poad-avatar-group [max]="3">
      @for (name of team(); track name) {
        <poad-avatar [text]="name" />
      }
    </poad-avatar-group>
    <poad-avatar-group size="sm">
      <poad-avatar text="Ada Lovelace" />
      <poad-avatar text="Alan Turing" />
    </poad-avatar-group>
  `,
})
export default class AvatarGroupDemo {
  readonly team = signal(['Ada Lovelace', 'Alan Turing', 'Grace Hopper', 'Linus Torvalds', 'Margaret Hamilton']);
}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

PoadAvatarGroup n’a pas d’état : il se rend aussi dans un composant serveur.

// app/avatar-group-demo.tsx — composant client (état, gestionnaires)
'use client';

import { PoadAvatar, PoadAvatarGroup } from '@poadio/ui-react';

const team = ['Ada Lovelace', 'Alan Turing', 'Grace Hopper', 'Linus Torvalds', 'Margaret Hamilton'];

export default function AvatarGroupDemo() {
  return (
    <>
      <PoadAvatarGroup max={3}>
        {team.map((name) => <PoadAvatar key={name} text={name} />)}
      </PoadAvatarGroup>
      <PoadAvatarGroup size="sm">
        <PoadAvatar text="Ada Lovelace" />
        <PoadAvatar text="Alan Turing" />
      </PoadAvatarGroup>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import AvatarGroupDemo from './avatar-group-demo';

export default function Page() {
  return <AvatarGroupDemo />;
}

À quoi ça sert

Pour montrer qui participe (membres d’un projet, relecteurs) sans prendre de place. Les avatars sont des enfants directs du groupe.

Clavier

Aucune interaction clavier : composant d’affichage.

Accessibilité

  • Racine role="group", chaque avatar role="img" nommé.
  • Les avatars masqués restent dans le DOM (is-overflow) ; l’avatar « +N » est nommé par leurs noms (« Grace Hopper, Linus Torvalds ») : rien n’est perdu pour un lecteur d’écran.

Vérifié par le banc de conformité — Ces scénarios sont joués, à l’identique, sur chaque rendu déclaré (angular, react, vue, elements) à chaque push :

Jetons de thème

Jetons --poad-* lus par la feuille @poadio/ui-core/avatar.css de @poadio/ui-core. Les redéfinir (globalement ou sur un conteneur) suffit à thémer le composant, dans tous les frameworks à la fois.

--poad-font --poad-elevated --poad-fg --poad-radius-sm --poad-surface
