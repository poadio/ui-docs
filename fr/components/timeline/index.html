Chronologie

<poad-timeline>

Des évènements dans l’ordre, le long d’une ligne : un marqueur (point coloré ou icône) par évènement, son contenu et, en regard, sa date. Les évènements passés et le courant ressortent.

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/carousel-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadCarousel } from '@poadio/ui-react';

interface Project { name: string; stack: string }
const projects: Project[] = [
  { name: 'fleet-manager', stack: 'Angular · PostgreSQL' }, { name: 'bridge-survey', stack: 'React · PostGIS' }, { name: 'open-data', stack: 'Vue · S3' },
  { name: 'road-works', stack: 'Angular · Redis' }, { name: 'tram-lines', stack: 'Svelte · Kafka' },
];

export default function CarouselDemo() {
  const [page, setPage] = useState(0);
  return (
    <>
      <div className="demo-wide">
        <PoadCarousel<Project>
          items={projects} numVisible="1 sm:2 lg:3" circular autoplay={6000} aria-label="Projects" page={page} onPageChange={setPage}
          renderItem={(p) => <div className="demo-slide"><strong>{p.name}</strong><span>{p.stack}</span></div>}
        />
      </div>
      <code>page={page}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import CarouselDemo from './carousel-demo';

export default function Page() {
  return <CarouselDemo />;
}

Accessibilité

  • alt est le texte de remplacement de l’image et le nom de l’aperçu ; une légende devient un <figcaption>.
  • Aperçu : boîte modale (role="dialog", aria-modal), focus piégé, défilement de la page bloqué, focus rendu à la fermeture ; outils nommés par le catalogue.
  • Squelette décoratif (aria-hidden) ; fondu et zoom animés coupés sous prefers-reduced-motion.

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-elevated: #e7e5e4;      /* Fond surélevé : piste d’un curseur ou d’une jauge, pastille neutre */
  --poad-radius: 4px;            /* Arrondi des coins des contrôles */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-elevated: #44403c;      /* Fond surélevé : piste d’un curseur ou d’une jauge, pastille neutre */
}

/* Une zone seulement */
.checkout {
  --poad-radius: 0;              /* Arrondi des coins des contrôles */
}
