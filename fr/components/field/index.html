À quoi ça sert

Pour tout champ de formulaire. L’erreur remplace l’aide tant qu’elle est là ; ne la montrer qu’après un premier essai de l’utilisateur.

Brancher sur un store

Déclarer le store une fois, puis le donner au composant : store (l’objet, ou son nom) et field ou fields. Lecture et écriture passent sous le RLS de l’utilisateur connecté. Tout le détail : Stores (@poadio/data).

import { store } from '@poadio/data';

// un enregistrement
const chantier = store.table('chantier', 'chantiers', { key: 42, version: 'version' });
// ou un store de LIGNES : le champ de son enregistrement courant (curseur : first, next, prior, last)
// const chantier = store.table('chantier', 'chantiers', { save: 'batch', version: 'version' });

Accessibilité

  • Le <label for> nomme le contrôle (identifiant posé par le champ s’il n’en a pas).
