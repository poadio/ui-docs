Boîte de dialogue

<poad-dialog>

Une boîte modale au-dessus de la page : titre, corps, pied de boutons ; focus piégé et rendu à la fermeture, défilement de la page bloqué, fermeture par la croix, Échap ou le fond selon les options, agrandissement, déplacement, plein écran ou feuille basse sur petit écran.

Démonstration

Angularrendu par @poadio/ui-angularNext.jsrendu par @poadio/ui-reactReactrendu par @poadio/ui-reactVuerendu par @poadio/ui-vueVanillarendu par @poadio/ui-elements

Votre réglage : :root { }

Réglage en direct, dans la démo seulement : rien n’est enregistré.

Chargement de la démo…

La démo ne s’est pas chargée. Une nouvelle version du site vient peut-être d’être publiée.

La boîte est rendue dans l’overlay du CDK. PoadDialogService.open(Composant, { header, data }) ouvre un composant qui injecte PoadDialogRef et POAD_DIALOG_DATA.

import { Component, signal } from '@angular/core';
import { PoadButtonComponent, PoadDialogComponent, PoadDialogFooterDirective, PoadFieldComponent, PoadInputDirective } from '@poadio/ui-angular';

@Component({
  selector: 'app-dialog-demo',
  imports: [PoadButtonComponent, PoadDialogComponent, PoadDialogFooterDirective, PoadFieldComponent, PoadInputDirective],
  template: `
    <div class="demo-row">
      <button poadButton (click)="draft.set(name()); open.set(true)">Rename…</button>
    </div>
    <poad-dialog [(visible)]="open" header="Rename project" maximizable>
      <poad-field label="Name">
        <input poadInput [value]="draft()" (input)="draft.set($any($event.target).value)" />
      </poad-field>
      <div poadDialogFooter>
        <button poadButton severity="secondary" (click)="open.set(false)">Discard</button>
        <button poadButton (click)="name.set(draft()); open.set(false)">Save</button>
      </div>
    </poad-dialog>
    <code>open={{ open() }} · name={{ name() }}</code>
  `,
})
export default class DialogDemo {
  readonly open = signal(false);
  readonly name = signal('api');
  readonly draft = signal('api');
}

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/dialog-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadButton, PoadDialog, PoadField, PoadInput } from '@poadio/ui-react';

export default function DialogDemo() {
  const [open, setOpen] = useState(false);
  const [name, setName] = useState('api');
  const [draft, setDraft] = useState('api');
  return (
    <>
      <div className="demo-row">
        <PoadButton onClick={() => { setDraft(name); setOpen(true); }}>Rename…</PoadButton>
      </div>
      <PoadDialog
        open={open} onOpenChange={setOpen} header="Rename project" maximizable
        footer={
          <>
            <PoadButton severity="secondary" onClick={() => setOpen(false)}>Discard</PoadButton>
            <PoadButton onClick={() => { setName(draft); setOpen(false); }}>Save</PoadButton>
          </>
        }
      >
        <PoadField label="Name">
          <PoadInput value={draft} onChange={(e) => setDraft(e.target.value)} />
        </PoadField>
      </PoadDialog>
      <code>open={String(open)} · name={name}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import DialogDemo from './dialog-demo';

export default function Page() {
  return <DialogDemo />;
}

Pas de Teleport. Pour ouvrir un composant depuis le code : <PoadDynamicDialog /> une fois dans l’application, puis useDialog().open(RenameForm, { header: 'Rename', data }) ; le composant reçoit data en prop et ferme par useDialogRef().close(résultat), lu dans ref.closed (une promesse).

<script setup lang="ts">
import { ref } from 'vue';
import { PoadButton, PoadDialog, PoadField, PoadInput } from '@poadio/ui-vue';

const open = ref(false);
const name = ref('api');
const draft = ref('api');
const start = () => { draft.value = name.value; open.value = true; };
const save = () => { name.value = draft.value; open.value = false; };
</script>

<template>
  <div class="demo-row">
    <PoadButton @click="start">Rename…</PoadButton>
  </div>
  <PoadDialog v-model:open="open" header="Rename project" maximizable>
    <PoadField label="Name">
      <PoadInput v-model="draft" />
    </PoadField>
    <template #footer>
      <PoadButton severity="secondary" @click="open = false">Discard</PoadButton>
      <PoadButton @click="save">Save</PoadButton>
    </template>
  </PoadDialog>
  <code>open={{ open }} · name={{ name }}</code>
</template>

Les enfants sont le corps, slot="footer" le pied. Fermée, la boîte garde son contenu dans l’élément, caché : la page le trouve et le modifie.

<script type="module">import '@poadio/ui-elements/define';</script>

<div class="demo-row">
  <poad-button id="rename">Rename…</poad-button>
</div>
<poad-dialog id="dialog" header="Rename project" maximizable>
  <poad-field label="Name"><input id="draft" value="api" /></poad-field>
  <div slot="footer">
    <poad-button id="discard" severity="secondary">Discard</poad-button>
    <poad-button id="save">Save</poad-button>
  </div>
</poad-dialog>
<code id="dialog-out">open=false · name=api</code>

<script type="module">
  const dialog = document.querySelector('#dialog');
  const draft = document.querySelector('#draft');
  let name = 'api';
  const show = () => {
    document.querySelector('#dialog-out').textContent = `open=${!!dialog.open} · name=${name}`;
  };
  const setOpen = (open) => { dialog.open = open; show(); };
  document.querySelector('#rename').addEventListener('click', () => { draft.value = name; setOpen(true); });
  document.querySelector('#discard').addEventListener('click', () => setOpen(false));
  document.querySelector('#save').addEventListener('click', () => { name = draft.value; setOpen(false); });
  dialog.addEventListener('openchange', show);
</script>

Accessibilité

  • Conteneur role="dialog", aria-modal="true", nommé par son titre (aria-labelledby).
  • Focus piégé dans la boîte, rendu à la fermeture ; défilement de la page bloqué.
  • Croix et bouton agrandir / restaurer nommés par le catalogue.

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius: 4px;            /* Arrondi des coins des contrôles */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius: 0;              /* Arrondi des coins des contrôles */
}
