Bouton

Déclenche une action. Toujours un vrai <button> natif (focus, clavier, formulaire), habillé par les classes du socle : sévérité, variante, taille, état en cours.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular

Une directive, pas un composant : le <button> (ou <a>) reste celui de votre gabarit, avec ses attributs et ses évènements.

import { Component, signal } from '@angular/core';
import { PoadButtonComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-button-demo',
  imports: [PoadButtonComponent],
  template: `
    <div class="demo-row">
      <button poadButton (click)="saves.set(saves() + 1)">Save</button>
      <button poadButton severity="secondary">Cancel</button>
      <button poadButton severity="danger" variant="outline">Delete</button>
      <button poadButton severity="ghost" variant="text">More</button>
      <button poadButton size="sm" [loading]="busy()" (click)="run()">Deploy</button>
      <button poadButton disabled>Disabled</button>
    </div>
    <code>saves={{ saves() }} · busy={{ busy() }}</code>
  `,
})
export default class ButtonDemo {
  readonly saves = signal(0);
  readonly busy = signal(false);
  run(): void {
    this.busy.set(true);
    setTimeout(() => this.busy.set(false), 1500);
  }
}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

PoadButton n’a pas d’état : il se rend aussi dans un composant serveur. Seul le gestionnaire onClick exige un composant client.

// app/button-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadButton } from '@poadio/ui-react';

export default function ButtonDemo() {
  const [saves, setSaves] = useState(0);
  const [busy, setBusy] = useState(false);
  const run = () => {
    setBusy(true);
    setTimeout(() => setBusy(false), 1500);
  };
  return (
    <>
      <div className="demo-row">
        <PoadButton onClick={() => setSaves(saves + 1)}>Save</PoadButton>
        <PoadButton severity="secondary">Cancel</PoadButton>
        <PoadButton severity="danger" variant="outline">Delete</PoadButton>
        <PoadButton severity="ghost" variant="text">More</PoadButton>
        <PoadButton size="sm" loading={busy} onClick={run}>Deploy</PoadButton>
        <PoadButton disabled>Disabled</PoadButton>
      </div>
      <code>saves={saves} · busy={String(busy)}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import ButtonDemo from './button-demo';

export default function Page() {
  return <ButtonDemo />;
}

À quoi ça sert

Une seule action principale (primary) par zone ; les autres en secondary, ghost ou variante text. Pour un état qui se garde, voir le bouton à bascule.

Accessibilité

  • Nommé par son contenu ; un bouton icône seule doit recevoir aria-label.
  • Désactivé : disabled pour le navigateur et aria-disabled="true" pour les technologies d’assistance.
  • En cours : aria-busy="true", indicateur caché (aria-hidden), nom inchangé.
  • À bascule : aria-pressed suit pressed.

Vérifié par le banc de conformité — Ces scénarios sont joués, à l’identique, sur chaque rendu déclaré (angular, react, vue, elements) à chaque push :

  • button/press-disabled-loading-pressed

Attributs vérifiés : accessible name disabled aria-disabled aria-busy aria-pressed aria-hidden

Jetons de thème

Jetons --poad-* lus par la feuille @poadio/ui-core/button.css de @poadio/ui-core. Les redéfinir (globalement ou sur un conteneur) suffit à thémer le composant, dans tous les frameworks à la fois.
