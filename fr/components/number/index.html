Nombre

Saisit un nombre : affiché mis en forme dans la langue (1 234,5), texte brut pendant la frappe, borné et arrondi à la sortie, flèches et boutons au pas. Vide vaut null.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular

Pas encore d’ariaLabel sur poad-number en Angular : nommer le champ par le contexte (légende, aria-labelledby posé par l’application).

import { Component, signal } from '@angular/core';
import { PoadNumberComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-number-demo',
  imports: [PoadNumberComponent],
  template: `
    <div class="demo-row">
      <poad-number [(value)]="timeout" [min]="0" [max]="2000" [step]="10" suffix=" ms" showButtons />
      <poad-number [(value)]="price" [decimals]="2" prefix="€ " />
      <poad-number [value]="8080" disabled />
    </div>
    <code>timeout={{ timeout() }} · price={{ price() }}</code>
  `,
})
export default class NumberDemo {
  readonly timeout = signal<number | null>(1234.5);
  readonly price = signal<number | null>(19.9);
}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/number-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadNumber } from '@poadio/ui-react';

export default function NumberDemo() {
  const [delay, setDelay] = useState<number | null>(1234.5);
  const [price, setPrice] = useState<number | null>(19.9);
  return (
    <>
      <div className="demo-row">
        <PoadNumber value={delay} onValueChange={setDelay} min={0} max={2000} step={10} suffix=" ms" showButtons aria-label="Timeout" />
        <PoadNumber value={price} onValueChange={setPrice} decimals={2} prefix="€ " aria-label="Price" />
        <PoadNumber defaultValue={8080} aria-label="Port" disabled />
      </div>
      <code>timeout={String(delay)} · price={String(price)}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import NumberDemo from './number-demo';

export default function Page() {
  return <NumberDemo />;
}

Rendu par Vanilla

Le préfixe s’écrit prefix-text (l’attribut prefix appartient déjà au DOM).

<script type="module">import '@poadio/ui-elements/define';</script>

<div class="demo-row">
  <poad-number id="timeout" name="timeout" value="1234.5" min="0" max="2000" step="10" suffix=" ms" show-buttons aria-label="Timeout"></poad-number>
  <poad-number id="price" name="price" value="19.9" decimals="2" prefix-text="€ " aria-label="Price"></poad-number>
  <poad-number value="8080" aria-label="Port" disabled></poad-number>
</div>
<code id="number-out">timeout=1234.5 · price=19.9</code>

<script type="module">
  const timeout = document.querySelector('#timeout');
  const price = document.querySelector('#price');
  const show = () => {
    document.querySelector('#number-out').textContent = `timeout=${timeout.value} · price=${price.value}`;
  };
  timeout.addEventListener('change', show);
  price.addEventListener('change', show);
</script>

À quoi ça sert

Pour une quantité, un délai, un prix. Pour un code (téléphone, SIRET), préférer le masque : ce n’est pas un nombre.

Accessibilité

  • Le champ est un role="spinbutton" avec aria-valuenow, aria-valuemin, aria-valuemax ; vide, plus de aria-valuenow.
  • Boutons + / − nommés par le catalogue (« Augmenter », « Diminuer »), hors tabulation, désactivés à la borne.
  • Texte illisible : rien ne change ; virgule ou point décimal acceptés.
