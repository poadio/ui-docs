Choix segmenté

Une rangée de boutons accolés pour choisir une vue, une période, un mode : un seul choix, ou plusieurs avec multiple.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Démonstration

Rendu par Angular
import { Component, signal } from '@angular/core';
import { PoadSegmentedComponent, type PoadSegmentOption } from '@poadio/ui-angular';

@Component({
  selector: 'app-segmented-demo',
  imports: [PoadSegmentedComponent],
  template: `
    <poad-segmented [(value)]="range" [options]="ranges" ariaLabel="Range" />
    <poad-segmented [(value)]="days" [options]="weekdays" multiple shape="pill" size="sm" ariaLabel="Days" />
    <code>range={{ range() }} · days={{ days() }}</code>
  `,
})
export default class SegmentedDemo {
  readonly ranges: PoadSegmentOption[] = [
    { label: 'Day', value: 'day' },
    { label: 'Week', value: 'week', disabled: true },
    { label: 'Month', value: 'month' },
    { label: 'Year', value: 'year' },
  ];
  readonly weekdays: PoadSegmentOption[] = ['Mon', 'Tue', 'Wed', 'Thu', 'Fri'].map((d) => ({ label: d, value: d }));
  readonly range = signal<unknown>('month');
  readonly days = signal<unknown>(['Mon', 'Thu']);
}
Rendu par React (@poadio/ui-react)

Next.js emploie le même paquet que React : la démo est rendue par @poadio/ui-react. Le code montre l'intégration App Router — un composant client ('use client') pour l'état, rendu par une page serveur.

// app/segmented-demo.tsx — composant client (état, gestionnaires)
'use client';

import { useState } from 'react';
import { PoadSegmented, type PoadSegmentOption } from '@poadio/ui-react';

const ranges: PoadSegmentOption[] = [
  { label: 'Day', value: 'day' },
  { label: 'Week', value: 'week', disabled: true },
  { label: 'Month', value: 'month' },
  { label: 'Year', value: 'year' },
];
const weekdays: PoadSegmentOption[] = ['Mon', 'Tue', 'Wed', 'Thu', 'Fri'].map((d) => ({ label: d, value: d }));

export default function SegmentedDemo() {
  const [range, setRange] = useState<unknown>('month');
  const [days, setDays] = useState<unknown>(['Mon', 'Thu']);
  return (
    <>
      <PoadSegmented options={ranges} value={range} onValueChange={setRange} aria-label="Range" />
      <PoadSegmented options={weekdays} value={days} onValueChange={setDays} multiple shape="pill" size="sm" aria-label="Days" />
      <code>range={String(range)} · days={String(days)}</code>
    </>
  );
}

// app/page.tsx — composant serveur : HTML rendu sur le serveur, hydraté au client
import SegmentedDemo from './segmented-demo';

export default function Page() {
  return <SegmentedDemo />;
}

À quoi ça sert

Pour deux à cinq options courtes qui changent l’affichage tout de suite. Pour un choix de formulaire détaillé, les boutons radio.

Clavier

ToucheEffet
→ ↓ ← ↑Déplace le focus vers l’option active suivante ou précédente (en boucle ; miroir de droite à gauche).
Début FinFocus sur la première ou la dernière option active.
Espace EntréeChoisit l’option qui a le focus (la bascule avec multiple).

Accessibilité

  • Conteneur role="group" nommé par aria-label ; chaque option est un <button> avec aria-pressed.
  • Un seul arrêt de tabulation : l’option choisie, sinon la première active ; les options désactivées sont sautées.

Vérifié par le banc de conformité — Ces scénarios sont joués, à l’identique, sur chaque rendu déclaré (angular, react, vue, elements) à chaque push :

  • segmented/roving-focus-single-and-multiple

Jetons de thème

Jetons --poad-* lus par la feuille @poadio/ui-core/segmented.css de @poadio/ui-core. Les redéfinir (globalement ou sur un conteneur) suffit à thémer le composant, dans tous les frameworks à la fois.
