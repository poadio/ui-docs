À quoi ça sert

responsive="scroll" (défaut) : la table défile en largeur, avec au besoin des colonnes figées. priority : chaque colonne a une priority de 1 (jamais masquée) à 5 (masquée en premier) ; sous les seuils (priorityBreakpoints, défaut 1100 / 900 / 720 / 560 px pour 5 / 4 / 3 / 2), elle disparaît et le bouton de détail la montre (showHiddenInExpansion). stack : sous stackAt (640 px), chaque ligne devient une carte où chaque valeur porte le libellé de sa colonne ; un gabarit de carte peut remplacer ce rendu, et les outils de la barre passent derrière un bouton « Filtres ». La largeur est celle du conteneur, pas de l’écran : une table dans un panneau étroit s’adapte aussi.

À quoi ça sert

Pour des colonnes dont le contenu varie (noms longs, descriptions) : l’utilisateur donne la place à ce qu’il lit. resizableColumns pose une poignée au bord de chaque en-tête (une colonne s’en retire avec resizable: false, ou la demande seule avec resizable: true). Glisser la poignée change la largeur ; un double-clic l’ajuste au contenu (en-tête et 200 premières lignes affichées). Au clavier, la poignée est un séparateur : ← → par 8 px (Maj : 40), Début et Fin vont aux bornes minWidth / maxWidth, Entrée ajuste au contenu. La table passe en mise en page fixe : les largeurs demandées sont tenues ; laissez une colonne sans width (une description, par exemple) : elle prend la place qui reste ; si toutes en ont une, une colonne de remplissage vide (cachée aux lecteurs d’écran) prend ce reste. Dans les deux cas, chaque colonne garde exactement sa largeur et la poignée suit le pointeur au pixel (page « Numéros, en-têtes groupés, densité »). Les largeurs choisies vivent dans columnWidths ({ [id de colonne]: px }) : gardez-les avec onColumnResize (React), v-model:column-widths (Vue), la propriété columnWidths (composant web) ou getColumnWidths() (Angular) pour les retrouver à la visite suivante. Pour des largeurs que l’utilisateur ne doit pas changer, donnez width aux colonnes sans poignée.

  • La poignée est un séparateur focalisable (motif « window splitter » : role="separator", aria-orientation="vertical", aria-valuenow / aria-valuemin / aria-valuemax en pixels), nommé « Redimensionner la colonne Service » et décrit par l’aide du clavier (aria-describedby).

Comment changer

Dans la feuille globale de l’application, après les feuilles de @poadio/ui-core : sur :root pour toute l’application, ou sur un conteneur pour une zone seulement. Une couche flottante (menu, liste, dialogue) peut être rendue hors de son conteneur : pour elle, préférez :root.

src/styles.css
/* Toute l’application */
:root {
  --poad-accent: #0b7a5c;        /* Couleur d’accent : bouton principal, case cochée, sélection */
  --poad-radius: 4px;            /* Arrondi des coins des contrôles */
}

/* En thème sombre seulement */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Couleur d’accent : bouton principal, case cochée, sélection */
}

/* Une zone seulement */
.checkout {
  --poad-radius: 0;              /* Arrondi des coins des contrôles */
}
