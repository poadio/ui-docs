Tokens & themes

One source: @poadio/ui-core/tokens.css. Components only read --poad-* tokens — there is no theme selector in their sheets. Redefining a token changes the component in every framework at once.

Three layers

Primitives

Radii, font sizes, durations, fonts: --poad-radius, --poad-font, --poad-dur…

Semantic

Surfaces, text, accent, severities, shadows: --poad-bg, --poad-fg, --poad-accent, --poad-danger…

Components

Control heights, inputs: --poad-control-h, --poad-input-bg… Touch density: poad-touch class on <html>.

Light and dark

The theme is carried by the theme-dark (or theme-light) class on <html> or on an area: aliases are redeclared on the class holder, so a theme can be scoped to any subtree. This site’s moon / sun button does exactly that — every framework’s demo follows.

<!-- Dark theme: a class on <html> (or on any area) -->
<html class="theme-dark">

/* The --poad-* tokens read the application's base variables (--surface-*, --text-*…),
   with a light fallback. For dark, define them under .theme-dark: */
.theme-dark {
  --surface-ground: #0d1117; --surface-section: #161b22; --surface-card: #161b22; --surface-overlay: #21262d;
  --surface-border: #30363d; --surface-hover: #21262d;
  --text-primary: #f0f6fc; --text-secondary: #9ba5b0; --text-muted: #7d8590;
  --input-bg: #0d1117; --input-border: #30363d;
}

Customise

/* The whole application */
:root {
  --poad-accent: #0e7c66;
  --poad-accent-hover: #0b6654;
  --poad-accent-soft: rgba(14, 124, 102, .12);
  --poad-ring: rgba(14, 124, 102, .35);
  --poad-radius: 10px;
}

/* One area only (same mechanism for a local dark theme) */
.marketing { --poad-font: 'Inter', system-ui, sans-serif; }
