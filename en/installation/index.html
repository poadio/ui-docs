Installation

Two packages: your framework’s renderer, and @poadio/ui-core (tokens, stylesheets, message catalogue, icons) shared by every renderer. Pick your framework: every step follows it.

1 · Install the package

Published on npmjs, no private registry to configure.

npm i @poadio/ui-angular @poadio/ui-core
npm i @poadio/ui-react @poadio/ui-core
npm i @poadio/ui-react @poadio/ui-core
npm i @poadio/ui-vue @poadio/ui-core
npm i @poadio/ui-elements @poadio/ui-core

Your framework’s renderer only provides the template; state machines, stylesheets, tokens, icons and message catalogue come from @poadio/ui-core, shared by every renderer.

3 · Use a component

Plug in the library language (English by default), then use the components where you need them.

// app.config.ts
import { ApplicationConfig } from '@angular/core';
import { provideUiI18n, UI_FR } from '@poadio/ui-angular';

export const appConfig: ApplicationConfig = {
  providers: [
    provideUiI18n({ locale: 'fr-FR', messages: UI_FR }), // default: English
  ],
};

// a standalone component imports what it uses
import { PoadSwitchComponent, PoadButtonComponent } from '@poadio/ui-angular';
@Component({ imports: [PoadSwitchComponent, PoadButtonComponent], template: `
  <poad-switch [(value)]="wifi" label="Wi-Fi" />
  <button poadButton (click)="save()">Save</button>` })
// app/layout.tsx — server component
import '@poadio/ui-core/tokens.css';
import '@poadio/ui-core/base.css';
import '@poadio/ui-core/switch.css';
import { Providers } from './providers';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return <html lang="fr"><body><Providers>{children}</Providers></body></html>;
}

// app/providers.tsx — the language provider is a client component
'use client';
import { UiI18nProvider, UI_FR } from '@poadio/ui-react';
export function Providers({ children }: { children: React.ReactNode }) {
  return <UiI18nProvider locale="fr-FR" messages={UI_FR}>{children}</UiI18nProvider>;
}
// main.tsx
import '@poadio/ui-core/tokens.css';
import '@poadio/ui-core/base.css';
import '@poadio/ui-core/switch.css';
import { createRoot } from 'react-dom/client';
import { UiI18nProvider, UI_FR } from '@poadio/ui-react';
import App from './App';

createRoot(document.getElementById('root')!).render(
  <UiI18nProvider locale="fr-FR" messages={UI_FR}>   {/* default: English */}
    <App />
  </UiI18nProvider>,
);
// main.ts (Vite)
import '@poadio/ui-core/tokens.css';
import '@poadio/ui-core/base.css';
import '@poadio/ui-core/switch.css';
import { createApp } from 'vue';
import { createPoadUi, UI_FR } from '@poadio/ui-vue';
import App from './App.vue';

createApp(App).use(createPoadUi({ locale: 'fr-FR', messages: UI_FR })).mount('#app');

// Nuxt — nuxt.config.ts : css: ['@poadio/ui-core/tokens.css', '@poadio/ui-core/base.css', …]
// plugins/poad-ui.ts
export default defineNuxtPlugin((nuxt) => nuxt.vueApp.use(createPoadUi({ locale: 'fr-FR', messages: UI_FR })));
<html lang="fr">
<head>
  <link rel="stylesheet" href="/node_modules/@poadio/ui-core/tokens.css">
  <link rel="stylesheet" href="/node_modules/@poadio/ui-core/base.css">
  <link rel="stylesheet" href="/node_modules/@poadio/ui-core/switch.css">
  <script type="module">
    import { defineElements, registerUiMessages, UI_FR } from '@poadio/ui-elements';
    registerUiMessages('fr', UI_FR);   // each element follows the closest lang
    defineElements();                  // <poad-switch>, <poad-button>… (or { prefix: 'poadx' })
  </script>
</head>
<body>
  <form>
    <poad-switch name="wifi" label="Wi-Fi" checked></poad-switch>
    <poad-button type="submit">Save</poad-button>
  </form>
</body>
</html>

4 · Switch the theme

The theme is carried by a class on <html>. No component contains a theme selector: they only read --poad-*, on every framework at once.

// No component contains a theme selector: they only read --poad-*.
document.documentElement.classList.toggle('theme-dark');

The moon / sun button in the top bar does exactly that: try any page in both themes.

Server rendering

  • Next.js: components with state or handlers start with 'use client' in the package; PoadButton, PoadBadge, PoadTag, PoadAvatar, PoadDivider, PoadSkeleton also render in a server component. HTML comes out of the server, hydration takes over.
  • Nuxt: @poadio/ui-vue touches neither window nor document while rendering; measurements and global listeners only after mount.
  • Web components: honestly, no server rendering of their content. The server writes the tags and their attributes; the inner DOM is drawn at definition time, in the browser. For full server rendering: React (Next.js) or Vue (Nuxt).
  • Angular: compatible with Angular server rendering; the select goes through the CDK overlay (@angular/cdk/overlay-prebuilt.css).

Web components and Angular on the same page

Elements use Angular's selector names (poad-switch…). If an Angular application also loads the web components, register them under another prefix: defineElements({ prefix: 'poadx' }) → <poadx-switch>; otherwise the browser would “upgrade” Angular's hosts.
