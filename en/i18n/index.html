Languages (i18n)

Library rule: no sentence, in any language, is hard-coded in a component. Every visible or screen-reader text comes from a message catalogue — UI_EN, UI_FR, in @poadio/ui-core — or from the application. A guard (tools/check-i18n.mjs) checks it for every package.

Choosing the language

Without any setup, the library speaks English. Each renderer has its idiomatic way to provide the language and catalogue; the language (locale) also drives formats (Intl: numbers, percentages).

Angular
import { provideUiI18n, UiI18n, UI_FR, UI_EN } from '@poadio/ui-angular';

// at start-up
providers: [provideUiI18n({ locale: 'fr-FR', messages: UI_FR })]

// at runtime, without reloading
inject(UiI18n).use('en-GB', UI_EN);
React · Next.js
import { UiI18nProvider, useUiI18n, UI_EN, UI_FR } from '@poadio/ui-react';

<UiI18nProvider locale={lang === 'fr' ? 'fr-FR' : 'en-GB'} messages={lang === 'fr' ? UI_FR : UI_EN}>
  <App />
</UiI18nProvider>

// in a component
const { t, locale } = useUiI18n();   // t('common.close')
Vue · Nuxt
import { createPoadUi, provideUiI18n, useUiI18n, UI_EN, UI_FR } from '@poadio/ui-vue';

app.use(createPoadUi({ locale: 'fr-FR', messages: UI_FR }));

// a subtree, reactive language (ref or getter)
provideUiI18n({ locale: () => lang.value, messages: () => (lang.value === 'fr' ? UI_FR : UI_EN) });
Vanilla
<html lang="fr">
<script type="module">
  import { registerUiMessages, setUiLocale, refreshUi, UI_FR } from '@poadio/ui-elements';
  registerUiMessages('fr', UI_FR);  // English is already there
  setUiLocale('fr');                // when no lang applies
  // each element follows the closest lang; after changing lang: refreshUi()
</script>

On this site, demos of the French version get UI_FR and those of the English version get UI_EN: switch language (top-right button) to see component texts change.

Another language

import { UI_EN, type UiMessages } from '@poadio/ui-core';

// A complete, typed catalogue: TypeScript flags any missing key.
export const UI_DE: UiMessages = {
  ...UI_EN,
  common: { ...UI_EN.common, close: 'Schließen', clear: 'Leeren' },
  field: { ...UI_EN.field, increment: 'Erhöhen', decrement: 'Verringern' },
};

Messages take parameters ({label}, {n}); a text given by the application to an option (for example aria-label, optionalText) always wins over the catalogue.
