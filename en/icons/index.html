Icons

405 named icons, in @poadio/ui-core: 24 × 24 SVG, 2 px stroke, currentColor. One registry for every renderer; the component is documented on its page.

Angular
import { PoadIconComponent, providePoadIcons } from '@poadio/ui-angular';

// <poad-icon name="search" [size]="18" />                decorative (aria-hidden)
// <poad-icon name="trash" label="Delete" />              named (role="img")

// app.config.ts — subset, added icons and aliases
providers: [providePoadIcons({ subset: ['core', 'ui'], icons: { logo: '<path d="…"/>' }, aliases: { pen: 'edit' } })]
React · Next.js
import { PoadIcon, PoadIconProvider } from '@poadio/ui-react';

<PoadIcon name="search" size={18} />
<PoadIcon name="trash" label="Delete" />

// subset, added icons and aliases
<PoadIconProvider subset={['core', 'ui']} icons={{ logo: '<path d="…"/>' }} aliases={{ pen: 'edit' }}>…</PoadIconProvider>
Vue
<PoadIcon name="search" :size="18" />
<PoadIcon name="trash" label="Delete" />

// main.ts
app.use(createPoadUi({ icons: { subset: ['core', 'ui'], aliases: { pen: 'edit' } } }));
Vanilla
<poad-icon name="search" size="18"></poad-icon>
<poad-icon name="trash" label="Delete"></poad-icon>

<script type="module">
  import { setIconRegistry } from '@poadio/ui-elements';
  setIconRegistry({ subset: ['core', 'ui'], aliases: { pen: 'edit' } });
</script>

Without label, an icon is decorative (aria-hidden="true"): its name comes from the surrounding button or text. With label, it becomes a named image. Aliases (pencil → edit, close → x…) are resolved by the registry.
