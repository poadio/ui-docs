Combo (autocomplete)

<poad-combo>

A text field that suggests values as you type: accent- and case-insensitive filter, or an asynchronous search (the last answer wins), keyboard picking, free text or forced selection, chips for multiple values.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular

The panel is rendered in the CDK overlay; suggestions may also stay empty while the application answers (completeMethod).

import { Component, computed, signal } from '@angular/core';
import { PoadComboComponent } from '@poadio/ui-angular';

interface City { name: string }

@Component({
  selector: 'app-combo-demo',
  imports: [PoadComboComponent],
  template: `
    <div class="demo-row">
      <poad-combo [suggestions]="cities" optionLabel="name" [(value)]="city" forceSelection dropdown clearable
        placeholder="City…" style="width: 260px" />
    </div>
    <code>city={{ cityName() }}</code>
  `,
})
export default class ComboDemo {
  readonly cities: City[] = [{ name: 'Lyon' }, { name: 'Lens' }, { name: 'Évry' }, { name: 'Paris' }, { name: 'Pau' }];
  readonly city = signal<unknown>(null);
  readonly cityName = computed(() => (this.city() as City | null)?.name ?? 'none');
}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/combo-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadCombo } from '@poadio/ui-react';

const cities = [{ name: 'Lyon' }, { name: 'Lens' }, { name: 'Évry' }, { name: 'Paris' }, { name: 'Pau' }];

export default function ComboDemo() {
  const [city, setCity] = useState<unknown>(null);
  return (
    <>
      <div className="demo-row">
        <div style={{ width: 260 }}>
          <PoadCombo suggestions={cities} optionLabel="name" value={city} onChange={setCity} forceSelection dropdown clearable
            placeholder="City…" aria-label="City" />
        </div>
      </div>
      <code>city={(city as { name: string } | null)?.name ?? 'none'}</code>
    </>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import ComboDemo from './combo-demo';

export default function Page() {
  return <ComboDemo />;
}

Rendered by Vanilla

Suggestions as JSON, or a function set as a property (combo.suggestions = (q) => fetch(…)); the value (label) is submitted with the <form> under name.

<script type="module">import '@poadio/ui-elements/define';</script>

<div class="demo-row">
  <div style="width: 260px">
    <poad-combo id="city" name="city" option-label="name" force-selection dropdown clearable placeholder="City…" aria-label="City"
      suggestions='[{"name":"Lyon"},{"name":"Lens"},{"name":"Évry"},{"name":"Paris"},{"name":"Pau"}]'></poad-combo>
  </div>
</div>
<code id="combo-out">city=none</code>

<script type="module">
  const city = document.querySelector('#city');
  city.addEventListener('change', () => {
    document.querySelector('#combo-out').textContent = `city=${city.value?.name ?? 'none'}`;
  });
</script>

What it is for

When the list is long or comes from a server (towns, users). For a short, closed list, a select.

Accessibility

  • Field role="combobox" (aria-autocomplete="list", aria-expanded, aria-controls), list role="listbox", suggestions role="option".
  • Active suggestion announced through aria-activedescendant: focus stays in the field.
  • Clear, suggestions and chip-removal buttons named by the catalogue.
