Color picker

Picks a color: saturation / brightness area, hue and opacity with the pointer or the keyboard, HEX and RGB fields, palette, browser eyedropper. Value as CSS text.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular
import { Component, signal } from '@angular/core';
import { PoadColorpickerComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-colorpicker-demo',
  imports: [PoadColorpickerComponent],
  template: `
    <div class="demo-row">
      <poad-colorpicker [(value)]="accent" ariaLabel="Accent" clearable style="width: 200px" />
      <poad-colorpicker [(value)]="overlay" format="rgb" alpha ariaLabel="Overlay" style="width: 240px" />
      <poad-colorpicker [value]="'#16a34a'" ariaLabel="Disabled" disabled style="width: 200px" />
    </div>
    <code>accent={{ accent() }} · overlay={{ overlay() }}</code>
  `,
})
export default class ColorpickerDemo {
  readonly accent = signal<string | null>('#2f6feb');
  readonly overlay = signal<string | null>('rgba(15, 23, 42, 0.6)');
}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/colorpicker-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadColorpicker } from '@poadio/ui-react';

export default function ColorpickerDemo() {
  const [accent, setAccent] = useState<string | null>('#2f6feb');
  const [overlay, setOverlay] = useState<string | null>('rgba(15, 23, 42, 0.6)');
  return (
    <>
      <div className="demo-row">
        <PoadColorpicker value={accent} onChange={setAccent} aria-label="Accent" clearable style={{ width: 200 }} />
        <PoadColorpicker value={overlay} onChange={setOverlay} format="rgb" alpha aria-label="Overlay" style={{ width: 240 }} />
        <PoadColorpicker defaultValue="#16a34a" aria-label="Disabled" disabled style={{ width: 200 }} />
      </div>
      <code>accent={String(accent)} · overlay={String(overlay)}</code>
    </>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import ColorpickerDemo from './colorpicker-demo';

export default function Page() {
  return <ColorpickerDemo />;
}

Rendered by Vanilla

Takes part in the form (name, required); the value is the CSS text.

<script type="module">import '@poadio/ui-elements/define';</script>

<div class="demo-row">
  <div style="width: 200px"><poad-colorpicker id="accent" name="accent" value="#2f6feb" aria-label="Accent" clearable></poad-colorpicker></div>
  <div style="width: 240px"><poad-colorpicker id="overlay" name="overlay" value="rgba(15, 23, 42, 0.6)" format="rgb" alpha aria-label="Overlay"></poad-colorpicker></div>
  <div style="width: 200px"><poad-colorpicker value="#16a34a" aria-label="Disabled" disabled></poad-colorpicker></div>
</div>
<code id="color-out">accent=#2f6feb · overlay=rgba(15, 23, 42, 0.6)</code>

<script type="module">
  const accent = document.querySelector('#accent');
  const overlay = document.querySelector('#overlay');
  const show = () => {
    document.querySelector('#color-out').textContent = `accent=${accent.value} · overlay=${overlay.value}`;
  };
  accent.addEventListener('change', show);
  overlay.addEventListener('change', show);
</script>

Keyboard

KeyEffect
← → ↑ ↓On a handle: moves it (Shift: ×10).
EnterIn the HEX field: applies.
EscCloses; focus returns to the trigger.

Accessibility

  • Trigger with aria-haspopup="dialog" and aria-expanded; panel role="dialog" named by the catalogue.
  • Area and bars are role="slider", named and valued (aria-valuenow, aria-valuetext); palette role="listbox".

Verified by the conformance bench — These scenarios are played, identically, on every declared renderer (angular, react, vue, elements) on every push:

Theme tokens

--poad-* tokens read by the @poadio/ui-core/colorpicker.css, @poadio/ui-core/floating.css stylesheet of @poadio/ui-core. Redefining them (globally or on a container) is enough to theme the component, on every framework at once.
