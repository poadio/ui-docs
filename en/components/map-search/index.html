Map search

<poad-map-search>

A place search field placed in one of the map’s corners: results arrive as you type, you go through them with the mouse or the keyboard, and the chosen place is flown to and marked with a named pin.

What it is for

The geocoder is replaceable: by default the French national address base (BAN, one network request per search), otherwise provider — an object with search(q, options). mapLocalGeocoder(places) searches a closed list without any network, as in this demo. Typing is debounced (debounce), a search starts at three characters (minChars), and a reply that arrives too late is dropped. On mobile, keep it alone in its corner: the list takes the field’s width. To filter the features of a layer that is already loaded, a geocoder is not the tool: a filter on the layer is.

Accessibility

  • The field is a named combobox (the prompt text by default, or ariaLabel); the list is a listbox linked by aria-controls, and the active result is pointed to by aria-activedescendant: focus stays in the field.
  • The number of results is announced (“3 results”, “No results”) through a role="status" region; waiting is shown by a decorative icon, without announcement.
  • The pin placed on the chosen place is named after it (role="img"); the “Clear” button removes it with the search, and gives focus back to the field.

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-accent: #0b7a5c;        /* Accent colour: primary button, checked box, selection */
  --poad-radius-lg: 16px;        /* Large rounding: cards, dialogs, panels */
}

/* In dark theme only */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Accent colour: primary button, checked box, selection */
}

/* One area only */
.checkout {
  --poad-radius-lg: 0;           /* Large rounding: cards, dialogs, panels */
}
