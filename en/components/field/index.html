// app/field-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadField, PoadInput } from '@poadio/ui-react';

  const [email, setEmail] = useState('');

  return (
    <>

        </PoadField>
      </div>

    </>
  );
}

What it is for

For every form field. The error replaces the hint while it is there; only show it after a first attempt by the user.

Binding to a store

Declare the store once, then give it to the component: store (the object, or its name) and field or fields. Reading and writing go through the signed-in user’s RLS. All the details: Stores (@poadio/data).

import { store } from '@poadio/data';

// one record
const chantier = store.table('chantier', 'chantiers', { key: 42, version: 'version' });
// or a ROW store: the field of its current record (cursor: first, next, prior, last)
// const chantier = store.table('chantier', 'chantiers', { save: 'batch', version: 'version' });

Accessibility

  • The <label for> names the control (the field sets an id if it has none).
  • The control is described (aria-describedby) by the hint, then by the error that replaces it; with neither, nothing describes it.
  • In error: aria-invalid="true" on the control, role="alert" on the message.

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-accent: #0b7a5c;        /* Accent colour: primary button, checked box, selection */
  --poad-radius: 4px;            /* Corner rounding of controls */
}

/* In dark theme only */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Accent colour: primary button, checked box, selection */
}

/* One area only */
.checkout {
  --poad-radius: 0;              /* Corner rounding of controls */
}
