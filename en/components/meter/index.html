Meter

Shows a measure within known bounds, split into segments: disk space, quota, budget used.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular
import { Component } from '@angular/core';
import { PoadMeterComponent, type PoadMeterValue } from '@poadio/ui-angular';

@Component({
  selector: 'app-meter-demo',
  imports: [PoadMeterComponent],
  template: `
    <div class="demo-col" style="width: min(100%, 480px)">
      <poad-meter [values]="disk" unit="Gi" showRemaining ariaLabel="Disk" />
      <poad-meter [values]="[{ label: 'CPU', value: 72, severity: 'warning' }]" unit="%" size="sm" ariaLabel="CPU" />
    </div>
  `,
})
export default class MeterDemo {
  readonly disk: PoadMeterValue[] = [
    { label: 'Database', value: 42, severity: 'primary' },
    { label: 'Storage', value: 18.5, severity: 'info' },
    { label: 'Logs', value: 6, severity: 'warning' },
  ];
}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/meter-demo.tsx — client component (state, handlers)
'use client';

import { PoadMeter } from '@poadio/ui-react';

const disk = [
  { label: 'Database', value: 42, severity: 'primary' as const },
  { label: 'Storage', value: 18.5, severity: 'info' as const },
  { label: 'Logs', value: 6, severity: 'warning' as const },
];

export default function MeterDemo() {
  return (
    <div className="demo-col" style={{ width: 'min(100%, 480px)' }}>
      <PoadMeter values={disk} unit="Gi" showRemaining aria-label="Disk" />
      <PoadMeter values={[{ label: 'CPU', value: 72, severity: 'warning' }]} unit="%" size="sm" aria-label="CPU" />
    </div>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import MeterDemo from './meter-demo';

export default function Page() {
  return <MeterDemo />;
}

What it is for

For a quantity, not a task in progress (prefer the progress bar). The legend formats numbers in the current language; the “remaining” label comes from the catalogue.

Keyboard

No keyboard interaction: display component.

Accessibility

  • role="meter" with aria-valuenow (sum of the segments), aria-valuemin, aria-valuemax, named by aria-label.
  • Each segment has a full title (“Used: 62 Gi (62%)”); the legend repeats value and percentage as text.

Theme tokens

--poad-* tokens read by the @poadio/ui-core/meter.css stylesheet of @poadio/ui-core. Redefining them (globally or on a container) is enough to theme the component, on every framework at once.
