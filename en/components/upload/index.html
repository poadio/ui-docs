File upload

<poad-upload>

An area to drop files on, or that opens the system file picker: each file is checked (type, size, count), listed with its size and status, removable, then uploaded with its progress.

Upload through url with HttpClient (provideHttpClient() required), or customUpload + (uploadHandler); the list is read with files(); poadUploadItem, poadUploadEmpty, poadUploadContent templates.

import { Component, signal } from '@angular/core';
import { PoadUploadComponent, type PoadUploadHandlerEvent } from '@poadio/ui-angular';

@Component({
  selector: 'app-upload-demo',
  imports: [PoadUploadComponent],
  template: `
    <poad-upload class="demo-upload" multiple accept="image/*,.pdf" [maxFileSize]="1048576" [maxFiles]="3" customUpload
      hint="PNG, JPG or PDF · 1 MB max · 3 files" (uploadHandler)="send($event)" (uploaded)="last.set($event.file.name)" />
    <poad-upload mode="basic" selectOnly chooseLabel="Attach a file" (select)="picked.set($event[0]?.name ?? '')" />
    <code>uploaded={{ last() }} · attached={{ picked() }}</code>
  `,
})
export default class UploadDemo {
  readonly last = signal('');
  readonly picked = signal('');
  // envoi simulé, sans réseau : la progression avance par quarts, puis le fichier est « envoyé »
  send({ files, progress, done }: PoadUploadHandlerEvent): void {
    files.forEach((_, i) => {
      let pct = 0;
      const timer = setInterval(() => {
        pct += 25;
        if (pct < 100) progress(i, pct);
        else { clearInterval(timer); done(i, true); }
      }, 200);
    });
  }
}

<script type="module">
  const out = { uploaded: '', attached: '' };
  const show = () => { document.querySelector('#upload-out').textContent = `uploaded=${out.uploaded} · attached=${out.attached}`; };
  // envoi simulé, sans réseau : la progression avance par quarts, puis le fichier est « envoyé »
  document.querySelector('#docs').addEventListener('uploadrequest', ({ detail: { files, progress, done } }) => {
    files.forEach((_, i) => {
      let pct = 0;
      const timer = setInterval(() => {
        pct += 25;
        if (pct < 100) progress(i, pct);
        else { clearInterval(timer); done(i, true); }
      }, 200);
    });
  });
  document.querySelector('#docs').addEventListener('uploaded', ({ detail }) => { out.uploaded = detail.file.name; show(); });
  // le fichier choisi part avec le formulaire (name="attachment") : new FormData(form).get('attachment')
  document.querySelector('#attach poad-upload').addEventListener('fileselect', ({ detail }) => { out.attached = detail[0]?.name ?? ''; show(); });
</script>

What it is for

To attach one or more files to a form or send them to a server. basic mode (one button) for a single file in a tight form; dropzone when the application uploads by itself, without buttons.

Keyboard

KeyEffect
Enter SpaceOn the area: opens the system file picker. On “Remove”: removes the row, focus moves to the next file (otherwise to the area).
TabArea, then each file’s “Remove” button, then “Upload” and “Remove all”. The hidden native field is not in the tab order.

Accessibility

  • The area is a focusable role="button", named by its texts; when disabled, it leaves the tab order and carries aria-disabled. Dropping is never the only way: click and keyboard open the picker.
  • The native <input type="file"> picks the files but stays hidden (aria-hidden, tabindex="-1"): a single tab stop.
  • Each remove button is named by its file (“Remove report.pdf”); the progress bar is a role="progressbar" named by the file, with the percentage written next to it.
  • A refused file stays in the list with its message (type, size, count), as text, not only as color; the refusals of an addition are also announced in a polite region (role="status", visually hidden).

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-accent: #0b7a5c;        /* Accent colour: primary button, checked box, selection */
  --poad-radius: 4px;            /* Corner rounding of controls */
}

/* In dark theme only */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Accent colour: primary button, checked box, selection */
}

/* One area only */
.checkout {
  --poad-radius: 0;              /* Corner rounding of controls */
}
