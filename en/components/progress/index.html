import { PoadButtonComponent, PoadProgressComponent } from '@poadio/ui-angular';

  selector: 'app-progress-demo',

      <poad-progress indeterminate ariaLabel="Upload" />
    </div>
    <div class="demo-row">
      <button poadButton severity="secondary" size="sm" (click)="build.set((build() + 10) % 110)">+10 %</button>

    </div>
  `,
})
export default class ProgressDemo {
  readonly build = signal(40);
}

}

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-accent: #0b7a5c;        /* Accent colour: primary button, checked box, selection */
  --poad-font-size-sm: 0.8125rem; /* Small text: hints, counters, badges */
}

/* In dark theme only */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Accent colour: primary button, checked box, selection */

/* One area only */
.checkout {

Accessibility

  • The blocked container carries aria-busy="true"; the veil is a status region (role="status", aria-live="polite") announcing the loading and the message.
  • The content under the veil is inert: it gets neither focus nor keyboard, not only no more mouse.
  • Fade-in off under prefers-reduced-motion.
