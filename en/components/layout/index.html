Layout

<poad-grid>

The layout bricks: stack, wrapping cluster, responsive grid (and column), two areas, sidebar, center, page container and spacer. Gaps come from the --poad-gap-* tokens; never margins on the children.

What it is for

A grid with cols="1 sm:2 lg:4" follows the WINDOW breakpoint (a page decision); min="220px" fills as many columns as the CONTAINER accepts (better inside a component). The sidebar goes below the content when space runs out, or always below collapseAt.

Keyboard

No keyboard interaction: display component.

Accessibility

  • No role or ARIA attribute: plain <div>s (the sidebar panel is an <aside> in React and Vue); the document order stays the reading order.
  • A side="left" sidebar panel is moved first with order: it stays after the content for a screen reader and for Tab.

Theme tokens

Layout is tuned by 2 CSS --poad-* tokens. Change a token’s value in your application’s global stylesheet: the component follows, on every framework at once. Values: this site’s base theme, light and dark.

LayoutBreakpoints, gaps, application bars

TokenWhat it changesLightDark
Panel width of a sidebar layout (set by its width property)set by the applicationset by the application
Minimum content width of a sidebar layout before the panel goes below (contentMin property)set by the applicationset by the application

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
app/globals.css
src/index.css
src/style.css
styles.css
/* styles.css — <link rel="stylesheet" href="styles.css"> after the @poadio/ui-core sheets */
