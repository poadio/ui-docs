<poad-grid>

The layout bricks: stack, wrapping cluster, responsive grid (and column), two areas, sidebar, center, page container and spacer. Gaps come from the --poad-gap-* tokens; never margins on the children.

What it is for

A grid with cols="1 sm:2 lg:4" follows the WINDOW breakpoint (a page decision); min="220px" fills as many columns as the CONTAINER accepts (better inside a component). The sidebar goes below the content when space runs out, or always below collapseAt.

Accessibility

  • No role or ARIA attribute: plain <div>s (the sidebar panel is an <aside> in React and Vue); the document order stays the reading order.
  • A side="left" sidebar panel is moved first with order: it stays after the content for a screen reader and for Tab.

What it is for
