Scheduler

<poad-scheduler>

Resources as rows, time along the horizontal axis: who does what, and when. A task assigned to several resources draws a bar on every row, overlaps stack up and, when allowed, you move, resize, reassign and create with the mouse, the finger or the keyboard.

import {
  PoadSchedulerComponent, PoadSegmentedComponent, type PoadPlan, type PoadSchedulerAssignEvent, type PoadSchedulerChangeEvent, type PoadSchedulerCreateEvent,

} from '@poadio/ui-angular';

const PLAN: PoadPlan = {
  resources: [
    { id: 'field', label: 'Field team' },
    { id: 'claire', label: 'Claire Fontaine', parent: 'field', color: '#2f6feb' },
    { id: 'marc', label: 'Marc Delorme', parent: 'field', color: '#a371f7' },
    { id: 'van', label: 'Inspection van', color: '#0f9d58' },

    { id: 's2', label: 'Bridge inspection', start: '2026-09-16T08:00', end: '2026-09-17T12:00', assignments: [{ resource: 'claire' }, { resource: 'van' }] },
    { id: 's3', label: 'Design review', start: '2026-09-14T09:00', end: '2026-09-14T17:00', assignments: [{ resource: 'marc' }] },
    { id: 's4', label: 'Report writing', start: '2026-09-15T09:00', end: '2026-09-17T17:00', assignments: [{ resource: 'marc' }] },
    { id: 's5', label: 'Servicing', start: '2026-09-21T08:00', end: '2026-09-21T17:00', assignments: [{ resource: 'van' }], locked: true },
    { id: 's6', label: 'Load test', duration: '1d' },
  ],
};
const hm = (d: Date) => `${d.getDate()}/${d.getHours()}:${String(d.getMinutes()).padStart(2, '0')}`;

@Component({
  selector: 'app-scheduler-demo',
  imports: [PoadSchedulerComponent, PoadSegmentedComponent],
  template: `
    <poad-segmented [(value)]="scale" [options]="scales" ariaLabel="Scale" size="sm" />
    <poad-scheduler class="demo-scheduler" [plan]="plan()" [scale]="scale()" [date]="date" [today]="today" editable ariaLabel="Team schedule"
      (eventMove)="change($event)" (eventResize)="change($event)" (eventAssign)="assign($event)" (eventCreate)="create($event)" (eventSchedule)="schedule($event)" />
    <code>{{ last() }}</code>
  `,
})
export default class SchedulerDemo {
  readonly scales: PoadSegmentOption[] = [{ label: 'Day', value: 'day' }, { label: 'Week', value: 'week' }, { label: 'Month', value: 'month' }];
  readonly scale = signal<PoadSchedulerScale>('week');
  readonly date = new Date(2026, 8, 14);
  readonly today = new Date(2026, 8, 15, 11);
  readonly plan = signal(PLAN);
  readonly last = signal('last=—');
  private nextId = 7;
  /** The scheduler never writes: the application applies the change to its own document. */
  change(e: PoadSchedulerChangeEvent): void {
    this.plan.update((p) => ({ ...p, tasks: p.tasks!.map((t) => (t.id === e.occurrence.taskId ? { ...t, start: e.start, end: e.end } : t)) }));
    this.last.set(`last=${e.occurrence.task.label} ${hm(e.start)}`);
  }
  assign(e: PoadSchedulerAssignEvent): void {
    this.plan.update((p) => ({ ...p, tasks: p.tasks!.map((t) => (t.id === e.occurrence.taskId ? { ...t, assignments: t.assignments!.map((a, i) => (i === e.assignmentIndex ? { ...a, resource: e.to } : a)) } : t)) }));
    this.last.set(`last=${e.occurrence.task.label} → ${e.to}`);
  }
  create(e: PoadSchedulerCreateEvent): void {
    this.plan.update((p) => ({ ...p, tasks: [...p.tasks!, { id: `s${this.nextId++}`, label: 'New task', start: e.start, end: e.end, assignments: [{ resource: e.resource }] }] }));
    this.last.set(`last=created ${e.resource} ${hm(e.start)}`);
  }
  schedule(e: PoadSchedulerScheduleEvent): void {
    this.plan.update((p) => ({ ...p, tasks: p.tasks!.map((t) => (t.id === e.task.id ? { ...t, start: e.start, end: e.end, duration: undefined, assignments: [{ resource: e.resource }] } : t)) }));
    this.last.set(`last=${e.task.label} → ${e.resource} ${hm(e.start)}`);
  }
}

What it is for

To answer “who is free on Thursday?”. For “what is happening on the 17th?”, the calendar; for linked tasks over time, the Gantt chart. The scheduler never writes: it emits the intention (new dates, new resource) and keeps the display up to date while the application applies it. A task without dates or without a resource goes to the “unplanned” tray, counted, from which you drop it on a row.

Keyboard

KeyEffect
TabMoves from bar to bar (they are buttons).
Enter SpaceOpens the task (eventClick).
Ctrl ← →Ctrl (⌘ on Mac) + ← / →: moves the task by one day (by one snap step at the day scale, 30 min by default).
Shift ← →Shift + ← / →: moves the end of the task (shortens or lengthens it) by the same step.
Ctrl ↑ ↓Ctrl + ↑ / ↓: assigns the bar to the resource of the neighbouring row, dates unchanged. Focus follows the bar.
EscDuring a drag: cancels, the bar goes back to its place.

Accessibility

  • A named region; every bar is a button whose name gives the task, its period and “multi-resource” where relevant; the tooltip adds the reason of a lock (locked task, occurrence of a series).
  • Editing on: every movable bar is described by the keyboard help (aria-describedby); every gesture is announced in an aria-live region, with the landing date or the resource in the language (““Site survey” moved to Tuesday 15 September”, ““Site survey” assigned to Marc Delorme”); focus follows the bar, even when it changes rows.
  • Dates in local time, daylight-saving changes included; day names in the language. Gestures snap: to the day at the week and month scales, to the step (snap) at the day scale. A vertical move only changes the resource, never the dates: one intention at a time.
  • Below the mobile breakpoint, auto switches to a list by resource: a fourteen-day grid at 390 px shows nothing any more.

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-accent: #0b7a5c;        /* Accent colour: primary button, checked box, selection */
  --poad-radius-pill: 6px;       /* Full rounding: pills, badges, tags */
}

/* In dark theme only */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Accent colour: primary button, checked box, selection */
}

/* One area only */
.checkout {
  --poad-radius-pill: 0;         /* Full rounding: pills, badges, tags */
}
