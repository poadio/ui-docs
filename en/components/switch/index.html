Switch

Turns a setting on or off, taking effect immediately. A real role="switch" button, named by its label.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular
import { Component, signal } from '@angular/core';
import { PoadSwitchComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-switch-demo',
  imports: [PoadSwitchComponent],
  template: `
    <div class="demo-row">
      <poad-switch [(value)]="wifi" label="Wi-Fi" (changed)="last.set($event)" />
      <poad-switch [(value)]="bluetooth" label="Bluetooth" labelPosition="left" />
      <poad-switch [value]="true" label="Disabled" disabled />
      <poad-switch [value]="true" label="Read-only" readonly />
      <poad-switch [(value)]="wifi" size="sm" ariaLabel="Wi-Fi (small)" />
    </div>
    <code>wifi={{ wifi() }} · bluetooth={{ bluetooth() }} · changed={{ last() }}</code>
  `,
})
export default class SwitchDemo {
  readonly wifi = signal(true);
  readonly bluetooth = signal(false);
  readonly last = signal<boolean | null>(null);
}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

PoadSwitch holds state: it starts with 'use client' in the package. A server page can import and render it; only the component that holds the state (useState) has to be a client component.

// app/switch-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadSwitch } from '@poadio/ui-react';

export default function SwitchDemo() {
  const [wifi, setWifi] = useState(true);
  const [bluetooth, setBluetooth] = useState(false);
  return (
    <>
      <div className="demo-row">
        <PoadSwitch label="Wi-Fi" checked={wifi} onCheckedChange={setWifi} />
        <PoadSwitch label="Bluetooth" labelPosition="left" checked={bluetooth} onCheckedChange={setBluetooth} />
        <PoadSwitch label="Disabled" defaultChecked disabled />
        <PoadSwitch label="Read-only" defaultChecked readOnly />
        <PoadSwitch aria-label="Wi-Fi (small)" size="sm" checked={wifi} onCheckedChange={setWifi} />
      </div>
      <code>wifi={String(wifi)} · bluetooth={String(bluetooth)}</code>
    </>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import SwitchDemo from './switch-demo';

export default function Page() {
  return <SwitchDemo />;
}

What it is for

Use it for a setting that applies right away. In a form that is submitted later, prefer a checkbox.

Keyboard

KeyEffect
Space EnterToggles (unless disabled or read-only).

Accessibility

  • role="switch" and aria-checked on a native <button>.
  • Named by its <label for>; without a visible label, by aria-label (and no aria-labelledby left).
  • Disabled: native disabled attribute. Read-only: stays focusable, refuses gestures.

Verified by the conformance bench — These scenarios are played, identically, on every declared renderer (angular, react, vue, elements) on every push:
