Tooltip

<poad-tooltip>

A short text that describes an element on hover and on keyboard focus: show and hide delays, flips against the window edge, Escape hides it.

A directive on the described element ([poadTooltip]); the tooltip is rendered in the CDK overlay.

import { Component } from '@angular/core';
import { PoadButtonComponent, PoadTooltipDirective } from '@poadio/ui-angular';

@Component({
  selector: 'app-tooltip-demo',
  imports: [PoadButtonComponent, PoadTooltipDirective],
  template: `
    <div class="demo-row">
      <button poadButton variant="outline" poadTooltip="Restart the pods">Restart</button>
      <button poadButton variant="outline" poadTooltip="Shown below" tooltipPosition="bottom">Below</button>
      <button poadButton variant="outline" poadTooltip="On the end side, after 100 ms" tooltipPosition="right" [tooltipDelay]="100">End</button>
      <button poadButton variant="outline" poadTooltip="Never shown" tooltipDisabled>Disabled</button>
    </div>
  `,
})
export default class TooltipDemo {}

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/tooltip-demo.tsx — client component (state, handlers)
'use client';

import { PoadButton, PoadTooltip } from '@poadio/ui-react';

export default function TooltipDemo() {
  return (
    <div className="demo-row">
      <PoadTooltip content="Restart the pods"><PoadButton variant="outline">Restart</PoadButton></PoadTooltip>
      <PoadTooltip content="Shown below" placement="bottom"><PoadButton variant="outline">Below</PoadButton></PoadTooltip>
      <PoadTooltip content="On the end side, after 100 ms" placement="right" delay={100}><PoadButton variant="outline">End</PoadButton></PoadTooltip>
      <PoadTooltip content="Never shown" disabled><PoadButton variant="outline">Disabled</PoadButton></PoadTooltip>
    </div>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import TooltipDemo from './tooltip-demo';

export default function Page() {
  return <TooltipDemo />;

What it is for

To name an icon button or clarify an action. Never for essential information: it does not exist for touch without hover, nor for interactive content (use a popover).

Keyboard

KeyEffect
TabKeyboard focus on the element shows the tooltip.
EscHides the tooltip.

Accessibility

  • role="tooltip"; when shown, it describes its element (aria-describedby), which keeps its own descriptions.
  • Shown on keyboard focus as on hover; Escape hides it without moving focus.

Stylesheets to import

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-tooltip-bg: #0b7a5c;    /* Tooltip background (inverted contrast) */
}

/* One area only */
.checkout {
  --poad-tooltip-bg: #0b7a5c;    /* Tooltip background (inverted contrast) */
}
