Icon

<poad-icon>

Draws an icon from the library's named set (the same in every framework), as a stroked SVG that takes the text colour.

What it is for

Decorative by default (hidden from screen readers); give it a label as soon as it carries a meaning nothing else conveys. The full set and the registry are described on the Icons page.

Keyboard

No keyboard interaction: display component.

Accessibility

  • Host role="img"; without label, aria-hidden="true" and no aria-label.
  • With label: named by it, no more aria-hidden.
  • <svg viewBox="0 0 24 24"> in currentColor: contrast is that of the surrounding text.

Catalogue texts

No library text: everything displayed comes from the application.

Stylesheets to import

Nothing to import for this component: it bundles its own sheet (@poadio/ui-core/icon.css) at build time. Only tokens.css and base.css are loaded once, globally (see Installation).

Theme tokens

Icon is tuned by 0 CSS --poad-* tokens. Change a token’s value in your application’s global stylesheet: the component follows, on every framework at once. Values: this site’s base theme, light and dark.

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

app/globals.css
src/index.css
src/style.css
styles.css
