Icon

<poad-icon>

Draws an icon from the library's named set (the same in every framework), as a stroked SVG that takes the text colour.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular
import { Component } from '@angular/core';
import { PoadIconComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-icon-demo',
  imports: [PoadIconComponent],
  template: `
    <div class="demo-row">
      <poad-icon name="search" />
      <poad-icon name="bell" [size]="20" />
      <poad-icon name="settings" [size]="24" [strokeWidth]="1.5" />
      <poad-icon name="alert-triangle" label="Warning" filled />
      <poad-icon name="loader" label="Loading" spin />
      <poad-icon name="map-pin" flip="h" />
      <poad-icon name="edit" [rotate]="90" />
    </div>
  `,
})
export default class IconDemo {}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/icon-demo.tsx — client component (state, handlers)
'use client';

import { PoadIcon } from '@poadio/ui-react';

export default function IconDemo() {
  return (
    <div className="demo-row">
      <PoadIcon name="search" />
      <PoadIcon name="bell" size={20} />
      <PoadIcon name="settings" size={24} strokeWidth={1.5} />
      <PoadIcon name="alert-triangle" label="Warning" filled />
      <PoadIcon name="loader" label="Loading" spin />
      <PoadIcon name="map-pin" flip="h" />
      <PoadIcon name="edit" rotate={90} />
    </div>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import IconDemo from './icon-demo';

export default function Page() {
  return <IconDemo />;
}

What it is for

Decorative by default (hidden from screen readers); give it a label as soon as it carries a meaning nothing else conveys. The full set and the registry are described on the Icons page.

Keyboard

No keyboard interaction: display component.

Accessibility

  • Host role="img"; without label, aria-hidden="true" and no aria-label.
  • With label: named by it, no more aria-hidden.
  • <svg viewBox="0 0 24 24"> in currentColor: contrast is that of the surrounding text.

Verified by the conformance bench — These scenarios are played, identically, on every declared renderer (angular, react, vue, elements) on every push:

  • icon/named-decorative-or-labelled

Attributes checked : role aria-hidden aria-label accessible name

Catalogue texts

No library text: everything displayed comes from the application.

Theme tokens

--poad-* tokens read by the @poadio/ui-core/icon.css stylesheet of @poadio/ui-core. Redefining them (globally or on a container) is enough to theme the component, on every framework at once.
