Timeline

<poad-timeline>

Events in order, along a line: a marker (coloured dot or icon) per event, its content and, opposite, its date. Past events and the current one stand out.

interface Job { title: string; date: string; icon?: string; severity?: string }

@Component({
  selector: 'app-timeline-demo',
  imports: [PoadTimelineComponent, PoadTimelineContentDirective, PoadTimelineOppositeDirective],
  template: `
    <div class="demo-wide">
      <poad-timeline [events]="jobs" align="alternate" [activeIndex]="1">
        <ng-template poadTimelineOpposite let-e>{{ e.date }}</ng-template>
        <ng-template poadTimelineContent let-e><strong>{{ e.title }}</strong></ng-template>
      </poad-timeline>
    </div>
  `,
})

  ];
}

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/timeline-demo.tsx — client component (state, handlers)
'use client';

import { PoadTimeline } from '@poadio/ui-react';

interface Job { title: string; date: string; icon?: string; severity?: string }

const jobs: Job[] = [
  { title: 'Build', date: '09:12', icon: 'check', severity: 'success' },
  { title: 'Tests', date: '09:15' },
  { title: 'Deploy', date: '09:21' },
];

export default function TimelineDemo() {
  return (
    <div className="demo-wide">
      <PoadTimeline<Job>
        events={jobs} align="alternate" activeIndex={1}
        opposite={(e) => e.date} content={(e) => <strong>{e.title}</strong>}
      />
    </div>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import TimelineDemo from './timeline-demo';

export default function Page() {
  return <TimelineDemo />;
}

<script type="module">
  const timeline = document.querySelector('#jobs');
  timeline.events = [
    { title: 'Build', date: '09:12', icon: 'check', severity: 'success' },
    { title: 'Tests', date: '09:15' },
    { title: 'Deploy', date: '09:21' },

  timeline.renderContent = (e) => Object.assign(document.createElement('strong'), { textContent: e.title });

What it is for

For a history or a sequence (deployment, the life of an asset). For a flow the user goes through step by step, a stepper.

Keyboard

No keyboard interaction: display component.

Accessibility

  • List (role="list"), one listitem per event: the number of events is announced, in order.
  • Markers and connectors are decorative: the state (past, current) is said in the content if the application needs it.
  • Right to left, the line and the alternation follow the text direction.

Catalogue texts

No library text: everything displayed comes from the application.

Stylesheets to import

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-accent: #0b7a5c;        /* Accent colour: primary button, checked box, selection */
  --poad-font-size: 0.875rem;    /* Base text size */
}

/* In dark theme only */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Accent colour: primary button, checked box, selection */
}

/* One area only */
.checkout {
  --poad-font-size: 1rem;        /* Base text size */
}
