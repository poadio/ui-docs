Data table

<poad-table>

Rows and columns: sorting by click (single or multiple, in the language’s order), pagination, server-side data, row selection with a Shift range, empty and loading states. With a selection, the table becomes a grid whose rows are reachable from the keyboard.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular

Columns as <poad-column> (poadCellTemplate templates) or as data through [colonnes]. The ui-angular table already carries later slices (filters, tree, editing…): they will be documented here once they are on all four renderers.

import { Component, computed, signal } from '@angular/core';
import { PoadCellTemplateDirective, PoadColumnComponent, PoadTableComponent } from '@poadio/ui-angular';

interface Project { id: number; name: string; env: string; pods: number }

@Component({
  selector: 'app-table-demo',
  imports: [PoadTableComponent, PoadColumnComponent, PoadCellTemplateDirective],
  template: `
    <div class="demo-wide">
      <poad-table [value]="projects" dataKey="id" title="Projects" selectionMode="multiple" [(selection)]="selection"
        paginator [rows]="5" [rowsPerPageOptions]="[5, 10]">
        <poad-column field="name" header="Name" sortable>
          <ng-template poadCellTemplate let-row><strong>{{ row.name }}</strong></ng-template>
        </poad-column>
        <poad-column field="env" header="Env" />
        <poad-column field="pods" header="Pods" dataType="number" sortable />
      </poad-table>
    </div>
    <code>selected={{ ids() }}</code>
  `,
})
export default class TableDemo {
  readonly projects: Project[] = [
    { id: 1, name: 'gestion', env: 'recette', pods: 4 }, { id: 2, name: 'inventaire', env: 'neo', pods: 0 },
    { id: 3, name: 'demo2', env: 'neo', pods: 2 }, { id: 4, name: 'best', env: 'recette', pods: 12 },
    { id: 5, name: 'demo10', env: 'recette', pods: 1 }, { id: 6, name: 'atlas', env: 'neo', pods: 7 },
    { id: 7, name: 'zephyr', env: 'neo', pods: 3 }, { id: 8, name: 'cartographie', env: 'recette', pods: 5 },
  ];
  readonly selection = signal<Project | Project[] | null>([]);
  readonly ids = computed(() => ((this.selection() ?? []) as Project[]).map((p) => p.id).join(',') || 'none');
}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/table-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadTable, type PoadTableColumn } from '@poadio/ui-react';

interface Project { id: number; name: string; env: string; pods: number }
const projects: Project[] = [
  { id: 1, name: 'gestion', env: 'recette', pods: 4 }, { id: 2, name: 'inventaire', env: 'neo', pods: 0 },
  { id: 3, name: 'demo2', env: 'neo', pods: 2 }, { id: 4, name: 'best', env: 'recette', pods: 12 },
  { id: 5, name: 'demo10', env: 'recette', pods: 1 }, { id: 6, name: 'atlas', env: 'neo', pods: 7 },
  { id: 7, name: 'zephyr', env: 'neo', pods: 3 }, { id: 8, name: 'cartographie', env: 'recette', pods: 5 },
];
const columns: PoadTableColumn<Project>[] = [
  { field: 'name', header: 'Name', sortable: true, cell: ({ row }) => <strong>{row.name}</strong> },
  { field: 'env', header: 'Env' },
  { field: 'pods', header: 'Pods', dataType: 'number', sortable: true },
];

export default function TableDemo() {
  const [selection, setSelection] = useState<Project[]>([]);
  return (
    <>
      <div className="demo-wide">
        <PoadTable value={projects} columns={columns} dataKey="id" title="Projects" selectionMode="multiple" selection={selection}
          onSelectionChange={(s) => setSelection(s as Project[])} paginator defaultRows={5} rowsPerPageOptions={[5, 10]} />
      </div>
      <code>selected={selection.map((p) => p.id).join(',') || 'none'}</code>
    </>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import TableDemo from './table-demo';

export default function Page() {
  return <TableDemo />;
}

Rendered by Vue

Columns as data (:columns) and / or <PoadColumn> in the slot (its default slot is the cell). For 10,000 rows, pass the array through shallowRef.

Rendered by Vanilla

heading and body-max-height replace title and scroll-height (properties of every DOM element). selectionchange is also a native text-selection event: read event.detail.

<div class="demo-wide">

</div>
<code id="table-out">selected=none</code>

<script type="module">
  const table = document.querySelector('#projects');
  table.value = [
    { id: 1, name: 'gestion', env: 'recette', pods: 4 }, { id: 2, name: 'inventaire', env: 'neo', pods: 0 },
    { id: 3, name: 'demo2', env: 'neo', pods: 2 }, { id: 4, name: 'best', env: 'recette', pods: 12 },
    { id: 5, name: 'demo10', env: 'recette', pods: 1 }, { id: 6, name: 'atlas', env: 'neo', pods: 7 },
    { id: 7, name: 'zephyr', env: 'neo', pods: 3 }, { id: 8, name: 'cartographie', env: 'recette', pods: 5 },
  ];
  table.renderCell = ({ row, column }) => (column.field === 'name' ? Object.assign(document.createElement('strong'), { textContent: row.name }) : undefined);
  table.addEventListener('selectionchange', (e) => {
    document.querySelector('#table-out').textContent = `selected=${e.detail.map((p) => p.id).join(',') || 'none'}`;
  });
</script>

What it is for

To compare records of the same shape (projects, deployments, users). This first slice covers columns, sorting, pages and selection; filters, tree, groups, frozen columns, editing and the column menu come in later slices. For a list of cards, a plain v-for / map.

Accessibility

  • Without selection: a native <table> (scope="col" headers). With selection: role="grid" (aria-multiselectable with multiple), aria-selected on rows, a single row in the tab order.
  • aria-sort on the first sorted column (none on the other sortable ones); sort buttons named “Sort by …”.
  • aria-rowcount (rows + header) and aria-rowindex accounting for the page; aria-busy while loading; selection bar in aria-live.

Verified by the conformance bench — These scenarios are played, identically, on every declared renderer (angular, react, vue, elements) on every push:

  • table/sort-click-keyboard-pagination-aria-empty
  • table/multiple-selection-shift-range-keyboard
  • table/single-selection-loading-skeleton-empty
