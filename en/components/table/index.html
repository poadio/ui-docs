Data table

<poad-table>

Rows and columns: sorting by click (single or multiple, in the language’s order), pagination, server-side data, row selection with a Shift range, empty and loading states. With a selection, the table becomes a grid whose rows are reachable from the keyboard.

What it is for

To compare records of the same shape (projects, deployments, users). This page covers columns, sorting, pages and selection; filters (global search, filter row, count footer), the side panel, the filter chip, the row detail, row groups, the tree table, row actions, frozen columns and the responsive table have their own pages. Editing and the column menu come in later slices. For a list of cards, a plain v-for / map.
