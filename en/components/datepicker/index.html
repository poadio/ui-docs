Date picker

<poad-datepicker>

A date field with its calendar: a six-week grid in the page language (names, first day, format through Intl), WAI-ARIA keyboard, one date, a range or several, bounds, typed input, time, inline or as a bottom sheet on small screens.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular

The calendar is rendered in the CDK overlay; the field is a form control (ngModel, formControl).

import { Component, signal } from '@angular/core';
import { PoadDatepickerComponent, type PoadDateValue } from '@poadio/ui-angular';

@Component({
  selector: 'app-datepicker-demo',
  imports: [PoadDatepickerComponent],
  template: `
    <div class="demo-row">
      <poad-datepicker [(value)]="day" [firstDayOfWeek]="1" clearable placeholder="Pick a day" style="width: 220px" />
    </div>
    <code>day={{ day() ?? 'none' }}</code>
  `,
})
export default class DatepickerDemo {
  readonly day = signal<PoadDateValue>('2026-11-24');
}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/datepicker-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadDatepicker } from '@poadio/ui-react';

export default function DatepickerDemo() {
  const [day, setDay] = useState<unknown>('2026-11-24');
  return (
    <>
      <div className="demo-row">
        <div style={{ width: 220 }}>
          <PoadDatepicker value={day as string | null} onChange={setDay} firstDayOfWeek={1} clearable placeholder="Pick a day" aria-label="Day" />
        </div>
      </div>
      <code>day={String(day ?? 'none')}</code>
    </>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import DatepickerDemo from './datepicker-demo';

export default function Page() {
  return <DatepickerDemo />;
}

Rendered by Vanilla

Form element: the ISO value is submitted with the <form> under name (one entry per date for a range or several).

<script type="module">import '@poadio/ui-elements/define';</script>

<div class="demo-row">
  <div style="width: 220px">
    <poad-datepicker id="day" name="day" value="2026-11-24" first-day-of-week="1" clearable placeholder="Pick a day" aria-label="Day"></poad-datepicker>
  </div>
</div>
<code id="datepicker-out">day=2026-11-24</code>

<script type="module">
  const day = document.querySelector('#day');
  day.addEventListener('change', () => {
    document.querySelector('#datepicker-out').textContent = `day=${day.value ?? 'none'}`;
  });
</script>

What it is for

For a nearby date, or one to place within its week. For a birth date, a masked field is quicker to type.

Keyboard

KeyEffect
EnterIn the field: reads the typed text, else opens or closes; on a day: picks it.
SpaceOn a day: picks it.
← →Previous / next day (reading direction), moving to another month when needed.
↑ ↓Previous / next week; in the field, ↓ (or Alt + ↓) moves into the grid.
Home EndStart / end of the week.
Page Up Page DownPrevious / next month (with Shift: year).
EscCloses the calendar; focus returns to the field.
TabCloses and moves on with Tab.

Accessibility

  • Field role="combobox" (aria-haspopup="dialog", aria-expanded, aria-controls); calendar role="dialog" named by the catalogue.
  • Grid role="grid": one day reachable with Tab (tabindex="0"), each day named in full (“Tuesday, November 24, 2026”), aria-selected, unavailable days aria-disabled.
  • Navigation, time and clear buttons named by the catalogue.
