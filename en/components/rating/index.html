Rating

<poad-rating>

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/rating-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadRating } from '@poadio/ui-react';

export default function RatingDemo() {
  const [score, setScore] = useState<number | null>(3.5);
  const [likes, setLikes] = useState<number | null>(2);
  return (
    <>
      <PoadRating value={score} onValueChange={setScore} allowHalf showValue />
      <div className="demo-row">
        <PoadRating defaultValue={4} readOnly size="sm" aria-label="Average rating" />
        <PoadRating value={likes} onValueChange={setLikes} icon="heart" severity="danger" max={3} aria-label="Likes" />
      </div>
      <code>score={String(score)} · likes={String(likes)}</code>
    </>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import RatingDemo from './rating-demo';

export default function Page() {
  return <RatingDemo />;
}

Accessibility

  • Focusable role="slider" with aria-valuenow, aria-valuetext (“2 / 5”), aria-valuemin / aria-valuemax.
  • Named “Rating” by the catalogue, or by aria-label.
  • Read-only: aria-readonly="true", tabindex="-1", no gesture. Fully mirrored right to left.

Stylesheets to import

Nothing to import for this component: it bundles its own sheet (@poadio/ui-core/rating.css, @poadio/ui-core/icon.css) at build time. Only tokens.css and base.css are loaded once, globally (see Installation).

import '@poadio/ui-core/tokens.css';          // once, in the global stylesheet
import '@poadio/ui-core/base.css';            // once, in the global stylesheet

import '@poadio/ui-core/icon.css';            // this component

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-warning: #b45309;       /* Warning */
  --poad-font-size: 0.875rem;    /* Base text size */
}

/* In dark theme only */
.theme-dark {
  --poad-warning: #fbbf24;       /* Warning */
}

/* One area only */
.checkout {
  --poad-font-size: 1rem;        /* Base text size */
}
