What it is for

maplibre-gl is an OPTIONAL dependency: npm i maplibre-gl; it is only loaded when the first map mounts (never during server rendering), and if it is missing the map says which package to install instead of breaking the page. Basemaps come from a registry (IGN Géoplateforme, OpenStreetMap, light and dark vector styles by default) that the application extends: a basemap can be a local MapLibre style, with no remote tile at all, as in this demo. Layers are children of the map; center and zoom are only enforced when the application changes them. For a single point on a static plan, an image is enough. Labels: a label (a layer field, a measurement, a cluster count) needs fonts. A style given by its URL brings its own; for a raster basemap or a style object without glyphs, the map uses its glyphs input (Angular: the POAD_MAP_GLYPHS token), OpenFreeMap’s fonts by default — a request to an outside service, made only when a label is shown. To serve everything yourself, put the {fontstack}/{range}.pbf files (font “Noto Sans Regular”) on your site and pass their address template, as the map tools and map chrome demos do.

Keyboard

KeyEffect
TabReaches the map (its canvas, a named region), then each control: zoom in, zoom out, compass, attributions.
← → ↑ ↓On the map: pans it west, east, north, south.
+ -On the map: zoom in, zoom out.
Shift ← →On the map: rotates it; the compass puts north back up.
Enter SpaceOn a control: activates it (zoom, north, fullscreen, geolocation).

Accessibility

  • The canvas is a region (role="region") named by ariaLabel (“Map” otherwise), reached with Tab; its focus is shown by a ring in the theme colours.
  • The controls (zoom, compass, fullscreen, geolocation, attributions) are buttons named in the application’s language; the scale follows the zoom.
  • Loading is announced (“Loading the map…”), an error (missing package) is shown in plain words.
  • Controls, popups, tooltips and markers follow the tokens (light / dark); followTheme picks the registry’s light or dark basemap from the page theme.

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-accent: #0b7a5c;        /* Accent colour: primary button, checked box, selection */
  --poad-radius-lg: 16px;        /* Large rounding: cards, dialogs, panels */
}

/* In dark theme only */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Accent colour: primary button, checked box, selection */
}

/* One area only */
.checkout {
  --poad-radius-lg: 0;           /* Large rounding: cards, dialogs, panels */
}
