Chip

A compact item the user removes or selects: active filter, recipient, keyword, person.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular
import { Component, signal } from '@angular/core';
import { PoadChipComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-chip-demo',
  imports: [PoadChipComponent],
  template: `
    <div class="demo-row">
      @for (city of cities(); track city) {
        <poad-chip [label]="city" icon="map-pin" removable (removed)="remove(city)" />
      }
    </div>
    <div class="demo-row">
      <poad-chip label="Mine only" clickable [selected]="mine()" (clicked)="mine.set(!mine())" />
      <poad-chip label="Ada Lovelace" avatarText="AL" severity="info" />
      <poad-chip label="Archived" size="sm" disabled removable />
    </div>
    <code>cities={{ cities().join(', ') }} · mine={{ mine() }}</code>
  `,
})
export default class ChipDemo {
  readonly cities = signal(['Paris', 'Lyon', 'Nantes']);
  readonly mine = signal(false);
  remove(city: string): void {
    this.cities.set(this.cities().filter((c) => c !== city));
  }
}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/chip-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadChip } from '@poadio/ui-react';

export default function ChipDemo() {
  const [cities, setCities] = useState(['Paris', 'Lyon', 'Nantes']);
  const [mine, setMine] = useState(false);
  return (
    <>
      <div className="demo-row">
        {cities.map((city) => (
          <PoadChip key={city} label={city} icon="map-pin" removable onRemove={() => setCities(cities.filter((c) => c !== city))} />
        ))}
      </div>
      <div className="demo-row">
        <PoadChip label="Mine only" clickable selected={mine} onClick={() => setMine(!mine)} />
        <PoadChip label="Ada Lovelace" avatarText="AL" severity="info" />
        <PoadChip label="Archived" size="sm" disabled removable />
      </div>
      <code>cities={cities.join(', ')} · mine={String(mine)}</code>
    </>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import ChipDemo from './chip-demo';

export default function Page() {
  return <ChipDemo />;
}

<script type="module">
  // remove: × button, Backspace or Delete — the chip is taken out of the page.
  document.querySelector('#cities').addEventListener('remove', (e) => e.target.remove());
  // press: click, Enter or Space on a clickable chip.
  const mine = document.querySelector('#mine');
  mine.addEventListener('press', () => (mine.selected = !mine.selected));
</script>

What it is for

removable adds a remove button; clickable turns it into a toggle button (selected). For a plain status, prefer a tag.

Keyboard

KeyEffect

Accessibility

  • Focusable (tabindex="0"); disabled, it leaves the tab order and carries aria-disabled="true", with no remove button.
  • Clickable: role="button" and aria-pressed; otherwise neither role nor aria-pressed.
  • The remove button is named “Remove Paris” by the catalogue.
