Key filter

Blocks some keystrokes in a free-form input: digits only, hexadecimal, letters… The text stays free in length and shape, only characters are filtered; a paste is cleaned.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular

With a form, the directive also validates the whole value (keyfilter error).

import { Component } from '@angular/core';
import { PoadFieldComponent, PoadInputDirective, PoadKeyFilterDirective } from '@poadio/ui-angular';

@Component({
  selector: 'app-key-filter-demo',
  imports: [PoadFieldComponent, PoadInputDirective, PoadKeyFilterDirective],
  template: `
    <div class="demo-col">
      <poad-field label="Quantity" hint="Integers only (int)">
        <input poadInput poadKeyFilter="int" />
      </poad-field>
      <poad-field label="Colour" hint="Hexadecimal (hex)">
        <input poadInput poadKeyFilter="hex" mono />
      </poad-field>
      <poad-field label="Code" hint="Letters and digits (alphanum)">
        <input poadInput poadKeyFilter="alphanum" />
      </poad-field>
    </div>
  `,
})
export default class KeyFilterDemo {}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/key-filter-demo.tsx — client component (state, handlers)
'use client';

import { PoadField, PoadInput, usePoadKeyFilter } from '@poadio/ui-react';

export default function KeyFilterDemo() {
  const int = usePoadKeyFilter('int');
  const hex = usePoadKeyFilter('hex');
  const code = usePoadKeyFilter('alphanum');
  return (
    <div className="demo-col">
      <PoadField label="Quantity" hint="Integers only (int)">
        <PoadInput {...int.inputProps} />
      </PoadField>
      <PoadField label="Colour" hint="Hexadecimal (hex)">
        <PoadInput {...hex.inputProps} mono />
      </PoadField>
      <PoadField label="Code" hint="Letters and digits (alphanum)">
        <PoadInput {...code.inputProps} />
      </PoadField>
    </div>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import KeyFilterDemo from './key-filter-demo';

export default function Page() {
  return <KeyFilterDemo />;
}

What it is for

When the value has no fixed format (otherwise: input mask). It is not validation: also check the value on submit (validateOnly + valid()).

Keyboard

No keyboard interaction: display component.

Accessibility

  • The input stays native (name, hint, form unchanged); a refused keystroke is simply prevented.
  • State the rule in the field hint: nothing else tells the user why a key has no effect.
