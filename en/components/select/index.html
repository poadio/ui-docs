Select

Picks one value from a list of options: WAI-ARIA combobox, type-ahead, filter, clear button, groups, templates. Never a native <select>; on small screens, the panel opens as a bottom sheet.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular

The panel is rendered in the CDK overlay: load @angular/cdk/overlay-prebuilt.css (included by the ui-angular base stylesheet).

import { Component, signal } from '@angular/core';
import { PoadSelectComponent } from '@poadio/ui-angular';

interface Runtime { id: number; name: string; disabled?: boolean }

@Component({
  selector: 'app-select-demo',
  imports: [PoadSelectComponent],
  template: `
    <div class="demo-row">
      <poad-select [options]="runtimes" optionLabel="name" optionValue="id" [(value)]="runtime"
        placeholder="Runtime" ariaLabel="Runtime" filter clearable style="width: 240px" />
      <poad-select [options]="sizes" [(value)]="size" ariaLabel="Size" size="sm" style="width: 120px" />
      <poad-select [options]="sizes" [value]="'M'" ariaLabel="Disabled" disabled style="width: 120px" />
    </div>
    <code>runtime={{ runtime() }} · size={{ size() }}</code>
  `,
})
export default class SelectDemo {
  readonly runtimes: Runtime[] = [
    { id: 1, name: 'Serverless' },
    { id: 2, name: 'Node / Bun', disabled: true },
    { id: 3, name: 'Spring Boot' },
    { id: 4, name: 'Python' },
  ];
  readonly sizes = ['S', 'M', 'L', 'XL'];
  readonly runtime = signal<unknown>(3);
  readonly size = signal<unknown>('M');
}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/select-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadSelect } from '@poadio/ui-react';

const runtimes = [
  { id: 1, name: 'Serverless' },
  { id: 2, name: 'Node / Bun', disabled: true },
  { id: 3, name: 'Spring Boot' },
  { id: 4, name: 'Python' },
];
const sizes = ['S', 'M', 'L', 'XL'];

export default function SelectDemo() {
  const [runtime, setRuntime] = useState<unknown>(3);
  const [size, setSize] = useState<unknown>('M');
  return (
    <>
      <div className="demo-row">
        <PoadSelect options={runtimes} optionLabel="name" optionValue="id" value={runtime} onChange={setRuntime}
          placeholder="Runtime" aria-label="Runtime" filter clearable style={{ width: 240 }} />
        <PoadSelect options={sizes} value={size} onChange={setSize} aria-label="Size" size="sm" style={{ width: 120 }} />
        <PoadSelect options={sizes} defaultValue="M" aria-label="Disabled" disabled style={{ width: 120 }} />
      </div>
      <code>runtime={String(runtime)} · size={String(size)}</code>
    </>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import SelectDemo from './select-demo';

export default function Page() {
  return <SelectDemo />;
}

Keyboard

↓ ↑Open: next / previous option, skipping disabled options.

TabCloses and moves on with Tab.
a–zType-ahead: when closed, directly picks the option starting that way.
DeleteWith clearable: clears the value.

Accessibility

  • Trigger role="combobox" (aria-haspopup="listbox", aria-expanded, aria-controls), list role="listbox", options role="option" with aria-selected and aria-disabled.
  • Active option announced through aria-activedescendant: focus stays on the trigger (or in the filter, a role="searchbox" linked to the list).
  • Disabled: aria-disabled="true" and tabindex="-1", neither click nor keyboard.
  • Empty list or filter with no result: a catalogue message inside the list.
