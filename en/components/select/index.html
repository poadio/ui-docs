Select

<poad-select>

Picks one value from a list of options: WAI-ARIA combobox, type-ahead, filter, clear button, groups, templates. Never a native <select>; on small screens, the panel opens as a bottom sheet.

What it is for

From half a dozen options on, or when space is short. Below that, a radio group or a segmented control shows everything at a glance.

Binding to a store

Declare the store once, then give it to the component: store (the object, or its name) and field or fields. Reading and writing go through the signed-in user’s RLS. All the details: Stores (@poadio/data).

import { store } from '@poadio/data';

// reference: the options
store.table('villes', 'villes', { reference: true, order: ['nom'] });
const chantier = store.table('chantier', 'chantiers', { key: 42, fields: [
  // one city
  { field: 'ville_id', options: { store: 'villes' } },
  // several (array column)
  { field: 'communes', options: { store: 'villes' } },
] });
Angular
<!-- chantier: the store (component property) or its name -->
<poad-select [store]="chantier" field="ville_id" />
React · Next.js
<PoadSelect store={chantier} field="ville_id" />
Vue · Nuxt
<PoadSelect :store="chantier" field="ville_id" />
Vanilla
<!-- the store by its name, declared before the components load (or el.store = the object) -->
<poad-select store="chantier" field="ville_id"></poad-select>

TabCloses and moves on with Tab.

DeleteWith clearable: clears the value.

Accessibility

  • Trigger role="combobox" (aria-haspopup="listbox", aria-expanded, aria-controls), list role="listbox", options role="option" with aria-selected and aria-disabled.
  • Active option announced through aria-activedescendant: focus stays on the trigger (or in the filter, a role="searchbox" linked to the list).
  • Disabled: aria-disabled="true" and tabindex="-1", neither click nor keyboard.
  • Empty list or filter with no result: a catalogue message inside the list.

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-accent: #0b7a5c;        /* Accent colour: primary button, checked box, selection */
  --poad-radius: 4px;            /* Corner rounding of controls */
}

/* In dark theme only */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Accent colour: primary button, checked box, selection */
}

/* One area only */
.checkout {
  --poad-radius: 0;              /* Corner rounding of controls */
}
