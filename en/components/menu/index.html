Menu

<poad-menu>

A list of actions, inline or floating against a button (or at a right-click position): shortcuts, icons, submenus, separators, dangerous actions. Bottom sheet on small screens.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular

Floating menu: popup, opened by toggle($event) from the trigger; rendered in the CDK overlay. routerLink on an item goes through the router.

import { Component, signal } from '@angular/core';
import { PoadButtonComponent, PoadMenuComponent, type PoadMenuItem } from '@poadio/ui-angular';

@Component({
  selector: 'app-menu-demo',
  imports: [PoadButtonComponent, PoadMenuComponent],
  template: `
    <div class="demo-row">
      <button poadButton variant="outline" (click)="actions.toggle($event)">Actions</button>
      <poad-menu #actions popup [items]="items" ariaLabel="Project actions" (itemClick)="last.set($event.item.label ?? '')" />
    </div>
    <code>last={{ last() }}</code>
  `,
})
export default class MenuDemo {
  readonly items: PoadMenuItem[] = [
    { label: 'Open', icon: 'folder-open', shortcut: '⌘O' },
    { label: 'Export', icon: 'download', items: [{ label: 'CSV' }, { label: 'JSON' }] },
    { separator: true },
    { label: 'Delete', icon: 'trash-2', severity: 'danger' },
  ];
  readonly last = signal('none');
}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/menu-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadButton, PoadMenu, type PoadMenuItem } from '@poadio/ui-react';

const items: PoadMenuItem[] = [
  { label: 'Open', icon: 'folder-open', shortcut: '⌘O' },
  { label: 'Export', icon: 'download', items: [{ label: 'CSV' }, { label: 'JSON' }] },
  { separator: true },
  { label: 'Delete', icon: 'trash-2', severity: 'danger' },
];

export default function MenuDemo() {
  const [last, setLast] = useState('none');
  return (
    <>
      <div className="demo-row">
        <PoadMenu
          items={items} trigger={<PoadButton variant="outline">Actions</PoadButton>} aria-label="Project actions"
          onItemClick={({ item }) => setLast(item.label ?? '')}
        />
      </div>
      <code>last={last}</code>
    </>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import MenuDemo from './menu-demo';

export default function Page() {
  return <MenuDemo />;
}

<script setup lang="ts">
import { ref } from 'vue';
import { PoadButton, PoadMenu, type PoadMenuItem } from '@poadio/ui-vue';

const items: PoadMenuItem[] = [
  { label: 'Open', icon: 'folder-open', shortcut: '⌘O' },

];
const last = ref('none');
</script>

<template>
  <div class="demo-row">
    <PoadMenu :items="items" aria-label="Project actions" @item-click="({ item }) => (last = item.label ?? '')">

    </PoadMenu>
  </div>
  <code>last={{ last }}</code>

Rendered by Vanilla

The slot="trigger" child toggles the menu; items with a command are given as a property (menu.items = […]).

<script type="module">import '@poadio/ui-elements/define';</script>

<div class="demo-row">
  <poad-menu id="actions" aria-label="Project actions"
    items='[{"label":"Open","icon":"folder-open","shortcut":"⌘O"},{"label":"Export","icon":"download","items":[{"label":"CSV"},{"label":"JSON"}]},{"separator":true},{"label":"Delete","icon":"trash-2","severity":"danger"}]'>
    <poad-button slot="trigger" variant="outline">Actions</poad-button>
  </poad-menu>
</div>
<code id="menu-out">last=none</code>

<script type="module">
  document.querySelector('#actions').addEventListener('itemclick', (e) => {
    document.querySelector('#menu-out').textContent = `last=${e.detail.item.label}`;
  });
</script>

What it is for

For actions on an object that don’t fit as buttons. To pick a value, a select; for a main action and its variants, a split button.

Keyboard

KeyEffect
↓ ↑Next / previous item, wrapping, skipping separators and disabled items.
Home EndFirst / last item.
→On an item with a submenu: opens it and focuses its first item.
←In a submenu: closes it, focus returns to its item.
Enter SpaceChooses the item (and closes the floating menu).
EscCloses the submenu, then the menu; focus returns to the trigger.

Accessibility

  • Panel role="menu", items role="menuitem" (buttons), separators role="separator".
  • When opened, focus goes to the first item; roving focus (tabindex="0" on the active item only).
  • Item with a submenu: aria-haspopup="menu" and aria-expanded.
