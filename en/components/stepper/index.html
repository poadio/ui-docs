Stepper

<poad-stepper>

An ordered sequence of steps and their state (done, current, to do, error); the current step shows its content. In linear mode, a step is reachable only after the previous ones.

What it is for

For a multi-part flow (deployment, sign-up). “Next” and “Back” buttons belong to the application: it moves on by changing the current step.

Methods

MethodSignatureDescription
canGo(i: number): booleanIn linear mode: reachable up to the first incomplete step (included).
goTo(i: number): booleanGoes to the step at index i if it is reachable; returns false otherwise.
next(): booleanGoes to the next step; returns false if it is not reachable.
prev(): booleanGoes back to the previous step; returns false if it is not reachable.

Accessibility

  • Ordered list <ol> named by aria-label; the current step has aria-current="step".
  • Each step’s state in data-state; decorative dot hidden (aria-hidden); the catalogue’s “(optional)” in the label.
  • Unreachable step: a disabled button.

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-fg: #0f172a;            /* Main text */
  --poad-dur: 80ms;              /* Transition duration (opening, hover, toggle) */
}

/* In dark theme only */
.theme-dark {
  --poad-fg: #f8fafc;            /* Main text */
}

/* One area only */
.checkout {
  --poad-dur: 0ms;               /* Transition duration (opening, hover, toggle) */
}
