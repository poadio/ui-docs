@Component({

      <button poadButton severity="danger" variant="outline">Delete</button>
      <button poadButton severity="ghost" variant="text">More</button>
      <button poadButton size="sm" [loading]="busy()" (click)="run()">Deploy</button>
      <button poadButton disabled>Disabled</button>
    </div>
    <code>saves={{ saves() }} · busy={{ busy() }}</code>
  `,
})
export default class ButtonDemo {
  readonly saves = signal(0);
  readonly busy = signal(false);
  run(): void {
    this.busy.set(true);
    setTimeout(() => this.busy.set(false), 1500);
  }
}

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

PoadButton holds no state: it also renders in a server component. Only the onClick handler requires a client component.

// app/button-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadButton } from '@poadio/ui-react';

export default function ButtonDemo() {
  const [saves, setSaves] = useState(0);
  const [busy, setBusy] = useState(false);
  const run = () => {
    setBusy(true);
    setTimeout(() => setBusy(false), 1500);
  };
  return (
    <>
      <div className="demo-row">
        <PoadButton onClick={() => setSaves(saves + 1)}>Save</PoadButton>
        <PoadButton severity="secondary">Cancel</PoadButton>
        <PoadButton severity="danger" variant="outline">Delete</PoadButton>
        <PoadButton severity="ghost" variant="text">More</PoadButton>
        <PoadButton size="sm" loading={busy} onClick={run}>Deploy</PoadButton>
        <PoadButton disabled>Disabled</PoadButton>
      </div>
      <code>saves={saves} · busy={String(busy)}</code>
    </>
  );
}

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-accent: #0b7a5c;        /* Accent colour: primary button, checked box, selection */
  --poad-dur: 80ms;              /* Transition duration (opening, hover, toggle) */
}

/* In dark theme only */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Accent colour: primary button, checked box, selection */
}

/* One area only */
.checkout {
  --poad-dur: 0ms;               /* Transition duration (opening, hover, toggle) */
}
