Button

Triggers an action. Always a real native <button> (focus, keyboard, form), dressed by the core classes: severity, variant, size, busy state.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular

A directive, not a component: the <button> (or <a>) stays the one in your template, with its attributes and events.

import { Component, signal } from '@angular/core';
import { PoadButtonComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-button-demo',
  imports: [PoadButtonComponent],
  template: `
    <div class="demo-row">
      <button poadButton (click)="saves.set(saves() + 1)">Save</button>
      <button poadButton severity="secondary">Cancel</button>
      <button poadButton severity="danger" variant="outline">Delete</button>
      <button poadButton severity="ghost" variant="text">More</button>
      <button poadButton size="sm" [loading]="busy()" (click)="run()">Deploy</button>
      <button poadButton disabled>Disabled</button>
    </div>
    <code>saves={{ saves() }} · busy={{ busy() }}</code>
  `,
})
export default class ButtonDemo {
  readonly saves = signal(0);
  readonly busy = signal(false);
  run(): void {
    this.busy.set(true);
    setTimeout(() => this.busy.set(false), 1500);
  }
}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

PoadButton holds no state: it also renders in a server component. Only the onClick handler requires a client component.

// app/button-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadButton } from '@poadio/ui-react';

export default function ButtonDemo() {
  const [saves, setSaves] = useState(0);
  const [busy, setBusy] = useState(false);
  const run = () => {
    setBusy(true);
    setTimeout(() => setBusy(false), 1500);
  };
  return (
    <>
      <div className="demo-row">
        <PoadButton onClick={() => setSaves(saves + 1)}>Save</PoadButton>
        <PoadButton severity="secondary">Cancel</PoadButton>
        <PoadButton severity="danger" variant="outline">Delete</PoadButton>
        <PoadButton severity="ghost" variant="text">More</PoadButton>
        <PoadButton size="sm" loading={busy} onClick={run}>Deploy</PoadButton>
        <PoadButton disabled>Disabled</PoadButton>
      </div>
      <code>saves={saves} · busy={String(busy)}</code>
    </>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import ButtonDemo from './button-demo';

export default function Page() {
  return <ButtonDemo />;
}

What it is for

One main action (primary) per area; the others as secondary, ghost or the text variant. For a state that sticks, see the toggle button.

Accessibility

  • Named by its content; an icon-only button must get an aria-label.
  • Disabled: disabled for the browser and aria-disabled="true" for assistive technologies.
  • Busy: aria-busy="true", spinner hidden (aria-hidden), name unchanged.
  • As a toggle: aria-pressed follows pressed.

Verified by the conformance bench — These scenarios are played, identically, on every declared renderer (angular, react, vue, elements) on every push:

Theme tokens

--poad-* tokens read by the @poadio/ui-core/button.css stylesheet of @poadio/ui-core. Redefining them (globally or on a container) is enough to theme the component, on every framework at once.
