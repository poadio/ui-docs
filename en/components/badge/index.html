Badge

A small counter or status dot, placed next to a label or an icon: notifications, pending items.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular

Angular also has the [poadBadge] directive, which places the badge on another element: it is not ported to the other frameworks yet.

import { Component, signal } from '@angular/core';
import { PoadBadgeComponent, PoadButtonComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-badge-demo',
  imports: [PoadBadgeComponent, PoadButtonComponent],
  template: `
    <div class="demo-row">
      <poad-badge [value]="count()" />
      <poad-badge [value]="120" />
      <poad-badge [value]="120" [max]="999" severity="info" />
      <poad-badge value="new" severity="success" />
      <poad-badge [value]="7" severity="neutral" size="sm" />
      <poad-badge dot severity="success" ariaLabel="Online" />
      <button poadButton size="sm" severity="secondary" (click)="count.set(count() + 1)">+1</button>
    </div>
  `,
})
export default class BadgeDemo {
  readonly count = signal(3);
}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

PoadBadge holds no state: it also renders in a server component.

// app/badge-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadBadge, PoadButton } from '@poadio/ui-react';

export default function BadgeDemo() {
  const [count, setCount] = useState(3);
  return (
    <div className="demo-row">
      <PoadBadge value={count} />
      <PoadBadge value={120} />
      <PoadBadge value={120} max={999} severity="info" />
      <PoadBadge value="new" severity="success" />
      <PoadBadge value={7} severity="neutral" size="sm" />
      <PoadBadge dot severity="success" aria-label="Online" />
      <PoadButton size="sm" severity="secondary" onClick={() => setCount(count + 1)}>+1</PoadButton>
    </div>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import BadgeDemo from './badge-demo';

export default function Page() {
  return <BadgeDemo />;
}

What it is for

Above max (99 by default), the value is capped (99+). A dot (dot) shows nothing: give it an accessible name if it carries information.

Main options

maxmaxmaxmaxnumber
Default 99		Cap: beyond it, 99+.
severityseverityseverityseverity'primary' | 'success' | 'warning' | 'danger' | 'info' | 'neutral'

Keyboard

No keyboard interaction: display component.

Accessibility

  • The displayed text is the capped value (99+): that is what a screen reader reads.
  • Without aria-label, no aria-label attribute is set; with it, the badge is named by it.
  • Colour alone does not carry the information: back it with text or a name.

Verified by the conformance bench — These scenarios are played, identically, on every declared renderer (angular, react, vue, elements) on every push:

Theme tokens

--poad-* tokens read by the @poadio/ui-core/badge.css stylesheet of @poadio/ui-core. Redefining them (globally or on a container) is enough to theme the component, on every framework at once.

--poad-danger --poad-radius-pill --poad-font-mono --poad-accent --poad-success --poad-warning --poad-info --poad-fg-secondary
