Slider

Picks a value, or a range with two handles, by dragging along a track; stepped, bounded, with optional marks.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular
import { Component, signal } from '@angular/core';
import { PoadSliderComponent, type PoadSliderMark, type PoadSliderValue } from '@poadio/ui-angular';

@Component({
  selector: 'app-slider-demo',
  imports: [PoadSliderComponent],
  template: `
    <div class="demo-col">
      <poad-slider [(value)]="volume" [step]="5" showValue="always" ariaLabel="Volume" />
      <poad-slider [(value)]="price" range label="Price" [marks]="marks" [formatValue]="euros" (changed)="saved.set($event)" />
    </div>
    <code>volume={{ volume() }} · price={{ price() }} · changed={{ saved() }}</code>
  `,
})
export default class SliderDemo {
  readonly volume = signal<PoadSliderValue | null>(40);
  readonly price = signal<PoadSliderValue | null>([20, 60]);
  readonly saved = signal<PoadSliderValue | null>(null);
  readonly marks: PoadSliderMark[] = [0, 50, { value: 100, label: 'Max' }];
  readonly euros = (v: number) => `${v} €`;
}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/slider-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadSlider, type SliderMark, type SliderValue } from '@poadio/ui-react';

const marks: SliderMark[] = [0, 50, { value: 100, label: 'Max' }];
const euros = (v: number) => `${v} €`;

export default function SliderDemo() {
  const [volume, setVolume] = useState<SliderValue>(40);
  const [price, setPrice] = useState<SliderValue>([20, 60]);
  const [saved, setSaved] = useState<SliderValue | null>(null);
  return (
    <>
      <div className="demo-col">
        <PoadSlider value={volume} onValueChange={setVolume} step={5} showValue="always" aria-label="Volume" />
        <PoadSlider value={price} onValueChange={setPrice} onChange={setSaved} range label="Price" marks={marks} formatValue={euros} />
      </div>
      <code>volume={String(volume)} · price={String(price)} · changed={String(saved)}</code>
    </>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import SliderDemo from './slider-demo';

export default function Page() {
  return <SliderDemo />;
}

What it is for

When the rough value matters more than the exact figure (volume, maximum price). For precise input, use the number field.

Keyboard

KeyEffect
→ ↑Increases by one step (Shift: × 10); right to left, ← increases.
← ↓Decreases by one step (Shift: × 10).
Page Up Page Down± 10 steps.
Home EndMinimum, maximum (in a range: bounded by the other handle).

Accessibility

  • Each handle is a focusable role="slider": aria-valuenow, aria-valuemin / aria-valuemax (in a range, bounded by the other handle), formatted aria-valuetext, aria-orientation.
  • Named by its visible label (aria-labelledby) or by aria-label.
  • Disabled: aria-disabled="true", tabindex="-1". Fully mirrored right to left.

Verified by the conformance bench — These scenarios are played, identically, on every declared renderer (angular, react, vue, elements) on every push:
