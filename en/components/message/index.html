Message

An inline message — information, success, warning, error — with its severity icon and, if needed, a close button.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular
import { Component, signal } from '@angular/core';
import { PoadMessageComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-message-demo',
  imports: [PoadMessageComponent],
  template: `
    <div class="demo-col">
      <poad-message severity="info" text="A new version is available." />
      <poad-message severity="success" closable (closed)="closed.set(closed() + 1)">Changes saved.</poad-message>
      <poad-message severity="warning" variant="outline">The certificate expires in 6 days.</poad-message>
      <poad-message severity="danger" size="sm" icon="" text="Connection lost (no icon)." />
    </div>
    <code>closed={{ closed() }}</code>
  `,
})
export default class MessageDemo {
  readonly closed = signal(0);
}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/message-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadMessage } from '@poadio/ui-react';

export default function MessageDemo() {
  const [closed, setClosed] = useState(0);
  return (
    <>
      <div className="demo-col">
        <PoadMessage severity="info" text="A new version is available." />
        <PoadMessage severity="success" closable onClose={() => setClosed((n) => n + 1)}>Changes saved.</PoadMessage>
        <PoadMessage severity="warning" variant="outline">The certificate expires in 6 days.</PoadMessage>
        <PoadMessage severity="danger" size="sm" icon="" text="Connection lost (no icon)." />
      </div>
      <code>closed={closed}</code>
    </>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import MessageDemo from './message-demo';

export default function Page() {
  return <MessageDemo />;
}

What it is for

For a state that stays on screen while it holds (a quota reached, a certificate expiring). For a passing confirmation, use a toast.

No keyboard interaction: display component.

Accessibility

  • role="status": screen readers announce the message politely.
  • The severity icon is decorative; the close button is named “Close” by the catalogue.

Theme tokens

--poad-* tokens read by the @poadio/ui-core/message.css, @poadio/ui-core/icon.css stylesheet of @poadio/ui-core. Redefining them (globally or on a container) is enough to theme the component, on every framework at once.
