Inplace editor

Shows a value as text; a click swaps it for its editor (a field, a select…), and Escape or the close button go back to display.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular
import { Component, signal } from '@angular/core';
import { FormsModule } from '@angular/forms';
import {
  PoadInplaceComponent, PoadInplaceContentDirective, PoadInplaceDisplayDirective, PoadInputDirective,
} from '@poadio/ui-angular';

@Component({
  selector: 'app-inplace-demo',
  imports: [FormsModule, PoadInplaceComponent, PoadInplaceDisplayDirective, PoadInplaceContentDirective, PoadInputDirective],
  template: `
    <poad-inplace closable ariaLabel="Edit the city" (deactivated)="closed.set(closed() + 1)">
      <ng-template poadInplaceDisplay>{{ city() }}</ng-template>
      <ng-template poadInplaceContent>
        <input poadInput [ngModel]="city()" (ngModelChange)="city.set($event)" aria-label="City" />
      </ng-template>
    </poad-inplace>
    <code>city={{ city() }} · closed={{ closed() }}</code>
  `,
})
export default class InplaceDemo {
  readonly city = signal('Paris');
  readonly closed = signal(0);
}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/inplace-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadInplace, PoadInput } from '@poadio/ui-react';

export default function InplaceDemo() {
  const [city, setCity] = useState('Paris');
  const [closed, setClosed] = useState(0);
  return (
    <>
      <PoadInplace display={city} closable aria-label="Edit the city" onDeactivate={() => setClosed((n) => n + 1)}>
        <PoadInput value={city} onChange={(e) => setCity(e.target.value)} aria-label="City" />
      </PoadInplace>
      <code>city={city} · closed={closed}</code>
    </>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import InplaceDemo from './inplace-demo';

export default function Page() {
  return <InplaceDemo />;
}

Rendered by Vanilla
<script type="module">import '@poadio/ui-elements/define';</script>

<!-- display : le texte montré hors édition ; le contenu de l'élément est l'éditeur -->
<poad-inplace id="city" display="Paris" closable aria-label="Edit the city">
  <input class="poad-input" value="Paris" aria-label="City">
</poad-inplace>
<code id="city-out">city=Paris</code>

<script type="module">
  const inplace = document.querySelector('#city');
  inplace.addEventListener('input', (e) => {
    inplace.display = e.target.value;
    document.querySelector('#city-out').textContent = `city=${e.target.value}`;
  });
</script>

What it is for

For read-mostly screens where a value gets corrected now and then, without a permanent form.

Keyboard

KeyEffect
Enter SpaceOn the display (a real button): opens the editor.
EscIn the editor: goes back to display (unless closeOnEscape is false).

Accessibility

  • The display is a <button> named “Edit” by the catalogue, or by aria-label; disabled: native disabled.
  • On opening, focus moves to the editor’s first field; the close button is named “Close” by the catalogue.

Theme tokens

--poad-* tokens read by the @poadio/ui-core/inplace.css, @poadio/ui-core/icon.css stylesheet of @poadio/ui-core. Redefining them (globally or on a container) is enough to theme the component, on every framework at once.
