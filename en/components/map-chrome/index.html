Map chrome

<poad-map-chrome>

All of a map’s chrome in a single component: basemaps, layers (symbology, GeoJSON import), tools (measure, draw, identify, compare) and export (PNG image, GeoJSON, link, print).

export default class MapChromeDemo {
  readonly bridges = bridges;
  readonly zone = zone;
  readonly open = signal(false);
  readonly imported = signal('none');
  readonly shapes = signal(0);
  constructor() {
    inject(PoadMapBasemapRegistry).registerAll([
      { id: 'paper', label: 'Paper', kind: 'vector', style: paper(false) },

}

What it is for

Child of the map. mode picks the presentation: drawer (one button opens a tabbed drawer), toolbar (one button per tab) or rail (the map’s rail and panels). On a small screen the drawer becomes a bottom sheet. The Layers tab lists the map’s layers; a layer’s palette button opens its symbology (colour, colour by field, label), applied live and removed with “Restore”. An imported GeoJSON file becomes a layer. Export makes no request: the image comes from the canvas (screenshotable on the map), the GeoJSON from the layers, the link from the view. A label taken from a field reads the map’s glyphs (glyphs). The label from a field (a layer’s symbology) and the measurements are written with the map’s fonts: see glyphs on the map.

Accessibility

  • The open button tells the drawer state (aria-expanded, aria-controls); the drawer is a named dialog, inert once closed.
  • The tabs form a tablist (a single tab stop, aria-selected, aria-controls); only the current panel is shown.
  • The tools are a named toolbar; the measure, the import, the copied link and “nothing here” are announced (role="status") in the language.
  • The identify popup is made of tables set as plain text (never HTML coming from the data).

Theme tokens

Map chrome is tuned by 39 CSS --poad-* tokens. Change a token’s value in your application’s global stylesheet: the component follows, on every framework at once. Values: this site’s base theme, light and dark.

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-accent: #0b7a5c;        /* Accent colour: primary button, checked box, selection */
  --poad-radius-lg: 16px;        /* Large rounding: cards, dialogs, panels */
}

/* In dark theme only */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Accent colour: primary button, checked box, selection */
}

/* One area only */
.checkout {
  --poad-radius-lg: 0;           /* Large rounding: cards, dialogs, panels */
}
