Task board

<poad-taskboard>

A column board (kanban): the tasks of a planning document sorted by column and by rank, moved with the mouse, the finger or the keyboard, with a work-in-progress limit that warns without blocking. On a phone it turns into a grouped list.

    { id: 't4', label: 'Traffic count', bucket: 'doing', rank: 'd', progress: 0.7, tags: ['data'], assignments: [{ resource: 'ana' }] },

@Component({
  selector: 'app-taskboard-demo',
  imports: [PoadTaskboardComponent],
  template: `
    <poad-taskboard class="demo-taskboard" [plan]="plan()" ariaLabel="Project tasks" (taskMove)="onMove($event)" />
    <code>{{ last() }}</code>
  `,
})
export default class TaskboardDemo {
  readonly plan = signal(PLAN);
  readonly last = signal('moved=—');
  /** The board never writes: the application applies the move to its own document. */
  onMove(e: PoadTaskMoveEvent): void {
    this.plan.update((p) => ({ ...p, tasks: p.tasks!.map((t) => (t.id === e.id ? { ...t, bucket: e.to, rank: e.rank } : t)) }));
    this.last.set(`moved=${e.task.label} → ${e.to}`);
  }
}

What it is for

To follow a batch of tasks through stages (to do, doing, done) or by person (list grouped by person: the same gesture reassigns). The board never writes: it emits the intention (column and new rank) and keeps the display up to date while the application applies or refuses it. For dated tasks, the Gantt chart or the scheduler.

Keyboard

KeyEffect
TabMoves from card to card (every card is in the tab order).
Enter SpaceOpens the task (taskOpen event).
Ctrl ← →Ctrl (⌘ on Mac) + ← / →: moves the task to the previous / next column, at the same height (swapped right to left). In the list, to the previous / next group.
Ctrl ↑ ↓Ctrl (⌘) + ↑ / ↓: moves the task one place up / down in its column. Focus follows the card.
EscDuring a mouse or touch drag: cancels, the card stays where it was.

Accessibility

  • Every card is a role="button" described by the keyboard help (aria-describedby); every column is a role="group" named by its title.
  • Every move is announced in an aria-live region: WHERE and AT WHICH PLACE (“Survey report — moved to Doing, position 2 of 3.”), not just “moved”.
  • Mouse drag: the grabbed card stays in place, dimmed, a floating preview follows the pointer and a line shows where it will land. With a finger, a long press grabs the card; a short swipe scrolls the page as usual.
  • The work-in-progress limit shows in the count (2/3) and its colour (reached, exceeded); it never blocks a gesture. A task whose column does not exist joins the first one, marked, never hidden.

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-accent: #0b7a5c;        /* Accent colour: primary button, checked box, selection */
  --poad-radius: 4px;            /* Corner rounding of controls */
}

/* In dark theme only */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Accent colour: primary button, checked box, selection */
}

/* One area only */
.checkout {
  --poad-radius: 0;              /* Corner rounding of controls */
}
