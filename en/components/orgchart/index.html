Org chart

<poad-orgchart>

A hierarchy drawn as connected boxes, top to bottom or left to right: collapsible nodes, picking one or several nodes, zoom, and a keyboard that follows the drawing (parent, children, siblings). On a phone it turns into an indented list.

import { PoadOrgchartComponent, type PoadOrgNode } from '@poadio/ui-angular';

interface Person { name: string; role: string; initials: string }

const p = (name: string, role: string): Person => ({ name, role, initials: name.split(' ').map((w) => w[0]).join('') });
const ORG: PoadOrgNode<Person>[] = [{
  data: p('Alice Martin', 'Director'), children: [
    { data: p('Bruno Petit', 'Engineering'), children: [{ data: p('Chloé Roux', 'Platform') }, { data: p('David Leroy', 'Apps') }] },
    { data: p('Emma Faure', 'Operations'), children: [{ data: p('Farid Benali', 'Support') }] },
    { data: p('Gaëlle Simon', 'Finance') },
  ],
}];

@Component({
  selector: 'app-orgchart-demo',
  imports: [PoadOrgchartComponent],
  template: `
    <poad-orgchart class="demo-org" [value]="org" labelField="name" sublabelField="role" avatarField="initials" selectionMode="single" [(selection)]="chosen" />
    <code>selected={{ name() }}</code>
  `,
})
export default class OrgchartDemo {
  readonly org = ORG;
  readonly chosen = signal<Person | Person[] | null>(null);
  name(): string { const c = this.chosen(); return (Array.isArray(c) ? c[0] : c)?.name ?? '—'; }
}

What it is for

To show an organisation, a breakdown or a decision tree of a few dozen nodes. To browse a deep hierarchy or tick nodes in it, the tree.

Keyboard

KeyEffect
↓ ↑Top to bottom: ↓ moves to the first child, ↑ to the parent. Left to right: ↑ / ↓ move to the previous / next sibling.
← →Top to bottom: ← / → move to the previous / next sibling. Left to right: → moves to the first child, ← to the parent. Swapped right to left.
Home EndFirst / last visible node. In the compact list, the arrows follow the list as in a tree.
Enter SpacePicks the node (a second time removes it).
+ - *+ expands the node, - collapses it, * expands everything.

Accessibility

  • role="tree" > role="group" > role="treeitem" with aria-level, aria-posinset, aria-setsize, aria-expanded, aria-selected; a single node in the tab order (roving focus).
  • The collapse button is for the mouse (“Collapse” / “Expand” tooltip); hidden from screen readers, + and - replace it. Named zoom buttons in a named group.
  • Wider than its room, the chart scrolls horizontally; below compactAt px (640 by default), it becomes an indented list.

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-accent: #0b7a5c;        /* Accent colour: primary button, checked box, selection */
  --poad-radius-sm: 2px;         /* Small rounding: list options, small elements */
}

/* In dark theme only */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Accent colour: primary button, checked box, selection */

/* One area only */
.checkout {
  --poad-radius-sm: 0;           /* Small rounding: list options, small elements */
