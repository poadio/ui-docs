Multiselect

<poad-multiselect>

Picks several values from a list: options checked without closing the panel, removable chips or joined labels, tri-state “all” box, filter, limit. Bottom sheet on small screens.

import { Component, signal } from '@angular/core';
import { PoadMultiselectComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-multiselect-demo',
  imports: [PoadMultiselectComponent],
  template: `
    <div class="demo-row">
      <poad-multiselect [options]="regions" [(value)]="selected" ariaLabel="Regions" placeholder="Pick regions"
        showToggleAll clearable style="width: 280px" />
    </div>
    <code>regions={{ (selected() ?? []).join(',') }}</code>
  `,
})
export default class MultiselectDemo {
  readonly regions = [
    { label: 'North', value: 'n' },
    { label: 'South', value: 's' },
    { label: 'East', value: 'e', disabled: true },
    { label: 'West', value: 'w' },
  ];
  readonly selected = signal<unknown[] | null>(['n']);
}

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/multiselect-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadMultiselect } from '@poadio/ui-react';

const regions = [
  { label: 'North', value: 'n' },
  { label: 'South', value: 's' },
  { label: 'East', value: 'e', disabled: true },
  { label: 'West', value: 'w' },
];

export default function MultiselectDemo() {
  const [selected, setSelected] = useState<string[]>(['n']);
  return (
    <>
      <div className="demo-row">
        <PoadMultiselect
          options={regions} value={selected} onChange={(v) => setSelected(v as string[])} aria-label="Regions" placeholder="Pick regions"
          showToggleAll clearable style={{ width: 280 }}
        />
      </div>
      <code>regions={selected.join(',')}</code>
    </>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import MultiselectDemo from './multiselect-demo';

export default function Page() {
  return <MultiselectDemo />;
}

What it is for

Accessibility

  • Trigger role="combobox" (aria-haspopup="listbox", aria-expanded, aria-controls), list role="listbox" with aria-multiselectable="true", options with aria-selected.
  • “All” box: role="checkbox" with aria-checked="mixed" when part is chosen; named by the catalogue.
  • Chip crosses and clear button named by the catalogue (“Remove North”, “Clear all”).

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-accent: #0b7a5c;        /* Accent colour: primary button, checked box, selection */
  --poad-radius: 4px;            /* Corner rounding of controls */
}

/* In dark theme only */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Accent colour: primary button, checked box, selection */
}

/* One area only */
.checkout {
  --poad-radius: 0;              /* Corner rounding of controls */
}
