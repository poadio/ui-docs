Popover

A floating panel anchored on a target, for short interactive content (filters, settings): flipped against the window edge, closed by an outside press or Escape, optional focus trap, bottom sheet on small screens.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular

The panel is rendered in the CDK overlay; the target is passed to toggle($event) or open(target).

import { Component, signal } from '@angular/core';
import { PoadButtonComponent, PoadPopoverComponent, PoadSwitchComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-popover-demo',
  imports: [PoadButtonComponent, PoadPopoverComponent, PoadSwitchComponent],
  template: `
    <div class="demo-row">
      <button poadButton variant="outline" (click)="filters.toggle($event)">Filters</button>
      <poad-popover #filters align="start" focusTrap mobile="sheet" sheetTitle="Filters" (opened)="open.set(true)" (closed)="open.set(false)">
        <div style="display: grid; gap: 8px; padding: 12px">
          <poad-switch [(value)]="running" label="Running only" />
          <poad-switch [(value)]="mine" label="Mine" />
        </div>
      </poad-popover>
    </div>
    <code>open={{ open() }} · running={{ running() }} · mine={{ mine() }}</code>
  `,
})
export default class PopoverDemo {
  readonly open = signal(false);
  readonly running = signal(true);
  readonly mine = signal(false);
}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/popover-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadButton, PoadPopover, PoadSwitch } from '@poadio/ui-react';

export default function PopoverDemo() {
  const [open, setOpen] = useState(false);
  const [running, setRunning] = useState(true);
  const [mine, setMine] = useState(false);
  return (
    <>
      <div className="demo-row">
        <PoadPopover
          trigger={<PoadButton variant="outline">Filters</PoadButton>} align="start" focusTrap mobile="sheet" sheetTitle="Filters"
          open={open} onOpenChange={setOpen}
        >
          <div style={{ display: 'grid', gap: 8, padding: 12 }}>
            <PoadSwitch label="Running only" checked={running} onCheckedChange={setRunning} />
            <PoadSwitch label="Mine" checked={mine} onCheckedChange={setMine} />
          </div>
        </PoadPopover>
      </div>
      <code>open={String(open)} · running={String(running)} · mine={String(mine)}</code>
    </>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import PopoverDemo from './popover-demo';

export default function Page() {
  return <PopoverDemo />;
}

Rendered by Vanilla

The slot="trigger" child is the target; the other children are put in the panel when it opens (closed, they stay in the element, hidden).

<script type="module">import '@poadio/ui-elements/define';</script>

<div class="demo-row">
  <poad-popover id="filters" align="start" focus-trap mobile="sheet" sheet-title="Filters">
    <poad-button slot="trigger" variant="outline">Filters</poad-button>
    <div style="display: grid; gap: 8px; padding: 12px">
      <poad-switch id="running" label="Running only" checked></poad-switch>
      <poad-switch id="mine" label="Mine"></poad-switch>
    </div>
  </poad-popover>
</div>
<code id="popover-out">open=false · running=true · mine=false</code>

<script type="module">
  const filters = document.querySelector('#filters');
  const running = document.querySelector('#running');
  const mine = document.querySelector('#mine');
  const show = () => {
    document.querySelector('#popover-out').textContent = `open=${!!filters.open} · running=${running.checked} · mine=${!!mine.checked}`;
  };
  filters.addEventListener('openchange', show);
  filters.addEventListener('change', show);
</script>

What it is for

For a few controls tied to a button. For a plain description, a tooltip; for a task that blocks the page, a dialog.

Keyboard

KeyEffect
Enter SpaceOn the target: opens or closes.
TabWith focusTrap: cycles inside the panel.
EscCloses; with focusTrap, focus returns to the target.

Accessibility

  • Target: aria-haspopup="dialog", aria-expanded, and aria-controls pointing to the open panel.
  • Panel role="dialog"; with focusTrap, aria-modal="true" and a focus trap.
