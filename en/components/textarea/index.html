Textarea

A native <textarea> dressed like the other controls, which fits in a field (label, hint, error) and can grow with its content (autosize).

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular
import { Component, signal } from '@angular/core';
import { FormsModule } from '@angular/forms';
import { PoadFieldComponent, PoadInputDirective } from '@poadio/ui-angular';

@Component({
  selector: 'app-textarea-demo',
  imports: [FormsModule, PoadFieldComponent, PoadInputDirective],
  template: `
    <div class="demo-col">
      <poad-field label="Release notes" hint="Markdown, grows as you type">
        <textarea poadInput autosize rows="2" [(ngModel)]="notes"></textarea>
      </poad-field>
      <poad-field label="Config (JSON)">
        <textarea poadInput mono rows="3" [value]="config"></textarea>
      </poad-field>
    </div>
    <code>{{ notes().length }} characters</code>
  `,
})
export default class TextareaDemo {
  readonly notes = signal('');
  readonly config = '{ "replicas": 2 }';
}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/textarea-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadField, PoadTextarea } from '@poadio/ui-react';

export default function TextareaDemo() {
  const [notes, setNotes] = useState('');
  return (
    <>
      <div className="demo-col">
        <PoadField label="Release notes" hint="Markdown, grows as you type">
          <PoadTextarea autosize rows={2} value={notes} onChange={(e) => setNotes(e.target.value)} />
        </PoadField>
        <PoadField label="Config (JSON)">
          <PoadTextarea mono rows={3} defaultValue={'{ "replicas": 2 }'} />
        </PoadField>
      </div>
      <code>{notes.length} characters</code>
    </>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import TextareaDemo from './textarea-demo';

export default function Page() {
  return <TextareaDemo />;
}

Rendered by Vanilla

The web component has no element of its own: write a native <textarea> inside <poad-field>, and set autosize on the field.

<script type="module">import '@poadio/ui-elements/define';</script>

<div class="demo-col">
  <poad-field label="Release notes" hint="Markdown, grows as you type" autosize>
    <textarea id="notes" name="notes" rows="2"></textarea>
  </poad-field>
  <poad-field label="Config (JSON)">
    <textarea name="config" rows="3" style="font-family: var(--poad-font-mono)">{ "replicas": 2 }</textarea>
  </poad-field>
</div>
<code id="notes-out">0 characters</code>

<script type="module">
  document.querySelector('#notes').addEventListener('input', (e) => {
    document.querySelector('#notes-out').textContent = `${e.target.value.length} characters`;
  });
</script>

What it is for

For multi-line text: description, notes, configuration. autosize avoids the inner scroll bar.

Accessibility

  • Inside a field: named by the label (<label for>), described by the hint (aria-describedby).
  • A native <textarea>: the browser’s keyboard, selection, spell-checker and form handling.
