Gantt chart

<poad-gantt>

The tasks of a planning document over time, with their dependencies: on the left the framework’s table as a tree, on the right the bars, summaries, milestones and links. Zoom by day, week or month, a “today” line and, when allowed, moving and resizing with the mouse, the finger or the keyboard.

@Component({
  selector: 'app-gantt-demo',
  imports: [PoadGanttComponent, PoadSegmentedComponent],
  template: `
    <poad-segmented [(value)]="scale" [options]="scales" ariaLabel="Zoom" size="sm" />
    <poad-gantt class="demo-gantt" [plan]="plan()" [scale]="scale()" [today]="today" editable ariaLabel="Bridge repair plan"
      (taskMove)="change($event)" (taskResize)="change($event)" />
    <code>{{ last() }}</code>
  `,
})
export default class GanttDemo {
  readonly scales: PoadSegmentOption[] = [{ label: 'Day', value: 'day' }, { label: 'Week', value: 'week' }, { label: 'Month', value: 'month' }];
  readonly scale = signal<PoadGanttScale>('week');
  readonly today = new Date(2026, 8, 15);
  readonly plan = signal(PLAN);
  readonly last = signal('last=—');
  /** The Gantt chart never writes: the application applies the change to its own document. */
  change(e: PoadGanttChangeEvent): void {
    this.plan.update((p) => ({ ...p, tasks: p.tasks!.map((t) => (t.id === e.task.id ? { ...t, start: e.start, end: e.end } : t)) }));
    this.last.set(`last=${e.task.label} ${e.start.getDate()}/${e.start.getMonth() + 1}`);
  }
}

What it is for

To answer “if this slips, what falls?”. For “who is free on Thursday?”, the scheduler; for a team’s agenda, the calendar. The left pane IS the library’s table (collapse, selection, the table’s keyboard): its rows and the bars stay aligned, even when a label wraps onto two lines, and scroll together. The Gantt chart never writes: it emits the intention (new dates, snapped to the day) and keeps the display up to date while the application applies it; summaries follow. Links are read here, they are not created.

Keyboard

KeyEffect
TabMoves from the table to the bars, then from bar to bar (they are buttons).
Enter SpaceOpens the task (taskClick) and selects it.
Ctrl ← →Ctrl (⌘ on Mac) + ← / →: moves the task (or the milestone) by one day.
Shift ← →Shift + ← / →: moves the end of the task by one day (never before its start).
EscDuring a drag: cancels, the bar goes back to its place.

Accessibility

  • A named region; every bar is a button whose name gives the task, its dates and its progress (“summary” for a rolled-up bar, “milestone” for a diamond); a link carries its type and lag as its title.
  • Editing on: every movable bar is described by the keyboard help (aria-describedby); every gesture is announced in an aria-live region, with the date in the language (““Structural diagnosis” moved to Tuesday 15 September”); focus stays on the bar. A summary (rolled-up dates) and a locked task do not move, and show it.
  • Dates in local time, daylight-saving changes included; gestures snap to the day at every zoom level. Below the mobile breakpoint, the table keeps only the task column: the bars keep the room.

Nothing to import for this component: it bundles its own sheet (@poadio/ui-core/gantt.css, @poadio/ui-core/table.css) at build time. Only tokens.css and base.css are loaded once, globally (see Installation).

import '@poadio/ui-core/tokens.css';          // once, in the global stylesheet

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-accent: #0b7a5c;        /* Accent colour: primary button, checked box, selection */
  --poad-radius: 4px;            /* Corner rounding of controls */
}

/* In dark theme only */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Accent colour: primary button, checked box, selection */
}

/* One area only */
.checkout {
  --poad-radius: 0;              /* Corner rounding of controls */
}
