Tree

<poad-tree>

A hierarchy you expand and collapse: pick one node, several, or tick boxes that propagate to parents and children, a filter that keeps ancestors, children loaded on demand, and the full tree keyboard.

import { Component, signal } from '@angular/core';
import { PoadTreeComponent } from '@poadio/ui-angular';

interface Item { id: string; label: string; leaf?: boolean; children?: Item[] }

const file = (id: string, label: string): Item => ({ id, label, leaf: true });
const NODES: Item[] = [
  { id: 'src', label: 'src', children: [
    { id: 'app', label: 'app', children: [file('main', 'main.ts'), file('routes', 'routes.ts')] },
    { id: 'lib', label: 'lib', children: [file('api', 'api.ts'), file('db', 'db.ts')] },
  ] },
  { id: 'docs', label: 'docs', children: [file('readme', 'README.md'), file('guide', 'guide.md')] },
  { id: 'archives', label: 'archives' },
];

@Component({
  selector: 'app-tree-demo',
  imports: [PoadTreeComponent],
  template: `
    <poad-tree class="demo-tree" [value]="nodes" dataKey="id" selectionMode="checkbox" [(selection)]="chosen" [(expandedKeys)]="open"
      filter lazyChildren [loadChildren]="load" [icons]="icon" ariaLabel="Files" />
    <code>selected={{ names() }}</code>
  `,
})
export default class TreeDemo {
  readonly nodes = NODES;
  readonly chosen = signal<Item | Item[] | null>([]);
  readonly open = signal<unknown[]>(['src', 'app']);
  // enfants chargés à la demande (ici, après un court délai)
  readonly load = (row: Item) => new Promise<Item[]>((r) => setTimeout(() => r([file(`${row.id}-2025`, '2025.zip'), file(`${row.id}-2024`, '2024.zip')]), 600));
  readonly icon = (row: Item) => (row.leaf ? 'file' : 'folder');
  names(): string { const s = this.chosen(); return (Array.isArray(s) ? s : s ? [s] : []).map((n) => n.label).join(', ') || '—'; }
}

What it is for

To browse a hierarchy (folders, organisation, categories) or pick nodes in it. With columns, the tree table; to pick a node inside a field, the tree select.

Keyboard

KeyEffect
↓ ↑ Home EndNext / previous / first / last visible node.
→ ←→ expands the node, then moves to its first child; ← collapses it, then moves up to the parent (swapped right to left).
*Expands every sibling node.
Enter SpaceEnter picks the node (a second time removes it); Space ticks its box (checkbox mode) or picks it.
aA letter moves to the next visible node starting with it; letters typed quickly form a word.

Accessibility

  • role="tree" > role="treeitem" with aria-level, aria-setsize, aria-posinset, aria-expanded; a single node in the tab order (roving focus).
  • Picking: aria-selected; boxes: aria-checked on the node (mixed for a partial parent), the drawn box is not a tab stop.
  • The toggle button is for the mouse (“Expand” / “Collapse” tooltip); hidden from screen readers and out of the tab order, → and ← replace it, and the node’s name stays its label alone. While loading, aria-busy and a spinner.

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-accent: #0b7a5c;        /* Accent colour: primary button, checked box, selection */
  --poad-radius: 4px;            /* Corner rounding of controls */
}

/* In dark theme only */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Accent colour: primary button, checked box, selection */
}

/* One area only */
.checkout {
  --poad-radius: 0;              /* Corner rounding of controls */
}
