Skeleton

A grey, animated silhouette that holds the place of content being loaded: text, image, avatar.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular
import { Component } from '@angular/core';
import { PoadSkeletonComponent } from '@poadio/ui-angular';

@Component({
  selector: 'app-skeleton-demo',
  imports: [PoadSkeletonComponent],
  template: `
    <div class="demo-row" style="width: min(100%, 420px); flex-wrap: nowrap; align-items: flex-start">
      <poad-skeleton shape="circle" width="40px" height="40px" />
      <div class="demo-col" style="flex: 1">
        <poad-skeleton width="60%" height="14px" />
        <poad-skeleton [lines]="3" />
      </div>
    </div>
    <poad-skeleton shape="rect" width="min(100%, 420px)" height="96px" [animation]="false" />
  `,
})
export default class SkeletonDemo {}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

PoadSkeleton holds no state: a good fit for an App Router loading.tsx, rendered on the server.

// app/skeleton-demo.tsx — client component (state, handlers)
'use client';

import { PoadSkeleton } from '@poadio/ui-react';

export default function SkeletonDemo() {
  return (
    <>
      <div className="demo-row" style={{ width: 'min(100%, 420px)', flexWrap: 'nowrap', alignItems: 'flex-start' }}>
        <PoadSkeleton shape="circle" width="40px" height="40px" />
        <div className="demo-col" style={{ flex: 1 }}>
          <PoadSkeleton width="60%" height="14px" />
          <PoadSkeleton lines={3} />
        </div>
      </div>
      <PoadSkeleton shape="rect" width="min(100%, 420px)" height="96px" animation={false} />
    </>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import SkeletonDemo from './skeleton-demo';

export default function Page() {
  return <SkeletonDemo />;
}

What it is for

Mirror the shape of the expected content: the page does not jump when it arrives. Announce the loading another way (spinner, aria-busy on the area): the skeleton is invisible to screen readers.

Default 1		Number of lines (paragraph).
lastWidthlastWidthlast-widthlast-widthstring

animationanimationanimationanimationboolean
Default true		Animated shimmer (stopped under reduced motion).

Keyboard

No keyboard interaction: display component.

Accessibility

  • Hidden from assistive technologies (aria-hidden="true"): one bar per line, none is read.
  • The shimmer honours prefers-reduced-motion.

Verified by the conformance bench — These scenarios are played, identically, on every declared renderer (angular, react, vue, elements) on every push:

  • skeleton/lines-and-shape

Attributes checked : aria-hidden

Theme tokens

--poad-* tokens read by the @poadio/ui-core/skeleton.css stylesheet of @poadio/ui-core. Redefining them (globally or on a container) is enough to theme the component, on every framework at once.
