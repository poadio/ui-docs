What it is for

For a report, a description, a message: short to medium text with simple formatting. Our own code, no third-party engine. Pasting from Word or the web is cleaned; pasted Markdown is converted; “## ”, “- ”, “1. ” or “> ” at the start of a line sets the block. format="markdown" makes the value Markdown. For a document made of blocks (images, tables, callouts), prefer the block editor; for code, the code editor.

Accessibility

  • A role="textbox" aria-multiline="true" body, named by ariaLabel (or “Rich text”), aria-invalid beyond maxLength, aria-readonly when read-only.
  • A named role="toolbar", roving focus; each button named with its shortcut, aria-pressed on toggles (bold, lists…) following the text under the caret.
  • Block style in the library’s menu (aria-haspopup="menu", arrows); link in its dialog (focus trap, named field, a refused address announced by role="alert").
  • Security: an allow-list of tags, NO attribute but a safe href (https://, mailto:, /path, #anchor) — no script, no event attribute, no javascript: or data:, on paste as when showing a value.

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-accent: #0b7a5c;        /* Accent colour: primary button, checked box, selection */
  --poad-radius: 4px;            /* Corner rounding of controls */
}

/* In dark theme only */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Accent colour: primary button, checked box, selection */
}

/* One area only */
.checkout {
  --poad-radius: 0;              /* Corner rounding of controls */
}
