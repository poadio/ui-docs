Paginator

<poad-paginator>

Navigation between the pages of a list: page links with ellipses around the current page, previous and next page, first and last, a “41–50 of 137” report, and a page size that keeps the current page.

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/paginator-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadPaginator } from '@poadio/ui-react';

export default function PaginatorDemo() {
  const [first, setFirst] = useState(0);
  const [rows, setRows] = useState(10);
  return (
    <>
      <div className="demo-wide">
        <PoadPaginator totalRecords={137} first={first} rows={rows} rowsPerPageOptions={[10, 25, 50]} showFirstLastIcon
          onPageChange={(e) => { setFirst(e.first); setRows(e.rows); }} />
      </div>
      <code>first={first} rows={rows}</code>
    </>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import PaginatorDemo from './paginator-demo';

export default function Page() {
  return <PaginatorDemo />;
}

Keyboard

KeyEffect

Enter SpaceActivates the page button.
↓ ↑On the page size (the library’s dropdown, as Select): opens the list and moves through the sizes; Enter picks.

Accessibility

  • A role="navigation" region named by the catalogue (“Pagination”); current page marked aria-current="page".
  • Page size: the library’s dropdown (role="combobox", never a native <select>), named by its label (“Rows per page”).
  • Text-less buttons named by the catalogue (“Next page”, “Page 3”…); ellipses hidden from assistive technologies.

How to change

In the application’s global stylesheet, after the @poadio/ui-core sheets: on :root for the whole application, or on a container for one area only. A floating layer (menu, list, dialog) may be rendered outside its container: for it, prefer :root.

src/styles.css
/* The whole application */
:root {
  --poad-accent: #0b7a5c;        /* Accent colour: primary button, checked box, selection */
  --poad-radius: 4px;            /* Corner rounding of controls */
}

/* In dark theme only */
.theme-dark {
  --poad-accent: #3fcf9f;        /* Accent colour: primary button, checked box, selection */
}

/* One area only */
.checkout {
  --poad-radius: 0;              /* Corner rounding of controls */
}
