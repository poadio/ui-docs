Segmented control

A row of joined buttons to pick a view, a period or a mode: a single choice, or several with multiple.

  • Angular
  • Next.js
  • React
  • Vue
  • Vanilla

Demo

Rendered by Angular
import { Component, signal } from '@angular/core';
import { PoadSegmentedComponent, type PoadSegmentOption } from '@poadio/ui-angular';

@Component({
  selector: 'app-segmented-demo',
  imports: [PoadSegmentedComponent],
  template: `
    <poad-segmented [(value)]="range" [options]="ranges" ariaLabel="Range" />
    <poad-segmented [(value)]="days" [options]="weekdays" multiple shape="pill" size="sm" ariaLabel="Days" />
    <code>range={{ range() }} · days={{ days() }}</code>
  `,
})
export default class SegmentedDemo {
  readonly ranges: PoadSegmentOption[] = [
    { label: 'Day', value: 'day' },
    { label: 'Week', value: 'week', disabled: true },
    { label: 'Month', value: 'month' },
    { label: 'Year', value: 'year' },
  ];
  readonly weekdays: PoadSegmentOption[] = ['Mon', 'Tue', 'Wed', 'Thu', 'Fri'].map((d) => ({ label: d, value: d }));
  readonly range = signal<unknown>('month');
  readonly days = signal<unknown>(['Mon', 'Thu']);
}
Rendered by React (@poadio/ui-react)

Next.js uses the same package as React: the demo is rendered by @poadio/ui-react. The code shows the App Router integration — a client component ('use client') for state, rendered by a server page.

// app/segmented-demo.tsx — client component (state, handlers)
'use client';

import { useState } from 'react';
import { PoadSegmented, type PoadSegmentOption } from '@poadio/ui-react';

const ranges: PoadSegmentOption[] = [
  { label: 'Day', value: 'day' },
  { label: 'Week', value: 'week', disabled: true },
  { label: 'Month', value: 'month' },
  { label: 'Year', value: 'year' },
];
const weekdays: PoadSegmentOption[] = ['Mon', 'Tue', 'Wed', 'Thu', 'Fri'].map((d) => ({ label: d, value: d }));

export default function SegmentedDemo() {
  const [range, setRange] = useState<unknown>('month');
  const [days, setDays] = useState<unknown>(['Mon', 'Thu']);
  return (
    <>
      <PoadSegmented options={ranges} value={range} onValueChange={setRange} aria-label="Range" />
      <PoadSegmented options={weekdays} value={days} onValueChange={setDays} multiple shape="pill" size="sm" aria-label="Days" />
      <code>range={String(range)} · days={String(days)}</code>
    </>
  );
}

// app/page.tsx — server component: HTML rendered on the server, hydrated on the client
import SegmentedDemo from './segmented-demo';

export default function Page() {
  return <SegmentedDemo />;
}

What it is for

For two to five short options that change the display right away. For a detailed form choice, use a radio group.

Keyboard

KeyEffect
→ ↓ ← ↑Moves focus to the next or previous enabled option (wrapping; mirrored right to left).
Home EndFocuses the first or last enabled option.
Space EnterSelects the focused option (toggles it with multiple).

Accessibility

  • role="group" container named by aria-label; each option is a <button> with aria-pressed.
  • A single tab stop: the selected option, otherwise the first enabled one; disabled options are skipped.

Theme tokens

--poad-* tokens read by the @poadio/ui-core/segmented.css stylesheet of @poadio/ui-core. Redefining them (globally or on a container) is enough to theme the component, on every framework at once.
